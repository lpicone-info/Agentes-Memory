# 4. Hook API

```ts
export const useAutorizacionApi = () => {
  const { apiRequest } = useApiRequest();

  const fetchAutorizaciones = async ({
    values,
    page
  }: {
    values: AutorizacionConsultaValues;
    page: number;
  }) => {
    const { VITE_ITEMS_X_PAGE } =
      getEnvVariables();

    const itemsXPagina =
      Number(VITE_ITEMS_X_PAGE || 10);

    const offset =
      (page - 1) * itemsXPagina;

    const data = await apiRequest<{
      autorizaciones:
        AutorizacionConsultaResultado[];
    }>(
      "POST",
      "/autorizaciones/retrieveAutorizaciones",
      {
        prepaga: values.prepaga,
        contra: values.contra,
        inte: values.inte,
        fecha: values.fecha,
        offset,
        itemsXPagina
      }
    );

    return {
      autorizaciones:
        data.autorizaciones ?? [],
      offset
    };
  };

  return { fetchAutorizaciones };
};
```

Se obtiene el prestador para buscar el lugar mediante:

Sin embargo, cuando `@cuit_prestad` llega `NULL`, previamente el SP calcula el CUIT en:

```sql
@var_cuit
```

pero **no actualiza `@cuit_prestad`**.

Por lo tanto:

```text
@cuit_prestad = NULL
@var_cuit      = CUIT encontrado
@var_prestad_por_cuit = NULL
```

Esto provoca que:

- la búsqueda por terminal no encuentre lugar;
- se rechace con código `272`;
- la búsqueda del lugar predeterminado tampoco encuentre filas.

```sql
SELECT @var_prestad_por_cuit = prestad
FROM prestadores
WHERE cuit = @var_cuit
AND baja_fecha IS NULL
```
