# Tags HTML y componentes JSX utilizados en Presmed Web

## 1. Objetivo

Este documento tiene como objetivo capacitar a desarrolladores que trabajen sobre Presmed Web. Se explican los principales tags HTML utilizados en la aplicación, su función y ejemplos tomados del código fuente.

La aplicación está desarrollada con React, TypeScript, JSX, Formik y React-Bootstrap.

## 2. Diferencia entre tags HTML y componentes React

En JSX se utilizan dos tipos de elementos:

### Tags HTML nativos

Se escriben en minúscula:

```tsx
<div>
  <span>Texto</span>
</div>
```

Ejemplos:

- `div`
- `span`
- `h3`
- `option`
- `table`
- `thead`
- `tbody`
- `tr`
- `th`
- `td`

### Componentes React

Se escriben comenzando con mayúscula:

```tsx
<FormInput
  name="usuario"
  label="Usuario"
/>
```

Ejemplos utilizados en Presmed Web:

- `FormInput`
- `FormSelect`
- `FormCheck`
- `Button`
- `Card`
- `Row`
- `Col`
- `Modal`

Estos componentes finalmente generan tags HTML, pero agregan comportamiento, estilos o integración con otras librerías.

---

## 3. Tag `div`

### Funcionamiento

`div` es un contenedor genérico. Se utiliza para agrupar elementos y aplicar estilos o estructura visual.

No tiene un significado semántico específico.

### Ejemplo en Presmed Web

Archivo: `AutorizacionCarga.tsx`

```tsx
<div
  style={{
    marginTop: mostrarTopes ? "200px" : 0,
    transition: "margin-top 0.25s ease"
  }}
>
  <AutorizacionDatosGral />
  <AfiliadoIngreso />
  <DemandanteIngreso />
  <EfectorIngreso />
</div>
```

En este caso, el `div` agrupa los distintos bloques de la autorización y permite modificar dinámicamente el margen superior cuando se muestran los topes del afiliado.

---

## 4. Tag `h3`

### Funcionamiento

`h3` representa un encabezado de nivel 3. Se utiliza para mostrar títulos o subtítulos.

Los encabezados deberían respetar una jerarquía: `h1`, `h2`, `h3`, etc.

### Ejemplo en Presmed Web

```tsx
<h3>Autorización {tipoAutorizacionDeno}</h3>
```

El texto del encabezado se completa dinámicamente utilizando el tipo de autorización.

---

## 5. Tag `span`

### Funcionamiento

`span` es un contenedor en línea. Se utiliza para aplicar estilos o mostrar una parte específica de un texto.

### Ejemplo en Presmed Web

Archivo: `TablaPrestadores.tsx`

```tsx
<span className="d-lg-none fw-bold">
  Código:
</span>
{prestador.prestad}
```

El `span` muestra el nombre del campo en dispositivos pequeños. La clase `d-lg-none` hace que se oculte en pantallas grandes.

Esto permite que una fila de datos sea más comprensible en formato mobile.

---

## 6. Formularios

La aplicación utiliza formularios administrados por Formik.

### Ejemplo principal

Archivo: `AutorizacionCarga.tsx`

```tsx
<Form
  autoComplete="off"
  spellCheck="false"
  noValidate
  onSubmit={handleSubmit}
>
  <AutorizacionDatosGral />
  <AfiliadoIngreso />
  <DemandanteIngreso />
  <EfectorIngreso />
</Form>
```

### Atributos utilizados

- `autoComplete="off"`: evita que el navegador complete automáticamente los campos.
- `spellCheck="false"`: desactiva la corrección ortográfica.
- `noValidate`: evita la validación automática del navegador.
- `onSubmit`: ejecuta la función de envío del formulario.

La validación se realiza mediante Formik y Yup.

## 7. Campos de entrada: `input`

En la aplicación, los campos de entrada se utilizan mediante el componente reutilizable `FormInput`.

### Uso en una pantalla

```tsx
<FormInput
  name="usuario"
  label="Usuario"
  placeholder="Ingrese usuario"
/>
```

### HTML generado internamente

Archivo: `FormInput.tsx`

```tsx
<Form.Control
  {...rest}
  {...field}
  type={type}
  placeholder={placeholder}
  onBlur={customHandleBlur}
/>
```

Conceptualmente, este componente genera un elemento equivalente a:

```html
<input
  type="text"
  name="usuario"
  placeholder="Ingrese usuario">
```

### Funciones agregadas por `FormInput`

El componente:

- Se conecta con Formik mediante `useField`.
- Obtiene el valor actual del campo.
- Actualiza el estado del formulario.
- Ejecuta validaciones.
- Muestra errores.
- Renderiza automáticamente el label.
- Permite configurar el tipo de dato mediante `type`.

### Ejemplo de contraseña

```tsx
<FormInput
  name="password"
  label="Contraseña"
  type="password"
  placeholder="Ingrese contraseña"
/>
```

El atributo `type="password"` oculta visualmente los caracteres ingresados.

## 8. Etiquetas de formulario: `label`

El `label` identifica un campo para el usuario.

En Presmed Web se genera mediante `Form.Label` dentro de `FormInput`:

```tsx
{label && <Form.Label>{label}</Form.Label>}
```

Uso:

```tsx
<FormInput
  name="efePrestad"
  label="Código"
/>
```

El label permite identificar que el campo corresponde al código del prestador.

El componente también utiliza:

```tsx
controlId={name}
```

Esto vincula el label con su control de formulario.

## 9. Listas desplegables: `select` y `option`

Las listas desplegables se implementan mediante `FormSelect`.

### Ejemplo de uso

Archivo: `ComboPrestadLugares.tsx`

```tsx
<FormSelect
  {...props}
  name="efeLugar"
  label="Lugar"
>
  <option value="">Seleccione lugar</option>

  {lugares.map((lugar) => (
    <option
      key={lugar.lugar}
      value={lugar.lugar}
    >
      {lugar.domi}
    </option>
  ))}
</FormSelect>
```

### Funcionamiento de `select`

`select` permite seleccionar un valor de una lista.

### Funcionamiento de `option`

Cada `option` representa una alternativa dentro del `select`.

- `value`: valor que se guarda en el formulario.
- Contenido interno: texto que se muestra al usuario.
- `key`: identificador que React utiliza al renderizar listas.

### Ejemplo HTML equivalente

```html
<select name="efeLugar">
  <option value="">Seleccione lugar</option>
  <option value="10">Sucursal Central</option>
  <option value="20">Sucursal Norte</option>
</select>
```

## 12. Distribución visual con `Row` y `Col`

`Row` y `Col` son componentes de React-Bootstrap basados en el sistema de grilla de Bootstrap.

### Ejemplo

```tsx
<Row className="gy-3">
  <FormInput
    lg={1}
    md={4}
    name="efePrestad"
    label="Código"
  />

  <FormInput
    lg={4}
    md={8}
    name="efeNombre"
    label="Denominación"
  />
</Row>
```

### Funcionamiento de `Row`

`Row` representa una fila dentro de la grilla.

### Funcionamiento de `Col`

`Col` representa una columna.

Los valores indican cuántas de las 12 columnas disponibles ocupa el elemento:

```tsx
<Col lg={4}>
```

Significa que, en pantallas grandes, ocupa 4 de las 12 columnas.

Los tamaños utilizados son:

- `sm`: pantallas pequeñas.
- `md`: pantallas medianas.
- `lg`: pantallas grandes.
- `xl`: pantallas extra grandes.
- `xxl`: pantallas muy grandes.

## 13. Tablas: `table`, `thead`, `tbody`, `tr`, `th` y `td`

Las tablas se utilizan para presentar información estructurada en filas y columnas.

### Ejemplo en `TopesAfiliadoPanel.tsx`

```tsx
<table className="table table-sm">
  <thead className="table-light sticky-top">
    <tr>
      <th>Nomenclador</th>
      <th>Prestación</th>
      <th>Autorización</th>
      <th>Cantidad</th>
    </tr>
  </thead>

  <tbody>
    {items.map((item) => (
      <tr key={`${item.nomenclador}-${item.autorizacion}`}>
        <td>{item.nomenclador}</td>
        <td>{item.prestacion}</td>
        <td>{item.autorizacion}</td>
        <td>{item.cantidad}</td>
      </tr>
    ))}
  </tbody>
</table>
```

### Funcionamiento de cada tag

- `table`: define la tabla completa.
- `thead`: agrupa el encabezado.
- `tbody`: agrupa los datos.
- `tr`: representa una fila.
- `th`: representa una celda de encabezado.
- `td`: representa una celda de datos.

### Recomendación

Utilizar `th` para encabezados y `td` para valores. Esto mejora la legibilidad y la accesibilidad de la tabla.

## 14. Renderizado condicional

React permite mostrar elementos solamente cuando se cumple una condición.

### Ejemplo en `EfectorIngreso.tsx`

```tsx
{categorias.length > 0 && (
  <ComboPrestadCategorias
    categorias={categorias}

    md={6}
```

El combo de categorías solamente se muestra cuando existe al menos una categoría.

La expresión:

```tsx
condicion && componente
```

significa:

- Si la condición es verdadera, se renderiza el componente.
- Si es falsa, no se renderiza nada.

## 15. Fragmentos JSX

Los fragmentos permiten devolver varios elementos sin agregar un `div` innecesario al HTML.

### Ejemplo en `EfectorIngreso.tsx`

```tsx
return (
```

La sintaxis:

```tsx
<>

</>
```

```tsx
<React.Fragment>
  ...
```

El fragmento no agrega un nodo HTML adicional.

# Tags HTML utilizados en WebPOS

## Objetivo

Capacitar a desarrolladores en la lectura y mantenimiento de las vistas PHP de WebPOS, explicando los principales tags HTML utilizados, su función y ejemplos reales de la aplicación.

Las páginas de WebPOS combinan código PHP con HTML. PHP genera dinámicamente parte del contenido y el navegador recibe finalmente HTML.

## 1. Estructura básica de una página

Ejemplo de `webpos/index.php`:

```php
<!DOCTYPE HTML>
<html translate="no">

<head>
    <meta charset="utf-8">
    <title>WebPos</title>
    <meta name="viewport" content="width=device-width, initial-scale=1">

    <link rel="stylesheet"
          href="css/bootstrap.css?<?= filemtime('css/bootstrap.css') ?>">
</head>

<body>
    <!-- contenido de la página -->

    <script src="js/jquery.min.js"></script>
    <script src="js/bootstrap.bundle.js"></script>
</body>

</html>
```

### Tags utilizados

- `html`: elemento raíz del documento.
- `head`: contiene metadatos, título y referencias a estilos.
- `meta`: define información técnica del documento.
- `title`: título mostrado en la pestaña del navegador.
- `link`: incorpora hojas de estilo o iconos.
- `body`: contiene el contenido visible.
- `script`: incorpora archivos JavaScript.

La expresión PHP:

```php
<?= filemtime('css/bootstrap.css') ?>
```

agrega la fecha de modificación del archivo como parámetro de la URL. Esto permite que el navegador detecte cambios en el CSS y no utilice una versión antigua de caché.

## 2. Tag `div`

`div` es un contenedor genérico utilizado para organizar visualmente los elementos.

Ejemplo real de `index.php`:

```html
<div class="d-flex align-items-center justify-content-center vh-100">
    <div class="panel login-form">
        <div class="panel-heading">
            <h2 id="logo-text">Portal Prestadores</h2>
        </div>

        <div class="panel-body login-content">
            <!-- formulario de ingreso -->
        </div>
    </div>
</div>
```

En WebPOS, `div` se utiliza junto con clases de Bootstrap para:

- Crear filas y columnas.
- Agrupar campos.
- Armar paneles.
- Centrar contenido.
- Controlar márgenes y espaciado.
- Mostrar u ocultar elementos.

## 3. Tags `form`, `input` y `button`

El formulario de inicio de sesión se encuentra en `index.php`:

```html
<form
    id="login"
    method="POST"
    action="administracion_principal.php"
    autocomplete="off"
    spellcheck="false"
>
    <input
        type="text"
        name="username"
        id="username"
        maxlength="15"
        placeholder="Usuario"
        autofocus
        required
    />

    <input
        type="password"
        name="password"
        id="password"
        maxlength="100"
        placeholder="Contraseña"
        required
    />

    <button
        type="button"
        id="boton_form"
        onclick="check_login()"
    >
        Entrar
    </button>
</form>
```

### `form`

Agrupa los controles que participan de una operación de entrada o envío de datos.

Atributos utilizados:

- `id`: identifica el formulario para JavaScript o CSS.
- `method="POST"`: indica el método HTTP utilizado.
- `action`: especifica el destino del envío.
- `autocomplete="off"`: desactiva el autocompletado.
- `spellcheck="false"`: desactiva el corrector ortográfico.

### `input`

Permite ingresar información.

### [16/09/2026 11:19:18] Agente

Sí, Leandro, pero con una aclaración importante: **PowerBuilder/DataWindow no suele tomar una fuente TTF por ruta directa** como `.\fuente.ttf`.

En controles PB, DataWindows y reportes normalmente se referencia la fuente por **nombre de familia**, por ejemplo:

```text
font.face = "Libre Barcode 39"
```

Para que eso funcione, Windows tiene que conocer esa fuente. Tenés dos caminos:

**1. Instalarla en Windows\Fonts**
Es el camino tradicional. Queda disponible para todo el sistema.

**2. Cargarla dinámicamente desde el directorio del EXE**
También se puede. La aplicación puede cargar el `.ttf` al iniciar usando API de Windows, por ejemplo con `AddFontResourceEx`, y luego usar la fuente por nombre dentro de PowerBuilder.

Conceptualmente:

```powerscript
// Al iniciar la app
AddFontResourceEx(ls_ruta_ttf, FR_PRIVATE, 0)
```

Después en PB/DataWindow usás el nombre real de la fuente:

```powerscript
dw_1.Modify("campo.Font.Face='Nombre de la Fuente'")
```

O en el painter, si ya está disponible en diseño/ejecución, se referencia por nombre.

Puntos importantes:

- No se referencia el TTF por path desde la propiedad font.
- Conviene cargar la fuente al iniciar la aplicación.
- Usá la ruta real del EXE, no “directorio actual”, porque el current directory puede cambiar.
- Con `FR_PRIVATE`, la fuente queda disponible solo para el proceso, sin instalarla globalmente.
- Al cerrar la app, se puede liberar con `RemoveFontResourceEx`.
- Para impresión/PDF hay que probarlo específicamente, porque algunos drivers o generadores pueden comportarse distinto si la fuente no está instalada globalmente.

Conclusión: **sí podés distribuir el TTF junto al EXE y cargarlo en runtime**, pero PB lo va a usar por **nombre de fuente**, no por archivo.
