### [28/08/2026 10:20:40] Agente

Leandro, para armar esa configuración desde las aplicaciones, el circuito correcto es este:

**Admin**
1. Entrar a `Administración de usuarios`.
2. Crear o buscar el usuario.
3. En `Tipo usuario`, seleccionar el tipo `W`.
4. Informar `E-mail`, porque para usuarios Web/Precarga es obligatorio.
5. En el selector `Prestador / Centro`, marcar `Centro`.
6. En `Código`, cargar el código del `Centro de Atención` que va a operar ese usuario.
7. Completar `Sucursal`, vigencias y password.
8. Grabar con `Alta` o `Modifica`.

Validaciones del código: para tipo `W`, Admin exige `es_centro` informado y exige `clini` cargado; además el login WebPos solo acepta usuarios `zz_usuari.tipo = 'W'` y usa `zz_usuari.clini` como centro/prestador asociado.

**Presmed**
1. Si el centro no existe, crearlo en `Prestadores > Centros de Atención`.
2. Para asignar prestadores a ese centro, entrar al ABM de prestadores.
3. Buscar cada prestador.
4. Ir a la grilla de `Lugares`.
5. En la columna `Centro de Atención`, seleccionar el centro correspondiente.
6. Grabar el prestador.
7. Verificar desde `Prestadores Asociados a Centros`.

Punto importante: para WebPos esto no es “centro de costo”; es `Centro de Atención`. La relación que consume WebPos sale de `prestad_lugares.cod_punto_atencion`, y el listado de prestadores del centro se arma con `ars_centro_prestadores`.

Evidencia revisada: `wp_sucur_clini.srw`, `de_usu_sucur.srd`, `d_lista_lugares.srd`, `wp_puntos_atencion.srw`, `ars_usuario_pass_valido.sql`, `ars_centro_prestadores.sql`.
