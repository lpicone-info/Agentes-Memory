- Sobre `vali_fecha`: el SP puede devolver `NULL`; se recomendó tipar `SituacionTerapeutica.vali_fecha` como `string | null`.

```ts
export interface SituacionTerapeutica {
  histo: number;
  vali_fecha: string | null;
  situ: string;
  situ_deno: string;
}
```

- `histoValiFecha` en Formik/UI puede permanecer como `string`, porque el componente transforma `null` a cadena vacía con `historiaSeleccionada?.vali_fecha ?? ""`.

- Se aclaró que pasa lo mismo con `icd`: `icd` e `histo` forman parte de los valores de Formik y cabecera, pero no del schema porque son datos opcionales seleccionables en esta etapa.
