```ts
const optionalPositiveDecimal = (
  fieldName: string,
  maxIntegerDigits: number
) =>
  z.preprocess(
    emptyToUndefined,
    z.coerce
      .number({
        error: `Ingrese un número válido para ${fieldName}`
      })
      .finite({
        error: `Ingrese un número válido para ${fieldName}`
      })
      .positive({
        error: `Ingrese un valor positivo para ${fieldName}`
      })
      .refine(
        (value) =>
          value
            .toFixed(2)
            .split(".")[0]
            .replace("-", "").length <= maxIntegerDigits,
        `Ingrese hasta ${maxIntegerDigits} dígitos enteros para ${fieldName}`
      )
      .refine(
        (value) =>
          Math.abs(
            value * 100 - Math.round(value * 100)
          ) < 1e-8,
        `Ingrese hasta 2 decimales para ${fieldName}`
      )
      .optional()
  );
```

### [29/09/2026 16:50:13] Agente

La normalización busca contar solamente los dígitos reales de la parte entera, sin que el signo, los ceros iniciales o los decimales afecten el límite.

```ts
const unsignedValue = value.replace(/^[-+]/, "");
```

Elimina un posible signo al inicio:

```text
"-123.45" → "123.45"
"+123.45" → "123.45"
"123.45"  → "123.45"
```

Aunque `allowNegative={false}` ya impida negativos, se elimina el signo para que la función sea reutilizable.

Luego:

```ts
const [integerPart = ""] =
  unsignedValue.split(".");
```

Separa la parte entera de los decimales:

```text
"123.45" → integerPart = "123"
"123"    → integerPart = "123"
""       → integerPart = ""
```

Los decimales no participan del límite de dígitos enteros.

Después:

```ts
const normalizedIntegerPart =
  integerPart.replace(/^0+(?=\d)/, "");
```

Elimina ceros iniciales, pero conserva al menos un dígito:

```text
"000123" → "123"
"0012"   → "12"
"000"    → "0"
"0"      → "0"
```

Finalmente:

```ts
return normalizedIntegerPart.length <= maxDigits;
```

Ejemplo con máximo de 3 dígitos:

```text
"123.45"  → 3 dígitos → permitido
"1234.00" → 4 dígitos → rechazado
"000123"  → 3 dígitos reales → permitido
"0000"    → 1 dígito normalizado → permitido
```

La función completa:

```ts
export const allowIntegerDigits =
  (maxDigits: number): IsAllowed =>
  ({ value }) => {
    const unsignedValue = value.replace(/^[-+]/, "");

    const [integerPart = ""] =
      unsignedValue.split(".");

    const normalizedIntegerPart =
      integerPart.replace(/^0+(?=\d)/, "");

    return normalizedIntegerPart.length <= maxDigits;
  };
```

`NumericFormat` entrega `value` sin separadores de miles, por lo que no es necesario eliminar comas o puntos de formato antes de separar los decimales.
