César, tomando como referencia `lcamaratta-V25.08.001 / webpos`, lo principal que deberías aprender no es “todo HTML”, sino el HTML práctico que usa esta aplicación.

**Evidencia**
WebPos está armado como PHP clásico que imprime HTML, con Bootstrap, jQuery y FontAwesome. Los tags más presentes son:

- `div`: estructura visual casi completa. Se usa para grillas, paneles, filas, columnas, modales y contenedores.
- `input`: campos de usuario, contraseña, afiliado, token, prestación, cantidad, hidden de control.
- `select` / `option`: combos de entidad, documento, nomenclador, lugares, sala, etc.
- `button` y `a`: acciones de pantalla. Muchas llaman funciones JS con `onclick`.
- `form`: login, impresión y algunas pantallas con envío.
- `label`: texto asociado a campos, muy usado para responsive/mobile.
- `span` / `i`: iconos FontAwesome y textos auxiliares.
- `script` / `link`: carga de JS y CSS.
- `fieldset`: agrupación funcional de bloques, por ejemplo prestaciones.
- `p`, `h2`, `h4`, `strong`, `br`, `img`: uso secundario.

**Qué aprender primero**
1. **Estructura base HTML**
   `html`, `head`, `body`, `meta`, `title`, `link`, `script`.

2. **Formularios**
   `form`, `input`, `select`, `option`, `button`, `label`.

   Atributos clave:
   `id`, `name`, `class`, `type`, `value`, `placeholder`, `maxlength`, `disabled`, `required`, `hidden`.

3. **Bootstrap**
   Es central para entender el layout:
   `container-fluid`, `row`, `col-*`, `d-flex`, `d-none`, `btn`, `form-control`, `form-select`, `modal`.

4. **Relación HTML + JavaScript**
   Esto es lo más importante en WebPos. El JS busca campos por:
   `#id`, `[name='campo']`, `.class`.

   Ejemplos reales:
   `#username`, `#password`, `#tipoTransac`, `#tablaPrestacionBody`, `[name='prestac']`, `[name='canti']`.

5. **Eventos**
   WebPos mezcla eventos inline y jQuery:
   `onclick`, `onchange`, `onkeydown`, `.click()`, `.on("change", ...)`, `.on("keydown", ...)`.

6. **Modales Bootstrap**
   Se usan para búsquedas:
   `div class="modal"`, `modal-dialog`, `modal-content`, `modal-header`, `modal-body`, `data-bs-dismiss`, `.modal("show")`.

**Recomendación**
Para entender WebPos, estudiaría en este orden:

1. `index.php`: login y estructura HTML básica.
2. `frames/frame_afiliado.php`: campos de afiliado y combos.
3. `frames/frame_prestacion.php`: grilla de prestaciones, botones y modal de búsqueda.
4. `js/login_user.js`: cómo el HTML dispara validaciones y AJAX.
5. `js/prestacion.js`: cómo se manipulan filas dinámicas.
6. `js/transac.js`: cómo se juntan datos del HTML para generar la transacción.

Conclusión: aprendé HTML orientado a formularios, Bootstrap y selectores jQuery. En WebPos el punto crítico no es dibujar páginas, sino entender cómo cada `id` y `name` conecta la pantalla PHP con la lógica JavaScript y luego con los controladores PHP.
