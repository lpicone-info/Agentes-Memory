Conviene crear un wrapper propio, por ejemplo:

```text

```

La secuencia sería:

```text

      5. pri_auto_prestac_items_remotas por cada ítem
      6. prs_valida_of_auto_remotas
```

### B. Nivel real del usuario

En [prs_valida_of_auto_remotas.sql](/home/luispicone/.openclaw/workspace/svn/lcamaratta-V25.08.001_CLON/backend/procedures/prs_valida_of_auto_remotas.sql:589):


Para Presmed Web recomiendo:

- Obtener el usuario desde `req.usuario`, no desde el body.
- Mantener su nivel real.
- Excluir `-4` del bloque que fuerza nivel cero.
