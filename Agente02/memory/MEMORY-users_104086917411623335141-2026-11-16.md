César, `fn_recha_orden` se llama **indirectamente durante `wf_valida_prestacion`**:

1. Al ingresar/modificar la prestación:
   `ItemChanged → wf_valida_prestacion`
2. Primero, al validar cobertura:
   `val.of_cobertura → prs_valida_of_cobertura → fn_recha_orden`
3. Después puede ejecutarse al validar:
   - prestador demandante;
   - convenio;
   - topes de cobertura.

La función **no valida la prestación directamente**: compara el orden o prioridad del rechazo actual contra otros posibles rechazos, como cobertura inexistente, carencia o falta de convenio.

Por eso puede invocarse varias veces durante una sola carga, dependiendo de las validaciones ejecutadas.
