Hoy el problema aparece porque Bootstrap aplica el color semitransparente al `.nav-link` dentro de `.navbar-dark`. La forma más limpia es definir una clase para estos dropdowns tipo botón, por ejemplo:

```tsx
className="navbar-menu-button btn-primary btn mx-1 mb-1 mb-sm-3"
```

y en CSS:

```css
.navbar-menu-button > .nav-link {
  color: white !important;
}

.navbar-menu-button > .nav-link:hover,
.navbar-menu-button > .nav-link:focus {
  color: white !important;
}
```

Después cualquier opción nueva del navbar usa la misma clase y queda resuelto una sola vez.

Otra alternativa más global sería sobrescribir todos los links de la navbar:

```css
.navbar-dark .navbar-nav .nav-link {
  color: white !important;
}
```

Pero es más amplia: también afectaría links que quizás queramos mantener con el comportamiento visual de Bootstrap. Para este caso prefiero la clase específica `navbar-menu-button`, porque apunta solo a los dropdowns que están estilizados como botones.
