## Interpretación funcional

El cambio **no consiste en cargar varios archivos simultáneamente**.

El nuevo circuito quedaría así:

1. **Guardar y continuar**
   - Valida los datos.
   - Genera el expediente sin presentarlo.
   - Guarda `chk_cierre = 'N'`.
   - Abre automáticamente el modal de adjuntos.

2. **Guardar y salir**, dentro de Adjuntos
   - Pregunta:
     > ¿Cierra la presentación? Esto impide seguir adjuntando
   - Si responde **Sí**:
     - Presenta el expediente.
     - Cierra el modal.
   - Si responde **No**:
     - No presenta el expediente.
     - Cierra el modal y vuelve a la pantalla principal.

3. **Adjuntos**
   - Permanece habilitado mientras el expediente no esté presentado.
   - Permite volver a entrar al modal y agregar adjuntos.

4. **Presentar**
   - Se habilita después de generar el expediente.
   - Ejecuta la presentación definitiva.
   - Después de presentarlo se deshabilitan `Adjuntos` y `Presentar`.

Esta interpretación resuelve la aparente contradicción del documento: desde **Guardar y salir** se puede presentar inmediatamente o salir sin presentar y hacerlo después desde el botón **Presentar**.
