César, para la versión `25.08.001`, la configuración sale así:

**Nomencladores**
La tabla base es `nomencladores`. El ABM usa estos campos relevantes:

- `carac`: clasifica el nomenclador como:
  - `1` Ambulatorio
  - `2` Internación
  - `3` Ambulatorio/Internación
  - `4` Cirugía
- `materiales`: flag `S/N`
- `traslado`: flag `S/N`

Importante: `carac` no identifica materiales, traslados ni odontología; solo indica el tipo asistencial/general del nomenclador.

**Materiales**
Se identifica directamente con:

```sql
nomencladores.materiales = 'S'
```

Esto se valida en autorizaciones: si el nomenclador es de materiales, la autorización debe ser tipo `M`. Además, en prestaciones hay lógica asociada a materiales con `prestaciones.req_cirugia`.

**Traslados**
Se identifica directamente con:

```sql
nomencladores.traslado = 'S'
```

También se valida en autorizaciones: si el nomenclador es de traslado, la autorización debe ser tipo `T`.

César, para que se vea el menú de odontología al login en Prestaciones hay dos condiciones:

**Evidencia**
El login de `wf_mainpresta` llama a `wf_habilita(gs_codusu, ls_msg)`. Esa función toma los permisos desde:

```sql
zz_accesos
zz_grupusua
zz_usuari
zz_grupo
```

con estas condiciones principales:

```sql
zz_accesos.grupo = zz_grupusua.grupo
zz_accesos.menu_id = 'm_main'
zz_grupusua.usuari = <usuario>
zz_accesos.baja_fecha IS NULL
zz_grupo vigente
zz_usuari vigente
```

El item del menú principal de odontología en Prestaciones es:

```sql
m_odontologa
```

Además, aunque el permiso exista, `wf_mainpresta` oculta odontología si la regla 12 está en `N`:

```powerscript
IF glob.gs_reglas[12] = 'N' THEN
    m_main.m_odontologa.Visible = FALSE
END IF
```

Esa regla viene de:

```sql
zz_sistema_reg.reg = 12
```

En reglas base de Premedic `25.08.001` está:

```sql
zzu_sistema 12, 'N' --MODULO DE ODONTOLOGIA
```

**Conclusión**
Para que se vea `m_odontologa` al login, se necesita:

```sql
zz_sistema_reg.reg = 12
zz_sistema_reg.valor = 'S'
zz_sistema_reg.baja_fecha IS NULL
```

y que el usuario pertenezca a un grupo vigente con acceso vigente en:

```sql
zz_accesos.menu_id = 'm_main'
zz_accesos.item = 'm_odontologa'
zz_accesos.baja_fecha IS NULL
```

También puede verse el padre `m_odontologa` si el grupo tiene permiso a algún hijo del menú odontología, porque la lógica arma el path y habilita los padres necesarios.

Separado de eso, para autorizaciones odontológicas el item es distinto:

```sql
m_odontología
```

Ese permiso se usa para mapear el tipo de autorización `O`. No reemplaza al permiso del menú principal `m_odontologa`.
