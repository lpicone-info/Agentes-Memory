Por ejemplo:


Además, un `useEffect` no se ejecuta intercalado entre esas instrucciones. React lo ejecuta después de:

1. terminar la función actual;
2. procesar el render;
3. confirmar los cambios.

Por eso esta secuencia es segura:

```ts
setValue("prepaga", autorizacion.prepaga);
```
