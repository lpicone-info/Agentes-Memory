Para validar sin tocar datos, si el SP escribe, ejecutar dentro de transacción y rollback:

```sql
BEGIN TRAN

EXEC dbo.pri_auto_remotas_webpos ...

SELECT *
FROM auto_remotas
WHERE transac = SCOPE_IDENTITY()

ROLLBACK
```

Para este caso concreto, pondría trazas en tres puntos:

SELECT 'antes pri_auto_remotas', @sucur AS sucur, @auto AS auto, @prm_sucur_rel AS sucur_rel, @prm_auto_rel AS auto_rel

Clave: para SP legacy, la forma más eficiente es instrumentar con `SELECT`/`RAISERROR ... WITH NOWAIT`, ejecutar con `sqlcmd`, y guardar la salida completa en un `.out`.
