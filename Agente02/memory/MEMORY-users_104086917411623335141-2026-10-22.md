Para mostrar los parámetros que recibe un procedimiento almacenado en SQL Server, agregá las sentencias al comienzo del `PROCEDURE`, después de `BEGIN`:

```sql
PRINT 'transac = ' + CONVERT(varchar(20), @transac)

PRINT 'var_erro inicial = ' + COALESCE(CONVERT(varchar(20), @var_erro), 'NULL')

PRINT 'auto inicial = ' + COALESCE(CONVERT(varchar(20), @auto), 'NULL')

PRINT 'prm_ret_sel = ' + COALESCE(@prm_ret_sel, 'NULL')
```

También podés devolverlos como resultado tabular, que suele ser más claro:

```sql
SELECT
    @transac AS transac,
    @var_erro AS var_erro_inicial,
    @auto AS auto_inicial,
    @prm_ret_sel AS prm_ret_sel
```

Desde el bloque que ejecuta el procedimiento, los parámetros de salida se pueden mostrar después del `EXEC`:

```sql
DECLARE
    @var_erro INTEGER,
    @auto INTEGER

EXEC prs_valida_of_auto_remotas
    7495410,
    @var_erro OUTPUT,
    @auto OUTPUT,
    @prm_ret_sel = 'S'

SELECT
    @var_erro AS var_erro_salida,
    @auto AS auto_salida
```

`PRINT` puede demorarse en aparecer por el buffering de SQL Server. Para visualizar el mensaje inmediatamente durante una ejecución larga, usar:

```sql
RAISERROR (
    'transac = %d',
    10,
    1,
    @transac
) WITH NOWAIT
```

El nivel `10` es informativo y no interrumpe la ejecución.
