## 2. Medición exacta de cada SP hijo con Extended Events

```sql

(
    ACTION
    (
        sqlserver.database_name,
        sqlserver.session_id,
        sqlserver.client_app_name,
        sqlserver.sql_text
    )
    WHERE
    (
        sqlserver.database_name = N'Ospecon_Prod'
    )
),
ADD EVENT sqlserver.sp_statement_completed
(
    ACTION
    (

        sqlserver.session_id,

        sqlserver.sql_text
    )
    WHERE
    (
        sqlserver.database_name = N'Ospecon_Prod'
        AND duration >= 100000
    )

ADD TARGET package0.event_file
(
```

## 3. Leer los tiempos de los procedimientos

```sql
WITH Eventos AS
(
    SELECT
        CAST(event_data AS XML) AS evento
    FROM sys.fn_xe_file_target_read_file
    (
        N'C:\Temp\xe_prs_valida_of_auto_remotas*.xel',
        NULL,
        NULL,
        NULL
    )
)
SELECT
    evento.value('(/event/@timestamp)[1]', 'datetime2(3)') AS fecha_utc,
    evento.value('(/event/action[@name="session_id"]/value)[1]', 'int') AS session_id,
    evento.value('(/event/data[@name="object_name"]/value)[1]', 'sysname') AS procedimiento,
    evento.value('(/event/data[@name="object_id"]/value)[1]', 'int') AS object_id,
    evento.value('(/event/data[@name="duration"]/value)[1]', 'bigint') / 1000 AS duracion_ms,
    evento.value('(/event/data[@name="cpu_time"]/value)[1]', 'bigint') / 1000 AS cpu_ms,
    evento.value('(/event/data[@name="logical_reads"]/value)[1]', 'bigint') AS lecturas_logicas,
    evento.value('(/event/data[@name="writes"]/value)[1]', 'bigint') AS escrituras,
    evento.value('(/event/data[@name="statement"]/value)[1]', 'nvarchar(max)') AS sentencia
FROM Eventos
ORDER BY fecha_utc
```

La columna `duracion_ms` está expresada en milisegundos porque Extended Events almacena la duración en microsegundos.

### Interpretación

| Resultado | Interpretación |
|---|---|
| `duracion_ms` alto y `cpu_ms` alto | El SP consume CPU |
| `duracion_ms` alto y `cpu_ms` bajo | Esperas, bloqueos, disco o red |
| Muchas `logical_reads` | Problema de índices, filtros o plan de ejecución |
| Un SP hijo cercano a 8 segundos | Principal candidato al cuello de botella |
| Padre de 8 segundos y varios hijos | El padre incluye el tiempo de sus hijos |

Importante: **no se debe sumar el tiempo del SP padre con el de los hijos**, porque el tiempo del padre incluye la ejecución de los hijos.

## 5. Verificar bloqueos durante la ejecución

Mientras la petición esté demorando, ejecutar desde otra sesión:

```sql
SELECT
    session_id,
    status,
    command,
    blocking_session_id,
    wait_type,
    wait_time,
    last_wait_type,
    cpu_time,
    total_elapsed_time,
    reads,
    writes,
    logical_reads,
    database_id,
    text AS sentencia
FROM sys.dm_exec_requests
CROSS APPLY sys.dm_exec_sql_text(sql_handle)
WHERE database_id = DB_ID(N'Ospecon_Prod')
```

Si aparece:

```text
blocking_session_id <> 0
```

el tiempo no necesariamente se está consumiendo dentro del código del SP, sino esperando a otra sesión.
