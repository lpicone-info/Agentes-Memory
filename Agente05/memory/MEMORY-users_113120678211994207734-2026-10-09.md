# 10. Evento `NavigationError`

El control WebBrowser dispone del evento:

```text
NavigationError
```

Argumentos:

```text
errorCode
errorText
failedUrl
```

Código:

```powerscript
IF PARENT.ib_cerrando THEN
    RETURN
END IF

IF NOT PARENT.ib_error_mostrado THEN

    PARENT.ib_error_mostrado = TRUE

    mBox(PARENT, &
        'No fue posible acceder al análisis IA.' + &
        '~r~n' + &
        'Detalle: ' + errorText, &
        2, &
        1)

END IF

CLOSE(PARENT)
```

Este evento permite controlar:

- Servidor no disponible.
- Error de conexión.
- DNS no resuelto.
- Navegación cancelada.
- URL inaccesible.
- Otros errores del motor CEF.

## Precisión sobre errores HTTP 404 y 500

`NavigationError` controla errores del navegador, pero una respuesta HTTP `404` o `500` puede ser técnicamente una navegación exitosa que presenta una página de error.

Por eso debe probarse cómo responde HISMART:

- Si el CEF genera `NavigationError`, este evento alcanza.
- Si HISMART devuelve una página HTML de error, será necesario definir un control adicional.
- No recomiendo hacer un `HTTPClient.GET` previo sin probar, porque generaría una segunda petición y podría afectar URLs firmadas o sesiones de un solo uso.

# 12. Cierre del visor

En el evento `CloseQuery` o `Close`:

```powerscript
ib_cerrando = TRUE

IF IsValid(wb_hismart) THEN
    wb_hismart.StopNavigation()
    wb_hismart.Navigate('about:blank')
END IF

RETURN 0
```

Esto:

- Detiene solicitudes pendientes.
- Abandona la URL actual.
- Destruye el control cuando se cierra la ventana.
- Evita devolver información a la ventana madre.

## Límite funcional

Cerrar el control elimina la sesión activa del navegador de esa ventana, pero no garantiza cerrar una sesión remota del servidor HISMART.

Para cerrar una sesión remota se necesitaría:

- Endpoint de logout de HISMART, o
- mecanismo de expiración administrado por HISMART.

PRESMED no debe inventar ni enviar tokens de cierre.

# 3. No usar `GetFileSaveName` directamente

`WebBrowserSet` recibe una **carpeta**, no el nombre completo de destino:

```powerscript
WebBrowserSet('DownloadPath', ls_directorio)
```

Por eso este enfoque no es correcto:

```powerscript
GetFileSaveName(...)
```
