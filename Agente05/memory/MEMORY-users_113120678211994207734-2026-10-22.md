
La recuperación completa evita dejar datos antiguos en otras autorizaciones o prestaciones.

# 16. Alternativa si `OpenWithParm` no retorna el resultado

Si el tipo de ventana configurado en el proyecto no permite bloqueo modal, utilizar un evento en la ventana padre:

```text
ue_complementariedad_guardada
```

La ventana de edición recibiría una referencia o identificador de la ventana padre y publicaría:

```powerscript
PARENT.EVENT ue_complementariedad_guardada()
```

No recomiendo esta alternativa inicialmente. `Response! + CloseWithReturn` es más simple y reduce el riesgo de refrescos incompletos.
