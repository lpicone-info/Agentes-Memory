## 3. Recalcular el estado de la solicitud

Con el `soli_auto` obtenido, se debe ejecutar:

```sql
prs_solicitudes_auto_esta_actual
```

Ese procedimiento calcula:

- `G` si todavía existen prestaciones pendientes;
- `V` si queda alguna autorización en estado pendiente;
- `F` cuando no quedan autorizaciones pendientes.

Actualmente el procedimiento devuelve el estado, pero no actualiza por sí mismo `SOLICITUDES_AUTO`.

Por lo tanto, la solución más segura es crear un procedimiento transaccional específico que:

1. Lea el estado anterior.
2. Ejecute la misma evaluación de estado.
3. Actualice `SOLICITUDES_AUTO.soli_esta`.
4. Registre `modi_fecha`.
5. Devuelva:
   - `soli_auto`;
   - estado anterior;
   - estado nuevo.

Conceptualmente:

```text
@prm_sucur
@prm_auto
@out_soli_auto OUTPUT
@out_soli_esta_anterior OUTPUT
@out_soli_esta_nueva OUTPUT
```

Este procedimiento debe ejecutarse después de que la autorización ya fue confirmada.

## 8. Manejo de errores

### Si falla la grabación de la autorización

Debe hacerse rollback o mantenerse el tratamiento actual. No se notifica.

## Corrección importante sobre `DESTROY lds_auto`

La ubicación antes de:

```powerscript
DESTROY lds_auto
```

no es el mejor punto final para ejecutar la notificación.

La razón es que, cuando la autorización queda **Negada**, después del `DESTROY` todavía se ejecuta:

```powerscript
ll_ret = THIS.EVENT ue_carta_negacion()
```

Ese flujo puede:

- abrir la carta de negación;
- finalizarla;
- revertir el estado si la carta no se completa;
- habilitar posteriormente la impresión.

La notificación de una solicitud negada solamente debe enviarse cuando la carta esté finalizada. Por eso, el punto más seguro es:

```powerscript
COMMIT
SQLCA.AUTOCOMMIT = TRUE

mbox(THIS, ls_mensaje, 1, 0)

DESTROY lds_auto
DESTROY lds_auto_items

IF glob.of_get_permiso_rol('ANULA_AUTO') = 'S' THEN
    cb_baja.enabled = TRUE
END IF

ib_continuar_aceptar = TRUE

IF EVENT ue_gettipo() = 'P' THEN
    dw_prestac.object.esta.protect = '0'
END IF

ll_ret = THIS.EVENT ue_carta_negacion()

IF ll_ret < 0 THEN
    RETURN 1
END IF

// AQUÍ debe evaluarse y dispararse la notificación

IF ll_ret = 1 THEN
    THIS.TRIGGEREVENT('ue_imprimir')
END IF
```

Es decir: **después de `ue_carta_negacion()` y antes de `ue_imprimir`**.

Para una autorización autorizada, `ue_carta_negacion()` no genera una carta y el flujo continúa normalmente. Para una negada, se espera a que la carta haya sido validada.
