### [02/09/2026 13:42:26] Agente

Walter, la causa más probable está en `w_preview.srw`: el botón `cb_3.clicked` hace esto:

```powerscript
dw_imprimir.of_addheader_con_logo('',300,'',1)
dw_imprimir.SaveAs()
dw_imprimir.of_sacarheader_con_logo()
```

Ese `SaveAs()` abre el diálogo genérico y, cuando elegís PDF, usa la configuración PDF propia del DataWindow. Si la DW está con `export.pdf(method=0)`, intenta exportar por Distill/Ghostscript y devuelve `-1`. Por eso TXT funciona y PDF no.

La solución es forzar NativePDF antes del `SaveAs()`:

```powerscript
dw_imprimir.of_addheader_con_logo('',300,'',1)

dw_imprimir.Object.DataWindow.Export.PDF.NativePDF.UsePrintSpec = 'Yes'
dw_imprimir.Object.DataWindow.Export.PDF.Method = NativePDF!
dw_imprimir.Object.DataWindow.Export.PDF.NativePDF.PDFStandard = 1

IF dw_imprimir.SaveAs() <> 1 THEN
	MBox(THIS, 'No se pudo exportar el reporte.', 1, 0)
END IF

dw_imprimir.of_sacarheader_con_logo()
```

Evidencia del mismo patrón en la rama: `wr_auto_impresion.srw` ya fuerza `Export.PDF.Method = NativePDF!` antes de hacer `saveAs(..., PDF!, TRUE)`.

`exe_presmed/Source Infomedical/w_preview.srw`, evento `cb_3.clicked`.
