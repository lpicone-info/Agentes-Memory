Para conciliar un ítem no será suficiente con localizar el número de autorización. El proceso deberá verificar que la autorización sea única, se encuentre en un estado habilitado y corresponda funcionalmente con los datos facturados.

## 14.1 Estado original y resultado de validación

- código del estado original en PRESMED;
- descripción del estado original;
- resultado de la validación realizada por la integración;

- nivel de origen: ítem, afiliado o factura;
- motivo por el cual fue aceptada o descartada.

## 14.2 Condiciones para considerar válida una autorización

Una autorización podrá utilizarse para conciliar un ítem únicamente cuando se cumplan todas las condiciones siguientes:

1. Existe una única autorización para la clave informada.
2. Pertenece a la entidad correspondiente.
3. Su estado original se encuentra homologado como habilitado.
4. No está anulada, rechazada, cancelada ni dada de baja.
5. Se encuentra vigente para la fecha de prestación.
6. Corresponde al afiliado identificado.
7. Corresponde al prestador facturante o al prestador habilitado por la regla vigente.
8. Contiene el servicio facturado o su equivalencia homologada.
9. Dispone de cantidad o saldo suficiente, cuando aplique control de consumo.
10. Cumple cualquier otra condición vigente del motor de reglas.

## 14.7 Prioridad de búsqueda

Para cada ítem se aplicará:

1. Autorización del ítem.
2. Autorización del afiliado.
3. Autorización de la factura.
4. Resultado `NO_ENCONTRADA` cuando el servicio requiera autorización y ningún nivel aporte una referencia válida.

Si una autorización de mayor prioridad está informada pero es inválida, debe definirse si se permite continuar con el nivel siguiente.

### Regla recomendada

- Si la referencia está ausente, continuar con el nivel siguiente.
- Si está informada pero es inválida, no ocultar el error buscando otra autorización.
- Registrar el resultado correspondiente y enviar el caso al motor de reglas.

Esto evita que una autorización errónea informada en el ítem sea reemplazada silenciosamente por otra de la factura.
