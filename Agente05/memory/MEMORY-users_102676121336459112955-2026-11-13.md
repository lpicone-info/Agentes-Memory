### Resultado funcional

- Si se selecciona **Todos**, se envía `NULL` y no se filtra por Tipo Plan.

- El Tipo Plan no filtra directamente el tipo de email/SMS; filtra las solicitudes/autorizaciones según el tipo de subcuenta del contrato del afiliado.
