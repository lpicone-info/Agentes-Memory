La ventana carga previamente los CUPS de convenios existentes mediante el DataWindow `d_muestra_presta_existe_conve.srd`. El SQL utilizado es:

```sql
SELECT DISTINCT
       conve_prestaciones.conve,
       substring(convenios.deno, 1, 500) AS conve_deno,
       carti_convenios.prestad,
       carti_convenios.lugar,
       cartillas.deno,
       space(1) AS baja,
       substring(prestadores.ape_razon, 1, 500) + ', ' +
       substring(prestadores.nombre_abre, 1, 500) AS prestad_deno,
       conve_prestaciones.prestac,
       conve_prestaciones.concep,
       substring(prestaciones.prestac, 1, 10) + space(1) +
       substring(prestaciones.exten_deno, 1, 59) AS pres_deno,
       cartillas.carti,
       prestaciones.nomen,
       conve_prestaciones.baja_fecha
FROM conve_prestaciones,
     convenios,
     carti_convenios,
     cartillas,
     prestadores,
     prestad_lugares,
     prestaciones,
     carti_prestadores
WHERE carti_convenios.carti = cartillas.carti
  AND prestad_lugares.prestad = prestadores.prestad
  AND carti_convenios.conve = conve_prestaciones.conve
  AND carti_convenios.carti = carti_prestadores.carti
  AND carti_convenios.prestad = carti_prestadores.prestad
  AND carti_convenios.lugar = carti_prestadores.lugar
  AND carti_prestadores.prestad = prestad_lugares.prestad
  AND carti_prestadores.lugar = prestad_lugares.lugar
  AND conve_prestaciones.nomen = prestaciones.nomen
  AND conve_prestaciones.prestac = prestaciones.prestac
  AND carti_convenios.conve = convenios.conve
  AND carti_convenios.conve = :a_conve
  AND carti_convenios.carti = :a_carti
  AND carti_convenios.prestad = :a_prestad
  AND (
        carti_convenios.baja_fecha IS NULL
        OR carti_convenios.baja_fecha > GETDATE()
      )
  AND (
        conve_prestaciones.baja_fecha IS NULL
        OR CONVERT(date, conve_prestaciones.baja_fecha) =
           CONVERT(date, GETDATE())
      )
  AND convenios.base = 'N'
```
