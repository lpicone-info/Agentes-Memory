## 1. Objetivo

Actualmente solo existe:

```sql
AUTORIZACIONES.complementariedad_nro_caso CHAR(10) NULL
```

Pero el funcional necesita persistir tres datos independientes:

| Campo | Tipo | Significado |
|---|---|---|
| `complementariedad_radica_caso` | `CHAR(1)` | Decisión de radicar: `S`, `N` o todavía no gestionada |
| `complementariedad_nro_caso` | `CHAR(10)` | Número asignado por la EPS |
| `complementariedad_motivo` | `VARCHAR(100)` | Motivo por el cual no se radicó |

Contrato funcional:

```text
radica_caso = NULL
→ todavía no fue gestionada

radica_caso = S
→ número obligatorio
→ motivo vacío

radica_caso = N
→ número vacío
→ motivo informado
```

## 2. Decisión importante: no utilizar valor por defecto

No debe declararse:

```sql
DEFAULT 'N'
```

Porque `N` significa que el usuario tomó expresamente la decisión de no radicar.

Los registros históricos o todavía no gestionados deben permanecer:

```text
complementariedad_radica_caso = NULL
```

Así se pueden distinguir tres estados:

```text
NULL = pendiente
S    = radicado
N    = no radicado
```
