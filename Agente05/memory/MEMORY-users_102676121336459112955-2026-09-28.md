## Hallazgo principal

En este modelo, un convenio básico se identifica mediante:

```sql
CONVENIOS.base = 'S'
AND CONVENIOS.cate IS NULL
```

No debe utilizarse `CONVENIOS.tipo = 'B'`: en `PruebasCoreINFOMEDICAL`, `tipo` tiene valor `P`.


## Riesgo de compatibilidad

- La ventana actual le envía siete parámetros posicionales.
- El DataWindow espera aproximadamente 50 columnas.
- El nuevo resultado es plano y tiene una estructura completamente diferente.

La opción segura es crear:

## Resultado propuesto

Técnicamente no serían “parámetros de salida”, sino columnas del result set:

- Código y descripción del convenio.
- Código y descripción del nomenclador.
- Código CUPS.
- Descripción CUPS.
- Concepto de valorización.
- Valor o porcentaje unificado.
- Unidad de valorización.
- `CONVE_PRESTAC_VALORES.vigen_desde`.
- Estado del convenio.
- `CONVENIOS.baja_fecha`.
- `CONVENIOS.fecha_terminacion`.

Debe devolverse una fila por **CUPS y concepto**, porque un mismo CUPS puede tener Honorarios, Gastos, Anestesia, etc., con valores diferentes.

## SP propuesto

```sql
USE PruebasCoreINFOMEDICAL;
GO

CREATE OR ALTER PROCEDURE dbo.prs_conve_preval_resumen_basico_nit
(
    @prm_nit VARCHAR(15)
)
AS
BEGIN
    SET NOCOUNT ON;
    SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED;

    DECLARE
        @var_prestad  INTEGER,
        @var_cantidad INTEGER;

    /*
        1. Obtener el código interno del prestador mediante el NIT.
    */
    SELECT
        @var_prestad  = MIN(P.prestad),
        @var_cantidad = COUNT(*)
    FROM dbo.PRESTADORES P
    WHERE LTRIM(RTRIM(P.cuit)) = LTRIM(RTRIM(@prm_nit));

    IF ISNULL(@var_cantidad, 0) = 0
    BEGIN
        RAISERROR(
            'No existe un prestador para el NIT informado.',
            16,
            1
        );
        RETURN;
    END;

    IF @var_cantidad > 1
    BEGIN
        RAISERROR(
            'Existe más de un prestador para el NIT informado.',
            16,
            1
        );
        RETURN;
    END;

    /*
        2. Recuperar únicamente convenios básicos asociados al prestador.

        Se utiliza EXISTS para evitar repetir prestaciones cuando el mismo
        convenio está asociado al prestador mediante varias cartillas.
    */
    SELECT
        prestador_codigo          = @var_prestad,
        prestador_nit             = LTRIM(RTRIM(@prm_nit)),

        convenio_codigo           = C.conve,
        convenio_descripcion      = C.deno,

        nomenclador_codigo        = N.nomen,
        nomenclador               = N.exten_deno,

        codigo_prestacion         = RTRIM(CP.prestac),
        descripcion_prestacion    = P.exten_deno,

        concepto_codigo           = CO.concep,
        concepto_valorizacion     = CO.deno,

        /*
            Unifica en una columna los diferentes mecanismos de
            valorización utilizados por el SP original.
        */
        valor_prestacion =
            CASE
                WHEN ISNULL(V.hono_espe,  0) > 0 THEN V.hono_espe
                WHEN ISNULL(V.valor_uni,   0) > 0 THEN V.valor_uni
                WHEN ISNULL(V.valor_multi, 0) > 0 THEN V.valor_multi
                WHEN ISNULL(V.valor,       0) > 0 THEN V.valor
                WHEN ISNULL(V.porce_menos, 0) > 0 THEN V.porce_menos
                WHEN ISNULL(V.porce_mas,   0) > 0 THEN V.porce_mas
                ELSE NULL
            END,

        unidad_valorizacion =
            CASE
                WHEN ISNULL(V.hono_espe,  0) > 0 THEN '%HE'
                WHEN ISNULL(V.valor_uni,   0) > 0 THEN '$U'
                WHEN ISNULL(V.valor_multi, 0) > 0 THEN '*'
                WHEN ISNULL(V.valor,       0) > 0 THEN '$'
                WHEN ISNULL(V.porce_menos, 0) > 0 THEN '%-'
                WHEN ISNULL(V.porce_mas,   0) > 0 THEN '%+'
                ELSE NULL
            END,

        valor_vigen_desde         = V.vigen_desde,

        estado_convenio =
            CASE
                WHEN C.baja_fecha IS NOT NULL
                    THEN 'BAJA'
                WHEN C.fecha_terminacion < CONVERT(DATE, GETDATE())
                    THEN 'TERMINADO'
                ELSE 'ACTIVO'
            END,

        convenio_baja_fecha       = C.baja_fecha,
        convenio_fecha_terminacion = C.fecha_terminacion

    FROM dbo.CONVENIOS C

    INNER JOIN dbo.CONVE_PRESTACIONES CP
        ON CP.conve = C.conve
       AND CP.baja_fecha IS NULL

    INNER JOIN dbo.PRESTACIONES P
        ON P.nomen  = CP.nomen
       AND P.prestac = CP.prestac

    INNER JOIN dbo.NOMENCLADORES N
        ON N.nomen = CP.nomen

    INNER JOIN dbo.CONCEPTOS CO
        ON CO.concep = CP.concep

    /*
        Recupera la última vigencia activa, no futura, para cada
        prestación/concepto.
    */
    OUTER APPLY
    (
        SELECT TOP (1)
            CPV.vigen_desde,
            CPV.valor,
            CPV.valor_uni,
            CPV.valor_multi,
            CPV.porce_mas,
            CPV.porce_menos,
            CPV.hono_espe
        FROM dbo.CONVE_PRESTAC_VALORES CPV
        WHERE CPV.conve_prestac = CP.conve_prestac
          AND CPV.baja_fecha IS NULL
          AND CPV.vigen_desde <= CONVERT(DATE, GETDATE())
        ORDER BY CPV.vigen_desde DESC
    ) V

    WHERE C.base = 'S'
      AND C.cate IS NULL

      AND EXISTS
      (
          SELECT 1
          FROM dbo.CARTI_CONVENIOS CC
          WHERE CC.conve   = C.conve
            AND CC.prestad = @var_prestad
            AND (
                   CC.baja_fecha IS NULL
                OR CC.baja_fecha > GETDATE()
            )
      )

    ORDER BY
        C.conve,
        N.exten_deno,
        CP.prestac,
        CP.concep;
END;
GO
```
