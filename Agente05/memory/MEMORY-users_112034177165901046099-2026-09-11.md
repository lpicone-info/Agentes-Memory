**Procedimiento completo propuesto**

```sql
IF OBJECT_ID('dbo.prs_auto_api_no_subidas') IS NOT NULL
  DROP PROCEDURE dbo.prs_auto_api_no_subidas
GO

CREATE PROCEDURE dbo.prs_auto_api_no_subidas
(
    @prm_desde DATETIME,
    @prm_hasta DATETIME
)
AS
BEGIN

    SET NOCOUNT ON
    SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED

    SELECT
        A.auto,
        A.fecha,
        A.esta,
        A.opcion_impresion,
        CN.impre_fecha,
        CN.carta_negacion,
        A.sucur,
        A.tipo,
        A.origen,
        A.inte,
        A.contra

    FROM AUTORIZACIONES A

    LEFT JOIN CARTA_NEGACION CN
        ON CN.sucur = A.sucur
       AND CN.auto = A.auto
       AND CN.baja_fecha IS NULL

    WHERE A.fecha >= CONVERT(DATE, @prm_desde)
      AND A.fecha < DATEADD(DAY, 1, CONVERT(DATE, @prm_hasta))

      AND
      (
          A.esta = 'A'
          OR
          (
              A.esta = 'N'
              AND CN.final_fecha IS NOT NULL
          )
      )

      AND A.baja_fecha IS NULL

      AND ISNULL(A.archivo_path_full, '') = ''

      AND EXISTS
      (
          SELECT 1
          FROM AUTO_PRESTAC_ITEMS API
          WHERE API.sucur = A.sucur
            AND API.auto = A.auto
            AND API.nivel = 2
            AND API.baja_fecha IS NULL
      )

    ORDER BY A.auto

    OPTION (RECOMPILE)

END
GO
```

El filtro de CUPS se implementa con `EXISTS` para evitar duplicar autorizaciones cuando una misma autorización tiene más de un CUPS de nivel 2. Esto también ayuda a reducir el volumen procesado por la ventana.
