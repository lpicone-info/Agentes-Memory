# 2. Verificar `wf_refrescar_post_auditoria`

Debe conservar esta lógica:

```powerscript
public subroutine wf_refrescar_post_auditoria ();

STRING ls_soli_esta_actual
STRING ls_soli_esta_grilla
LONG ll_row

DECLARE soli_auto_esta_actual PROCEDURE FOR &
    dbo.prs_solicitudes_auto_esta_actual &
    @prm_soli_auto = :idc_soli_auto_refrescar, &
    @prm_echo      = 'S' &
USING SQLCA;

EXECUTE soli_auto_esta_actual;

IF SQLCA.SQLCode <> 0 THEN

    MBox( &
        THIS, &
        'prs_solicitudes_auto_esta_actual', &
        2, &
        0)

    CLOSE soli_auto_esta_actual

    RETURN
END IF

FETCH soli_auto_esta_actual INTO &
    :ls_soli_esta_actual;

IF SQLCA.SQLCode <> 0 THEN
    CLOSE soli_auto_esta_actual
    RETURN
END IF

CLOSE soli_auto_esta_actual

ll_row = dw_lista.Find( &
    'soli_auto = ' + &
    String(idc_soli_auto_refrescar), &
    1, &
    dw_lista.RowCount())

IF ll_row > 0 THEN

    ls_soli_esta_grilla = &
        dw_lista.GetItemString( &
            ll_row, &
            'soli_esta')

    IF ls_soli_esta_actual <> &
       ls_soli_esta_grilla THEN

        wf_retrieve()

        ll_row = 0

        IF dw_lista.RowCount() > 0 THEN

            ll_row = dw_lista.Find( &
                'soli_auto = ' + &
                String(idc_soli_auto_refrescar), &
                1, &
                dw_lista.RowCount())

        END IF

        IF ll_row > 0 THEN

            idc_soli_auto = &
                idc_soli_auto_refrescar

            dw_lista.SetRow(ll_row)

            dw_lista.SelectRow( &
                0, &
                FALSE)

            dw_lista.SelectRow( &
                ll_row, &
                TRUE)

            wf_inhab_tabs(TRUE)

            idw_detalle.Retrieve( &
                idc_soli_auto)

            idw_auto.Retrieve( &
                idc_soli_auto)

            IF tab_1.tabpage_auto_auditoria.Enabled THEN

                idw_auto_auditoria.Retrieve( &
                    idc_soli_auto)

            END IF

        ELSE

            wf_limpia_solicitud_seleccionada()

        END IF

        RETURN
    END IF

END IF

// El estado no cambió, pero se actualiza la ficha.
idc_soli_auto = idc_soli_auto_refrescar

idw_auto.Retrieve( &
    idc_soli_auto)

IF tab_1.tabpage_auto_auditoria.Enabled THEN

    idw_auto_auditoria.Retrieve( &
        idc_soli_auto)

END IF

end subroutine
```

```powerscript
CASE 'b_editar_complementariedad'

    IF row <= 0 THEN
        RETURN
    END IF

    lstr_auto.sucur = &
        THIS.GetItemNumber( &
            row, &
            'sucur')

    lstr_auto.auto = &
        THIS.GetItemNumber( &
            row, &
            'auto')

    IF IsNull(lstr_auto.sucur) OR &
       IsNull(lstr_auto.auto) OR &
       lstr_auto.sucur <= 0 OR &
       lstr_auto.auto <= 0 THEN

        MessageBox( &
            'Gestión de complementariedad', &
            'No fue posible identificar la autorización.', &
            StopSign!)

        RETURN
    END IF

    Message.DoubleParm = 0

    OpenWithParm( &
        wp_complementariedad_auto, &
        lstr_auto)

    li_resultado = &
        Integer(Message.DoubleParm)

    IF li_resultado = 1 THEN

        PARENT.PARENT.PARENT.EVENT &
            ue_refrescar_auto()

    END IF

    RETURN
```

## Resultado

```text
Guardar exitosamente
→ CloseWithReturn(THIS, 1)
→ li_resultado = 1
→ ue_refrescar_auto
→ wf_refrescar_post_auditoria
→ actualiza dw_lista si cambió el estado
```

Si se pulsa Salir o Cancelar:


y no se ejecuta un refresco innecesario.

# 8. No recuperar siempre `dw_lista`

No recomiendo ejecutar incondicionalmente:

```powerscript
wf_retrieve()
```

cada vez que se cierra una ventana.

La función actual primero compara:

```text
estado en base
contra
estado mostrado en dw_lista
```

Esto evita:

- Consultas completas innecesarias.
- Saltos visuales de la lista.
- Pérdida innecesaria de la posición.
- Recargas cuando solamente cambió un número o motivo.

# 9. Matriz de pruebas

## Caso 1 — `V → G`

1. Buscar una solicitud en `Validación Auditoría`.
2. Abrir `Consultar Autorización`.
3. Negar la autorización.
4. Finalizar la carta.
5. Cerrar la autorización.

Esperado:

```text
dw_lista muestra En Gestión
```

Si el filtro era exclusivamente `Validación Auditoría`:

```text
La solicitud desaparece
```

## Caso 2 — Complementariedad incompleta

1. Abrir una solicitud en `G`.
2. Gestionar una autorización.
3. Todavía quedan otras pendientes.

Esperado:

```text
La solicitud permanece en G
La fila continúa seleccionada
Se actualizan los campos de autorización
```

## Caso 3 — Última autorización `G → F`

1. Gestionar la última autorización pendiente.
2. Guardar.

Esperado:

```text
La solicitud cambia a Finalizada
dw_lista se actualiza
```

Si el filtro mostraba únicamente Gestión:

```text
La solicitud desaparece
Se limpia la ficha derecha
```

## Caso 4 — Cancelar complementariedad

1. Abrir la ventana.
2. Modificar.
3. Salir descartando cambios.

Esperado:

```text
No se refresca la lista
El estado permanece igual
```

## Caso 5 — Error de guardado

Esperado:

```text
La ventana permanece abierta
No se refresca dw_lista
```

## Caso 6 — Estado Todos

Esperado:

```text
La solicitud continúa visible
Muestra el nuevo estado
Mantiene seleccionada la misma fila
```
