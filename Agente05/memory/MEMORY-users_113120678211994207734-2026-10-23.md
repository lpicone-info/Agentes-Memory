# Contrato del procedimiento

```

```

## Regla de edición

`editable_complementariedad = 'S'` únicamente cuando:

- La solicitud está marcada para complementariedad.
- La solicitud se encuentra en estado `G`.
- La autorización está negada.
- La autorización está vigente.
- La carta de negación está finalizada.
- La EPS está parametrizada como `O` o `L`.
- El plan vigente está parametrizado con `S`.
- El tipo de solicitud está parametrizado con `S`.

## Normalización de `RADICA CASO`

```text
Valor almacenado S/N       → conserva el valor
Valor NULL con número      → devuelve S
Valor NULL sin número      → devuelve N
```

Esta normalización permite que el checkbox del futuro DataWindow siempre reciba `S` o `N`.

## Control de duplicados

El procedimiento no relaciona prestaciones y resuelve mediante `APPLY`:

- Una solicitud vigente.
- Una EPS.
- El plan vigente más reciente.
- La existencia de carta finalizada.

Si una autorización tuviera más de una asociación vigente, prioriza:

1. Solicitud en estado `G`.
2. Asociación modificada más recientemente.
3. Número de solicitud más alto.

# 7. Programar el evento `Open`

Crear o modificar el evento:

```text
Open
```

El patrón utilizado por el proyecto es:

```powerscript
event open;call super::open;
```

El código debe quedar:

```powerscript
event open;call super::open;

LONG ll_filas

ib_cargando = TRUE

istr_auto = Message.PowerObjectParm

IF istr_auto.sucur <= 0 OR &
   istr_auto.auto <= 0 THEN

    MessageBox( &
        'Gestión de complementariedad', &
        'No se recibió una autorización válida.', &
        StopSign!)

    Close(THIS)
    RETURN
END IF

ll_filas = dw_complementariedad.Retrieve( &
    istr_auto.sucur, &
    istr_auto.auto)

IF ll_filas < 0 THEN

    MessageBox( &
        'Gestión de complementariedad', &
        'No fue posible consultar los datos de complementariedad.' + &
        '~r~nCódigo SQL: ' + String(SQLCA.SQLCode) + &
        '~r~nMensaje: ' + SQLCA.SQLErrText, &
        StopSign!)

    Close(THIS)
    RETURN
END IF

IF ll_filas = 0 THEN

    MessageBox( &
        'Gestión de complementariedad', &
        'La autorización no tiene información disponible para editar.', &
        Exclamation!)

    Close(THIS)
    RETURN
END IF

ib_cargando = FALSE

dw_complementariedad.SetRow(1)
dw_complementariedad.SetColumn( &
    'complementariedad_radica_caso')

end event
```

## Importante sobre `Message.PowerObjectParm`

Este patrón ya se utiliza en el proyecto para recibir estructuras:

```powerscript
istr_auto = Message.PowerObjectParm
```

No uses:

```powerscript
Message.StringParm
```

porque el parámetro recibido no es una URL ni una cadena: es una estructura `str_auto`.

# 10. Actualizar dinámicamente la protección

Las expresiones `Protect` del DataWindow determinan el estado inicial, pero después de cambiar el checkbox necesitamos volver a evaluar los campos.

Agregar una función local en la ventana:

```powerscript
public function integer wf_actualizar_proteccion ()
```

Código:

```powerscript
public function integer wf_actualizar_proteccion ();

STRING ls_editable
STRING ls_radica

IF dw_complementariedad.RowCount() <= 0 THEN
    RETURN -1
END IF

ls_editable = dw_complementariedad.GetItemString( &
    1, &
    'editable_complementariedad')

ls_radica = dw_complementariedad.GetItemString( &
    1, &
    'complementariedad_radica_caso')

IF IsNull(ls_editable) OR &
   Trim(ls_editable) = '' THEN

    ls_editable = 'N'
END IF

IF IsNull(ls_radica) OR &
   Trim(ls_radica) = '' THEN

    ls_radica = 'N'
END IF

IF ls_editable = 'S' THEN

    dw_complementariedad.Modify( &
        'complementariedad_radica_caso.Protect=0')

    IF ls_radica = 'S' THEN

        dw_complementariedad.Modify( &
            'complementariedad_nro_caso.Protect=0')

        dw_complementariedad.Modify( &
            'complementariedad_motivo.Protect=1')

    ELSE

        dw_complementariedad.Modify( &
            'complementariedad_nro_caso.Protect=1')

        dw_complementariedad.Modify( &
            'complementariedad_motivo.Protect=0')

    END IF

ELSE

    dw_complementariedad.Modify( &
        'complementariedad_radica_caso.Protect=1')

    dw_complementariedad.Modify( &
        'complementariedad_nro_caso.Protect=1')

    dw_complementariedad.Modify( &
        'complementariedad_motivo.Protect=1')

END IF

RETURN 1

end function
```

- Motivo.

# 19. Criterio de cierre

La ventana queda lista cuando:

- Recibe una estructura `str_auto`.
- Recupera una única autorización.
- Muestra los valores del SP.
- El checkbox se habilita solo cuando corresponde.
- El número se habilita únicamente con `RADICA CASO = S`.
- El motivo se habilita únicamente con `RADICA CASO = N`.
- El cambio del checkbox limpia el campo contrario.
- `Cancelar` cierra devolviendo `0`.
- `Guardar` cierra temporalmente devolviendo `1`.
- No ejecuta todavía ningún guardado en base de datos.
- No utiliza `DataWindow.Update()`.

El siguiente paso será crear el SP transaccional `pru_guardar_complementariedad.sql` y reemplazar el `CloseWithReturn(THIS, 1)` temporal por el guardado real.
