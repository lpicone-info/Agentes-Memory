### 1. Selección determinística del primer detalle activo

El código anterior actualizaba `#SOLI_AUTO` mediante un `INNER JOIN` directo:

```sql
UPDATE #SOLI_AUTO
SET prestad = APCD.prestad,
    lugar   = APCD.lugar
FROM #SOLI_AUTO T
INNER JOIN AUTO_PRESTAC_CIRU_DETALLE APCD
    ON T.sucur = APCD.sucur
```
