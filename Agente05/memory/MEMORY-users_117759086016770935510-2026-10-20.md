## Consideración importante

No siempre el partido geográfico del lugar es una sucursal comercializable.

Presmed determina la sucursal así:

```sql
CASE
    WHEN PARTIDOS.comercializable = 'S'
        THEN PARTIDOS.partido
    ELSE PARTIDOS.sucu_comercializa
```

Por eso no conviene comparar directamente:


## Consulta geográfica recomendada

Esta consulta obtiene prestadores con lugares vigentes para una regional y sucursal:

```sql
DECLARE @regional SMALLINT = 10;     -- LIQUI_OFICINAS.ofi
DECLARE @sucursal CHAR(5) = 'XXXXX'; -- PARTIDOS.partido
DECLARE @fecha DATETIME = GETDATE();

WITH Lugares AS
(
    SELECT
        p.prestad,
        p.ape_razon,
        p.nombre_abre,
        pl.lugar,
        pl.nombre AS nombre_lugar,
        pl.domi,
        pl.loca,
        l.deno AS localidad,
        pg.partido AS partido_geografico,
        CASE
            WHEN pg.comercializable = 'S'
                THEN pg.partido
            ELSE pg.sucu_comercializa
        END AS sucursal_comercial
    FROM prestadores p
    INNER JOIN prestad_lugares pl
        ON pl.prestad = p.prestad
    INNER JOIN localidades l
        ON l.loca = pl.loca
    INNER JOIN partidos pg
        ON pg.partido = l.partido
    WHERE ISNULL(p.baja_fecha, '20500101') > @fecha
      AND ISNULL(p.recu_fecha, '19000101') <= @fecha
      AND ISNULL(p.inhab_fecha, '20500101') > @fecha

      AND ISNULL(pl.baja_fecha, '20500101') > @fecha
      AND ISNULL(pl.recu_fecha, '19000101') <= @fecha
      AND pl.vigen_desde <= @fecha
      AND pl.vto_habi_sani > @fecha

      AND l.baja_fecha IS NULL
      AND pg.baja_fecha IS NULL
)
SELECT
    l.prestad,
    l.ape_razon,
    l.nombre_abre,
    l.lugar,
    l.nombre_lugar,
    l.domi,
    l.localidad,
    suc.partido AS sucursal,
    suc.descripcion AS sucursal_descripcion,
    lo.ofi AS regional,
    lo.deno AS regional_descripcion
FROM Lugares l
INNER JOIN partidos suc
    ON suc.partido = l.sucursal_comercial
INNER JOIN liqui_oficinas lo
    ON lo.ofi = suc.regional
WHERE suc.partido = @sucursal
  AND suc.regional = @regional
  AND suc.comercializable = 'S'
  AND suc.baja_fecha IS NULL
  AND lo.baja_fecha IS NULL
ORDER BY
    l.ape_razon,
    l.nombre_abre,
    l.lugar;
```

Esta consulta devuelve un registro por **prestador y lugar**. Si solamente necesitas prestadores únicos, utiliza:

```sql
SELECT DISTINCT
    l.prestad,
    l.ape_razon,
    l.nombre_abre
```

## Si “habilitado” también exige contrato regional

La ubicación vigente no garantiza que el prestador tenga un contrato habilitado para esa regional. En ese caso debe agregarse:

```sql
AND EXISTS
(
    SELECT 1
    FROM prestadores_contratos pc
    INNER JOIN prestad_contra_rel_liqui_oficinas pclo
        ON pclo.prestad_contra = pc.prestad_contra
    WHERE pc.prestad = l.prestad
      AND pc.estado = 'A'
      AND pc.fecha_inicio <= @fecha
      AND pc.fecha_fin >= @fecha
      AND pc.baja_fecha IS NULL
      AND pclo.ofi = @regional
      AND pclo.baja_fecha IS NULL
)
```

La interpretación sería:

| Nivel | Validación |
|---|---|
| Ubicación | Tiene un `PRESTAD_LUGARES` vigente en la sucursal |
| Prestador | No está retirado ni inhabilitado |
| Regional | La sucursal pertenece a `LIQUI_OFICINAS.ofi` |
| Contrato | Tiene contrato activo relacionado con esa oficina |
| Servicio específico | Además debe verificarse convenio, cartilla, CUPS y plan |
