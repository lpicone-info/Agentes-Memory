# Regla funcional confirmada

La solicitud permanece en `G` cuando existe alguna autorización activa que:

- No está en `A`, `N` o `U`.
- Está negada pero no tiene carta finalizada.
- Está negada y no tiene definida la decisión `RADICA CASO`.
- Tiene `RADICA CASO = S` pero no tiene número.

Puede finalizar cuando todas las autorizaciones activas están resueltas:

```text

N = Negada
U = Anulada
```

Para una autorización negada:

```text

RADICA = N → número vacío; motivo opcional
```
