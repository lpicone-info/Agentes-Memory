  2. Consulta autorizaciones asociadas.
  3. Por cada autorizacion: reutiliza `AUTORIZACIONES.archivo_path_full` si existe; si no existe, genera PDF, lo sube a API y actualiza `archivo_path_full`.
  4. Arma XML con PDFs generados/reutilizados.
  5. Llama una sola vez a `pri_solicitudes_auto_notif` pasando el XML.
  6. El SP crea mail, inserta `MAIL_ATTACH_BINARY` y luego marca pendiente con `afu_mail_envio_send`.
