## Cómo se configura

La ventana genera las columnas esperadas para el archivo y permite informar:

| Campo | Uso |
|---|---|
| Columna | Nombre lógico; lo determina la aplicación |
| Posición | Posición inicial en cada línea |
| Longitud | Cantidad de caracteres |
| Tipo | `E` decimal, `S` texto, `N` numérico, `D` fecha |
| Observación | Descripción y obligatoriedad del campo |

Existe un botón **Calcular posición**, que ordena automáticamente las posiciones según la longitud de cada campo.

Validaciones principales:

- Debe existir al menos un campo con posición y longitud.
- Si se informa longitud, debe existir posición.
- Si se informa posición, debe existir longitud.
- Una fecha debe tener longitud mínima de 8.
- Los campos marcados como obligatorios no pueden excluirse con posición cero.

Al aceptar, ejecuta `pru_homolog_formatos`, que hace `INSERT` o `UPDATE`, reactiva registros dados de baja y confirma con `COMMIT`.

Para este flujo guarda con:

```text
enti_tipo = 'P'
enti_codi = código del prestador
archi     = 100
```

## ¿Quién llena la configuración?

La completa manualmente un usuario con acceso a esa opción:

- La aplicación genera automáticamente la lista de columnas esperadas desde `d_import_exp_homolog_prest`.
- El usuario informa principalmente **posición** y **longitud**.
- El tipo y la descripción se derivan de la estructura del DataWindow.
- Puede utilizar **Calcular posición**.
- Al aceptar, se guardan los registros mediante `pru_homolog_formatos`.

Si el prestador aún no tiene formato:

- La ventana presenta las columnas con posición y longitud en cero.
- No quedan asociadas hasta que el usuario complete y guarde.
- Al intentar importar sin configuración, aparece:

> “No hay formato de importación definido para este prestador.”
