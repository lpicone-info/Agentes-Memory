**Causa**

El SP construye `deno_error` así:

```sql
STUFF(
  (
    SELECT ' | ' + ISNULL(recha_deno, '')
    FROM TRANSAC_VALOR_CUPS_LOG
    WHERE nro_transaccion = T.nro_transaccion
      AND nomen = T.nomen
      AND prestac = T.prestac
      AND (recha IS NULL OR recha NOT IN (12,1369))
    FOR XML PATH('')
  ),
  1,
  3,
  ''
)
```

Para la transacción `539` existen **dos filas** para nomenclador `30` y CUPS `890383A`. Ambas tienen `recha_deno` vacío:

```text
[ ]
[ ]
```

Por eso la concatenación genera:

```text
' | ' + '' + ' | ' + '' = ' |  | '
```

`STUFF` elimina únicamente el primer separador y queda:

```text
' | '
```

Por lo tanto, el PIPE no proviene del CUPS ni de los parámetros enviados: se genera por concatenar filas con `recha_deno` vacío.
