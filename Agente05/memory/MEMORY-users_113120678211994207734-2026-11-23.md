# Si Funcional exige controlar XML sintácticamente inválido

Si Funcional pretende enviar exactamente:

```xml
<nombre>/nombre>
```

y recibir un error funcional del wrapper, entonces el parámetro no puede continuar siendo de tipo `XML`.

Debe recibirse como texto y convertirse dentro del procedimiento.

## Paso 1 — Cambiar el parámetro

Antes:

```sql
@prm_adjuntos XML,
```

Después:

```sql
@prm_adjuntos NVARCHAR(MAX),
```

## Paso 2 — Declarar una variable XML interna

Agregar al bloque `DECLARE`:

```sql
@var_adjuntos XML,
```

Por ejemplo:

```sql
DECLARE	@var_error			SMALLINT		= NULL,
		@var_deno_error		VARCHAR(1024)	= NULL,
		@var_adjuntos		XML,
		...
```

# Opción 2 — Migrar de CEF a WebView2 Evergreen

Si Funcional exige mantener el visor dentro de PRESMED, la alternativa técnica es actualizar el runtime a **PowerBuilder 2022 R2/R3, build 2797 o posterior**, donde el control `WebBrowser` utiliza Microsoft Edge WebView2.

Appeon cambió el motor CEF por WebView2 a partir de PowerBuilder 2022 R2. [Documentación oficial](https://docs.appeon.com/pb/upgrading_pb_apps/WebBrowser_engine_changes.html).

## Modo adecuado

Utilizar:

```text
WebView2 Evergreen Runtime
```

En ese modo se distribuyen solamente los componentes de integración de PowerBuilder:

```text
pbwebbrowser.dll
webbrowserapi.tlb
```

No se distribuye la carpeta grande `PBWebView2`; esa carpeta solo es necesaria para el modo **Fixed Version**. [Archivos runtime de PB 2022 R3](https://docs.appeon.com/pb2022r3/application_techniques/PowerBuilder_runtime_files.html).

El motor WebView2 queda instalado y actualizado centralmente en Windows, normalmente junto con Microsoft Edge.

## Impacto

- Migrar IDE y runtime al mismo build.
- Realizar Full Build de la aplicación.
- Actualizar el runtime en todos los equipos.
- Verificar que WebView2 Evergreen esté instalado.
- Probar proxy, certificados y políticas corporativas.
- Regresar `Navigate`, descargas y eventos del control.
- Eliminar la lógica de `pbcef.zip`.

El `DownloadPath` utilizado actualmente está soportado por WebView2, por lo que gran parte de `wp_visor_hismart` puede conservarse. [Configuración WebBrowser](https://docs.appeon.com/pb2022r2/pbug/ch04s05s03.html).

## Riesgo

Aunque elimina `pbcef.zip`, sigue dependiendo de un runtime externo. Si Coomeva bloquea o elimina WebView2, reaparecerá un problema de instalación, aunque mucho más estándar y administrable que CEF.
