## 11. Clave funcional de duplicidad

**Estado: parcialmente definido.**

La EF utiliza dos controles distintos:

### Duplicidad de factura

```text

+ numero_identificacion_ips
+ numero_factura
```

### Duplicidad física del archivo

```text
hash_archivo
```

Esto es razonable, pero la secuencia técnica también menciona “proveedor + factura + fecha o hash”, introduciendo una contradicción.

### Regla recomendada

- **Mismo hash:** mismo archivo físico.
- **Misma entidad, prestador y factura:** misma factura de negocio.
- **Misma factura con contenido diferente:** posible corrección o conflicto, no duplicado simple.
- La fecha de factura no debería permitir duplicar una factura con el mismo prestador y número.

La clave debe incluir entidad si un prestador puede operar en más de una.

## 12. Alcance del rechazo de un ítem

**Estado: parcialmente definido.**

La EF establece que una inconsistencia de negocio no debe impedir automáticamente la integración. También exige registrar resultados por ítem. Sin embargo, declara que archivo, factura y expediente forman una única transacción.

Esto genera una contradicción entre atomicidad total y procesamiento parcial.

### Regla recomendada

- Error sintáctico o estructural: rechaza el archivo completo.
- Error de cabecera o prestador: rechaza la factura.
- Afiliado no identificable: afecta ese afiliado y sus ítems.
- Error de conciliación de un ítem: afecta solo ese ítem.
- La factura queda `PROCESADA_CON_INCONSISTENCIAS` cuando al menos un ítem presenta diferencias.

Para soportarlo, la transacción no puede tratar cualquier inconsistencia funcional como rollback total.

## 23. Nivel de reproceso

**Estado: no definido.**

La EF indica que el reproceso crea un nuevo intento y no duplica información exitosa, pero no define el nivel.

Con el modelo transaccional actual, el reproceso natural sería **por archivo**. Para reprocesar factura, afiliado o ítem se necesita:

- idempotencia por nivel;
- estados independientes;
- relación con el intento;
- preservación del resultado anterior;
- control de concurrencia;
- reglas sobre qué datos se recalculan.
