# Procesos que puede generar una solicitud

El procedimiento determina el proceso de notificación así:

| Condición | Proceso |
|---|---:|
| Solicitud originada por prestador GIS | `23` |
| Todas las autorizaciones en estado `A` | `8` |
| Todas las autorizaciones en estado `N` | `9` |
| Autorizaciones mezcladas `A` y `N` | `13` |
| Solicitud originada por prestador funcional | También puede existir proceso `5` |

Por lo tanto, no alcanza con revisar solamente si existe cualquier registro en `SOLICITUDES_AUTO_AUDITORIA`. Hay que verificar el proceso que corresponde a esa solicitud.

Ejemplo:

```text
Solicitud finalizada
Proceso calculado = 8
Auditoría proceso 8 existente
        ↓
No hay nada pendiente para enviar
```

Pero si:

```text
Proceso calculado = 8
Auditoría proceso 8 inexistente
        ↓
La notificación sí corresponde
```


Además, si se implementa incorrectamente, podría deshabilitarse el botón aunque todavía exista un proceso pendiente parcial.

### Conclusión sobre opción 1

Es útil como mejora de interfaz, pero no debe ser el único control.

# Diseño técnico recomendado

## 1. Crear un procedimiento de validación

Por ejemplo:

```text
prs_solicitud_auto_valida_notificacion
```

Debe recibir:

```text
@prm_soli_auto
```

Y devolver:

```text
aplica_notificacion
proceso_id
mensaje
```

Valores posibles:

| `aplica_notificacion` | Significado |
|---|---|
| `S` | Existe un proceso pendiente |
| `N` | No corresponde enviar nuevamente |

## 2. Regla del procedimiento

El procedimiento debe:

1. Verificar que la solicitud exista.
2. Verificar que esté en estado `F`.
3. Contar autorizaciones vigentes.
4. Clasificar el proceso:
   - `5`
   - `8`
   - `9`
   - `13`
   - `23`
5. Consultar `SOLICITUDES_AUTO_AUDITORIA`.
6. Devolver `S` si falta el proceso correspondiente.
7. Devolver `N` si ya está auditado.

La lógica conceptual sería:

```sql
IF @var_soli_esta <> 'F'
BEGIN
    SELECT
        aplica_notificacion = 'N',
        proceso_id = NULL,
        mensaje = 'La solicitud no está finalizada'
    RETURN
END
```

Luego, después de determinar el proceso:

```sql
IF EXISTS
(
    SELECT 1
    FROM SOLICITUDES_AUTO_AUDITORIA
    WHERE soli_auto = @prm_soli_auto
    AND activi LIKE '%proceso_id: ' + CONVERT(VARCHAR(10), @var_proceso) + '%'
)
BEGIN
    SELECT
        aplica_notificacion = 'N',
        proceso_id = @var_proceso,
        mensaje = 'No corresponde enviar nuevamente la notificación'
    RETURN
END
```

Si no existe la auditoría:

```sql
SELECT
    aplica_notificacion = 'S',
    proceso_id = @var_proceso,
    mensaje = ''
```

## 3. Llamar la validación antes de preparar PDF

En el evento del botón, el orden debe ser:

```text
Validar solicitud
        ↓
Validar si corresponde notificar
        ↓
Si no corresponde, mostrar mensaje y salir
        ↓
Preparar adjuntos
        ↓
Ejecutar reenvío
```

No se debe preparar el PDF antes de la validación, porque eso puede:

- Regenerar archivos innecesariamente.
- Subir archivos a la API sin necesidad.
- Generar residuos si luego el procedimiento no hace nada.

## 4. Mensaje funcional

Cuando ya exista la auditoría, mostrar:

```text
No corresponde enviar nuevamente la notificación de esta solicitud.
```

También puede diferenciarse el proceso:

```text
La notificación correspondiente al proceso 8 ya fue generada.
No corresponde enviarla nuevamente.
```

## 5. Mostrar éxito únicamente si hubo una acción real

Actualmente el mensaje:

```text
Proceso terminado con éxito.
```

se muestra después de ejecutar el SP, aunque el SP haya omitido el envío porque ya existía auditoría.

Debe mostrarse solamente cuando:

```text
aplica_notificacion = 'S'
y
el procedimiento de notificación finaliza correctamente
```

# Paso 1 — Crear el procedimiento de validación

Nombre propuesto:

```text
prs_solicitudes_auto_notif_aplica
```

Ubicación del archivo en el repositorio:

```text
backend/procedures/prs_solicitudes_auto_notif_aplica.sql
```

## Contrato

### Entrada

```text
@prm_soli_auto
```

### Salidas

| Parámetro | Descripción |
|---|---|
| `@prm_aplica` | `S` si existe algo pendiente; `N` si no corresponde |
| `@prm_proceso_id` | Proceso de afiliado calculado: `8`, `9`, `13` o `23` |
| `@prm_mensaje` | Motivo por el cual no corresponde procesar |

## Script completo propuesto

```sql
IF OBJECT_ID('dbo.prs_solicitudes_auto_notif_aplica') IS NOT NULL
    DROP PROCEDURE dbo.prs_solicitudes_auto_notif_aplica
GO

/*
    Procedure      : prs_solicitudes_auto_notif_aplica

    Creation Date  : <fecha>

    Programmer     : whiguera

    Description    : Determina si una solicitud finalizada tiene
                     notificaciones pendientes de generación.

    Reference      : Tarea #29489
*/

CREATE PROCEDURE dbo.prs_solicitudes_auto_notif_aplica
(
    @prm_soli_auto          NUMERIC(18,0),
    @prm_aplica             CHAR(1) = NULL OUTPUT,
    @prm_proceso_id         SMALLINT = NULL OUTPUT,
    @prm_mensaje            VARCHAR(500) = NULL OUTPUT
)
AS
BEGIN

    SET NOCOUNT ON

    DECLARE @var_soli_esta                   CHAR(1),
            @var_tipo_usuario                CHAR(1),
            @var_origen                      CHAR(1),
            @var_cantidad_autorizaciones     INT,
            @var_cantidad_aprobadas          INT,
            @var_cantidad_negadas            INT,
            @var_pendiente_prestador         CHAR(1),
            @var_pendiente_afiliado          CHAR(1)

    SET @prm_aplica = 'N'
    SET @prm_proceso_id = NULL
    SET @prm_mensaje = ''
    SET @var_pendiente_prestador = 'N'
    SET @var_pendiente_afiliado = 'N'

    SELECT
        @var_soli_esta = SA.soli_esta,
        @var_tipo_usuario = SA.tipo_usuario,
        @var_origen = SA.origen
    FROM dbo.SOLICITUDES_AUTO SA
    WHERE SA.soli_auto = @prm_soli_auto
    AND SA.baja_fecha IS NULL

    IF @var_soli_esta IS NULL
    BEGIN
        SET @prm_mensaje =
            'La solicitud indicada no existe o se encuentra dada de baja'

        RETURN
    END

    IF @var_soli_esta <> 'F'
    BEGIN
        SET @prm_mensaje =
            'La solicitud no se encuentra en estado Finalizada'

        RETURN
    END

    SELECT
        @var_cantidad_autorizaciones = COUNT(*),
        @var_cantidad_aprobadas =
            ISNULL(
                SUM(
                    CASE
                        WHEN A.esta = 'A' THEN 1
                        ELSE 0
                    END
                ),
                0
            ),
        @var_cantidad_negadas =
            ISNULL(
                SUM(
                    CASE
                        WHEN A.esta = 'N' THEN 1
                        ELSE 0
                    END
                ),
                0
            )
    FROM dbo.SOLICITUDES_AUTO_AUTORIZACIONES SAA

    INNER JOIN dbo.AUTORIZACIONES A
        ON A.sucur = SAA.sucur
        AND A.auto = SAA.auto
        AND A.baja_fecha IS NULL

    WHERE SAA.soli_auto = @prm_soli_auto
    AND SAA.baja_fecha IS NULL

    IF @var_cantidad_autorizaciones = 0
    BEGIN
        SET @prm_mensaje =
            'La solicitud finalizada no tiene autorizaciones vigentes para notificar'

        RETURN
    END

    IF EXISTS
    (
        SELECT 1
        FROM dbo.SOLICITUDES_AUTO_AUTORIZACIONES SAA

        INNER JOIN dbo.AUTORIZACIONES A
            ON A.sucur = SAA.sucur
            AND A.auto = SAA.auto
            AND A.baja_fecha IS NULL

        WHERE SAA.soli_auto = @prm_soli_auto
        AND SAA.baja_fecha IS NULL
        AND ISNULL(A.esta, '') NOT IN ('A', 'N')
    )
    BEGIN
        SET @prm_mensaje =
            'La solicitud contiene autorizaciones en estados no notificables'

        RETURN
    END

    IF @var_origen = 'G'
    AND @var_tipo_usuario = 'P'
    BEGIN
        SET @prm_proceso_id = 23
    END
    ELSE IF @var_cantidad_aprobadas =
            @var_cantidad_autorizaciones
    BEGIN
        SET @prm_proceso_id = 8
    END
    ELSE IF @var_cantidad_negadas =
            @var_cantidad_autorizaciones
    BEGIN
        SET @prm_proceso_id = 9
    END
    ELSE IF @var_cantidad_aprobadas > 0
    AND @var_cantidad_negadas > 0
    BEGIN
        SET @prm_proceso_id = 13
    END

    IF @prm_proceso_id IS NULL
    BEGIN
        SET @prm_mensaje =
            'No fue posible determinar el proceso de notificación de la solicitud'

        RETURN
    END

    /*
        Si el origen funcional es prestador, debe existir
        la notificación del proceso 5.
    */
    IF @var_tipo_usuario = 'P'
    AND NOT EXISTS
    (
        SELECT 1
        FROM dbo.SOLICITUDES_AUTO_AUDITORIA
        WHERE soli_auto = @prm_soli_auto
        AND activi LIKE '%proceso_id: 5%'
    )
    BEGIN
        SET @var_pendiente_prestador = 'S'
    END

    /*
        Se valida el proceso correspondiente al afiliado:
        8, 9, 13 o 23.
    */
    IF NOT EXISTS
    (
        SELECT 1
        FROM dbo.SOLICITUDES_AUTO_AUDITORIA
        WHERE soli_auto = @prm_soli_auto
        AND activi LIKE
            '%proceso_id: '
            + CONVERT(VARCHAR(10), @prm_proceso_id)
            + '%'
    )
    BEGIN
        SET @var_pendiente_afiliado = 'S'
    END

    IF @var_pendiente_prestador = 'S'
    OR @var_pendiente_afiliado = 'S'
    BEGIN
        SET @prm_aplica = 'S'
        SET @prm_mensaje = ''

        RETURN
    END

    SET @prm_aplica = 'N'
    SET @prm_mensaje =
        'No corresponde enviar nuevamente la notificación de esta solicitud.'

END
GO
```
