Para RM30414 recomendaría separar la **identidad de la factura** del control del archivo.

## Clave única de negocio propuesta

```text
tipo_identificacion_ips
+ numero_identificacion_ips
+ numero_factura
```

Ejemplo:

```text
NIT|901456782|FE-2026-004587
```

Esta combinación identifica la factura dentro del prestador, independientemente del nombre del archivo.

En SQL podría aplicarse:

```sql
UNIQUE (
    tipo_identificacion_ips,
    numero_identificacion_ips,
    numero_factura
)
```

## Control adicional mediante hash

La clave de negocio no alcanza para distinguir una factura corregida. Por eso debe combinarse conceptualmente con:

```text
hash_contenido
```

Reglas:

| Situación | Tratamiento |
|---|---|
| Misma clave y mismo hash | Archivo duplicado; no reprocesar |
| Misma clave y distinto hash | Factura corregida o modificada |
| Nueva clave | Nueva factura |
| Reproceso del mismo archivo | Nuevo intento, misma factura |

## Facturas corregidas

Si IQ puede reenviar una factura corregida, no conviene impedirla mediante una restricción única rígida. En ese caso agregaría:

```text
version_factura
estado_version
factura_anterior_id
```

Y utilizaría una restricción como:

```sql
UNIQUE (
    tipo_identificacion_ips,
    numero_identificacion_ips,
    numero_factura,
    version_factura
)
```

## Fecha de factura

No incluiría `fecha_factura` inicialmente en la clave, porque una corrección podría cambiar esa fecha. Solo debería incorporarse si IQ confirma que un prestador puede reutilizar el mismo número de factura en períodos distintos.

## Texto sugerido para la EF

> La clave de negocio de la factura estará compuesta por el tipo y número de identificación del prestador y el número de factura. El hash del contenido se utilizará como control técnico de idempotencia. Cuando se reciba la misma clave con el mismo hash, el archivo será considerado duplicado. Cuando se reciba la misma clave con diferente hash, se tratará como una posible factura corregida y se aplicará la política de versionado definida para el proceso.

Mi recomendación concreta es:

```text
Clave de negocio:
tipo_identificacion_ips + numero_identificacion_ips + numero_factura

Control de idempotencia:
clave de negocio + hash del contenido
```
