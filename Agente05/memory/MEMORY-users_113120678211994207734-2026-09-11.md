## 9. Regla Funcional De Bloqueo

La validación global debe ser:

```powerscript
private function integer of_validar_solicitud_apta &
(datastore ads_autos, ref string as_mensaje);
long ll_row
string ls_esta, ls_carta_estado

FOR ll_row = 1 TO ads_autos.RowCount()

    ls_esta = ads_autos.GetItemString(ll_row, 'esta')
    ls_carta_estado = ads_autos.GetItemString(ll_row, 'carta_estado')

    IF ls_esta = 'N' AND ls_carta_estado <> 'F' THEN
        as_mensaje = &
            'La solicitud no puede notificarse porque existe al menos una ' + &
            'carta de negación sin finalizar.'
        RETURN -1
    END IF

NEXT

RETURN 1
end function
```

    -> no se envía al prestador
    -> no se genera XML
