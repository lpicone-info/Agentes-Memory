## 1. Reapertura de Cierre y Envío a Revisión

### Validaciones

En PowerBuilder solo realiza una confirmación:

> “¿Está seguro que desea reabrir el Cierre Administrativo?”

- **Aceptar:** continúa con la reapertura.

No se observan validaciones previas adicionales sobre estado, pendientes o usuario dentro del formulario. El procedimiento SQL tampoco contiene validaciones explícitas: ejecuta directamente las actualizaciones para la oficina y expediente recibidos.

## 2. Cerrar Auditoría

### Validación para habilitar el botón

Cada vez que se actualiza la ventana se ejecuta:

```sql
prs_audit_pend
```

Este procedimiento cuenta las órdenes vigentes del expediente que tienen errores enviados a auditoría:

- `total`: cantidad total de órdenes por auditar.
- `auditados`: cantidad con `expe_ordenes.auditado = 'S'`.

El botón **Cerrar Auditoría** solo queda habilitado cuando:

```text
total = auditados
```

Por eso, en la imagen aparece deshabilitado: figura:

```text
Auditados: 0  Pendientes: 1  Total: 1
```

### Validación al presionar el botón

Dentro de una transacción, el sistema vuelve a verificar pendientes ejecutando:

```sql
prs_expe_sin_auditar
```

Se considera pendiente cuando existe un registro que cumple simultáneamente:

- Error vigente.
- `expe_errores.vali = 'S'`.
- `expe_errores.envia_auditoria = 'S'`.
- Orden vigente.
- `expe_ordenes.auditado = 'N'`.

Si encuentra alguno:

- muestra:

  > “No deben existir registros pendientes de auditar para continuar con el Cierre”

- ejecuta `ROLLBACK`;
- no cierra la auditoría.

También controla errores SQL de los procedimientos; si ocurre alguno, no confirma el cierre.

### Qué ejecuta

Primero invoca:

```sql
pru_expedientes_auditoria
    @ofi,
    @expe,
    @audi_fecha   = fecha actual,
    @usuario      = usuario conectado,
    @export_audit = 'S',
    @prm_origen   = 'F'
```

Este procedimiento:

1. Actualiza `expedientes`:
   - `audi_fecha = fecha actual`.
   - `expor_audit = 'S'`.

2. Inserta un registro en `expe_auditoria` con:
   - oficina;
   - expediente;
   - fecha y hora;
   - usuario;
   - actividad `Audita Masiva`.

3. Ejecuta la comprobación final de pendientes.

4. Si no quedan pendientes:
   - realiza `COMMIT`;
   - establece `is_cerrado = 'S'`;
   - cierra la ventana;
   - el expediente se elimina de la bandeja pendiente de auditoría.
