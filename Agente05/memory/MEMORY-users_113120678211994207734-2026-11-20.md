## Recomendación

### Paso 1 — Agregar variables

```sql

@var_email_tld     VARCHAR(63),
```

### Paso 2 — Complementar el bloque de correo

Reemplazar el bloque actual por:

```sql
IF NULLIF(LTRIM(RTRIM(@prm_email)), '') IS NOT NULL
BEGIN
	SET @out_valido = NULL

	EXEC dbo.afs_valida_mail
			@prm_mail   = @prm_email,
			@prm_echo   = 'N',
			@prm_valido = @out_valido OUTPUT

	SET @var_email_dominio =
		SUBSTRING
		(
			@prm_email,
			CHARINDEX('@', @prm_email) + 1,
			LEN(@prm_email)
		)

	SET @var_pos_punto = CHARINDEX('.', REVERSE(@var_email_dominio))

	SET @var_email_tld =
		CASE
			WHEN @var_pos_punto > 1
				THEN RIGHT(@var_email_dominio, @var_pos_punto - 1)

	OR @var_email_tld IS NULL
	OR LEN(@var_email_tld) NOT BETWEEN 2 AND 6
	OR @var_email_tld COLLATE Latin1_General_100_BIN2 LIKE '%[^A-Za-z]%'
```
