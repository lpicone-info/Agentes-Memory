# 4. Diferencia crítica cuando falta el rango de capacidad

El motor general carga:

```sql
max_tareas = @var_max_asignaciones
```

Después evalúa:

```sql
cantidad_activa < max_tareas
```

Si no encuentra una parametrización aplicable en `SOLICITUDES_AUTO_RANGO_USUARIO`:

```text
max_tareas = NULL
```

La comparación:

```sql

```

nunca es verdadera. En ese caso, ningún usuario es seleccionado.

En cambio, `pru_fonosalud_asigna_auditor` hace:


```text
Motor Fonosalud + rango inexistente
→ considera capacidad 999999
```

```text
1. Proceso puntual intenta buscar auditor.
2. No encuentra candidato y conserva NULL.
3. Proceso masivo encuentra auditor y lo asigna.
4. Proceso puntual ejecuta después su UPDATE.

6. Se pierde la asignación realizada por el proceso masivo.
```

```sql

```
