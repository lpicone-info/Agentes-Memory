### [27/10/2026 10:52:56] Agente

Sí, existe una forma de identificarlo, pero intervienen **dos configuraciones distintas**:

1. En `PLANES`, el campo `princi = 'S'` identifica que el plan es **principal**.
2. En `PLAN_ADIC_DEFAULTS` se registran los **planes adicionales asociados por defecto** a ese plan principal.

No existe un único atributo que signifique “este plan principal debe contener adicionales”. La condición se obtiene combinando ambas configuraciones.

### ¿Un afiliado puede tener faltantes?

Sí, técnicamente puede ocurrir que:

- El afiliado tenga activo un plan principal.
- Ese plan tenga adicionales configurados en `PLAN_ADIC_DEFAULTS`.
- Pero el afiliado no tenga los correspondientes registros activos en `AFI_ADICIONALES`.

Esto puede suceder, por ejemplo, si:

- La asociación se configuró después del alta del afiliado.
- El afiliado ya tenía algún adicional y el proceso no volvió a cargar los valores predeterminados.
- Hubo una modificación o baja posterior.
- El alta se realizó mediante un proceso que no aplicó los adicionales predeterminados.

La asociación funciona como una configuración **por defecto durante la solicitud**, pero no constituye una restricción permanente que garantice que todos los afiliados existentes mantengan esos planes adicionales.

### Configuración en Afilmed

La relación se administra desde:

**Configuración → Planes → Planes adicionales por plan principal**

Por lo tanto, es correcto hablar de un posible faltante, pero debe comprobarse comparando el plan principal vigente, sus asociaciones activas y los adicionales activos del afiliado.

### Consulta propuesta

La siguiente consulta es de solo lectura y devuelve los contratos e integrantes activos cuyo plan principal tiene un adicional configurado por defecto, pero no poseen activa la combinación correspondiente de plan adicional y tarifa:

```sql
DECLARE @FechaCorte SMALLDATETIME =
    CONVERT(SMALLDATETIME, CONVERT(VARCHAR(8), GETDATE(), 112))

DECLARE @Prepaga SMALLINT = 0

SELECT
    A.prepaga,
    PR.deno AS entidad,
    A.contra,
    A.inte,
    A.ape,
    A.nombre,
    A.ingre_fecha,
    AP.plan_codi AS plan_principal,
    PP.deno AS plan_principal_deno,
    AP.vigen_desde AS plan_principal_desde,
    PAD.plan_adic AS plan_adicional_faltante,
    PA.deno AS plan_adicional_deno,
    PAD.tari AS tarifa_faltante,
    T.deno AS tarifa_deno,
    CASE
        WHEN EXISTS
        (
            SELECT 1
            FROM AFI_ADICIONALES AA2
            WHERE AA2.prepaga = A.prepaga
              AND AA2.contra = A.contra
              AND AA2.inte = A.inte
              AND AA2.plan_codi = PAD.plan_adic
              AND AA2.vigen_desde <= @FechaCorte
              AND AA2.baja_fecha IS NULL
        )
        THEN 'PLAN ACTIVO CON OTRA TARIFA'
        ELSE 'SIN PLAN ADICIONAL'
    END AS situacion
FROM AFILIADOS A

INNER JOIN AFI_PLANES AP
    ON AP.prepaga = A.prepaga
   AND AP.contra = A.contra
   AND AP.vigen_desde =
       (
           SELECT MAX(AP2.vigen_desde)
           FROM AFI_PLANES AP2
           WHERE AP2.prepaga = AP.prepaga
             AND AP2.contra = AP.contra
             AND AP2.vigen_desde <= @FechaCorte
             AND AP2.baja_fecha IS NULL
       )

INNER JOIN PLANES PP
    ON PP.prepaga = AP.prepaga
   AND PP.plan_codi = AP.plan_codi
   AND PP.princi = 'S'
   AND PP.baja_fecha IS NULL

INNER JOIN PLAN_ADIC_DEFAULTS PAD
    ON PAD.prepaga = AP.prepaga
   AND PAD.plan_codi = AP.plan_codi
   AND PAD.alta_fecha <= @FechaCorte
   AND PAD.baja_fecha IS NULL

INNER JOIN PLANES PA
    ON PA.prepaga = PAD.prepaga
   AND PA.plan_codi = PAD.plan_adic
   AND PA.baja_fecha IS NULL

LEFT JOIN TARIFAS T
    ON T.prepaga = PAD.prepaga
   AND T.plan_codi = PAD.plan_adic
   AND T.tari = PAD.tari
   AND T.baja_fecha IS NULL

LEFT JOIN PREPAGAS PR
    ON PR.prepaga = A.prepaga

WHERE (@Prepaga = 0 OR A.prepaga = @Prepaga)
  AND A.ingre_fecha <= @FechaCorte
  AND A.baja_fecha IS NULL
  AND AP.vigen_desde <= @FechaCorte
  AND AP.baja_fecha IS NULL
  AND NOT EXISTS
      (
          SELECT 1
          FROM AFI_ADICIONALES AA
          WHERE AA.prepaga = A.prepaga
            AND AA.contra = A.contra
            AND AA.inte = A.inte
            AND AA.plan_codi = PAD.plan_adic
            AND AA.tari = PAD.tari
            AND AA.vigen_desde <= @FechaCorte
            AND AA.baja_fecha IS NULL
      )
ORDER BY
    A.prepaga,
    A.contra,
    A.inte,
    PAD.plan_adic,
    PAD.tari
```

El resultado permitiría regularizar cada caso desde Afilmed mediante una solicitud, incorporando el plan adicional y la tarifa indicados.
