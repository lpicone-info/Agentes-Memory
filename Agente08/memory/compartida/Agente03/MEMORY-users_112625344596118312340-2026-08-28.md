### [28/08/2026 15:39:39] Agente

Cristian, sí: la causa es esa estructura del `WHERE`.

El problema no es el `1 = 1`; eso es neutro. El problema es el `OR` separado:

```sql
WHERE (@auto IS NOT NULL AND au.auto = @auto)
OR (
  @auto IS NULL
  AND ...
  AND au.tipo = 'D'
)
```

Cuando `@auto` viene informado, SQL evalúa la primera rama:

```sql
@auto IS NOT NULL AND au.auto = @auto
```

Y ya no exige los filtros de la segunda rama, donde está el `tipo` correcto de la solapa.

Por eso una autorización `tipo='R'` podía aparecer en solapas de `D`, `E`, `C`, `I`, etc.: el filtro `tipo` quedaba condicionado a `@auto IS NULL`.

Lo correcto es que el filtro funcional de la solapa aplique en ambos casos. Ejemplo:

```sql
WHERE (
  @auto IS NOT NULL
  AND au.auto = @auto
  AND au.tipo = 'D'
)
OR (
  @auto IS NULL
  AND ...
  AND au.tipo = 'D'
)
```

Resumen: no es culpa del `1 = 1`; es culpa de que el `OR` dejó el filtro `tipo` solo del lado `@auto IS NULL`.
