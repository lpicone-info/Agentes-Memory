Hugo, en Windows podés verificarlo así:

1. Presioná `Win + R`.
2. Ejecutá:

```text
shell:fonts
```

3. Buscá el nombre del font en la carpeta de fuentes.

También podés comprobarlo desde PowerShell:

```powershell
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts"
```

Para fuentes instaladas solo para tu usuario:

```powershell
Get-ItemProperty "HKCU:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts"
```

La validación más práctica es abrir Word, Notepad o PowerBuilder y comprobar que el font aparezca en la lista. Si lo instalaste mientras la aplicación estaba abierta, cerrala y volvela a abrir para que actualice el listado.
