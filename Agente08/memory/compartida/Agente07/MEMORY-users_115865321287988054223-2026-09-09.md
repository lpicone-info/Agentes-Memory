### [09/09/2026 17:12:58] Agente

Pato, para los request de `EjecutarTransaccion` (`02A`, `02C`, `02D`, `02L`) la respuesta sí puede traer copago, pero no trae un tag de “tipo de copago”.

En la salida de `DetalleProcedimientos` se serializa:

```xml
<Copago>...</Copago>
<ImporteACargoAfiliado>...</ImporteACargoAfiliado>
```

Y a nivel general, en `RtaAdicional`, puede venir:

```xml
<Coseguro>...</Coseguro>
<MontoFinanciador>...</MontoFinanciador>
```

No vi en esa respuesta tags como:

```xml
<TipoCopago>
<PagoCopa>
<PagoCopaDeno>
```

Esos `PagoCopa` / `PagoCopaDeno` existen en otras estructuras del WS vinculadas a consulta de autorizaciones/detalles (`AutoDetalle`), pero no quedan expuestos en la respuesta normal de `TransactionServ.EjecutarTransaccion` para estos tipos.
