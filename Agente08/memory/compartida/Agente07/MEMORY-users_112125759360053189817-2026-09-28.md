## ¿Se generan comprobantes automáticamente?

Al guardar se registran los **comprobantes respaldatorios presentados por el afiliado** —facturas, recibos y sus ítems—, pero **no se genera automáticamente un comprobante contable ni una Orden de Pago**.

El sistema permite imprimir manualmente:

- Recibo de comprobantes.
- Comprobante de recepción del reintegro.
- Detalle del reintegro o liquidación.
- Orden de Pago.
- Orden de Pago detallada.
