- Definición operativa encontrada: una Situación Terapéutica es una patología/grupo de riesgo/condición especial asignada a un afiliado, con vigencia y efectos sobre coberturas, prestaciones, medicamentos, copagos, topes, autorizaciones, liquidaciones, documentación y seguimiento.

- Integración de formularios PDF descargables desde App/Webpos: los PDFs se guardan en BD en tabla `formularios_attach`, campo `datos` (`VARBINARY(MAX)`), con `codigo`, `deno`, `ruta`, `archivo`, `baja_fecha`.
- SP para listar formularios: `apps_formularios_attach`, que devuelve `codigo`, `deno`, `archivo` desde `FORMULARIOS_ATTACH` donde `baja_fecha IS NULL`, ordenado por `deno`.
- SP clave para descargar PDF: `apps_formularios_attach_datos`, parámetro `@prm_codigo INT`, devuelve `codigo`, `archivo`, `datos` desde `FORMULARIOS_ATTACH` donde `baja_fecha IS NULL AND codigo = @prm_codigo`.
- Código Webpos relacionado: `webpos/modelo/formulario.php`, métodos `listar()` (`EXEC apps_formularios_attach`) y `recuperar($codigo)` (`EXEC apps_formularios_attach_datos @prm_codigo = ?`). Controlador `webpos/controlador/formulario_busqueda.php` descarga `datos` con headers `application/octet-stream` y `Content-disposition: attachment; filename=...`.
- Carga/mantenimiento del PDF en Presmed: ventana PB `wp_st_formulario_attach_abm`, llama a `pri_st_formularios_attach` y luego ejecuta `updateblob formularios_attach set datos = :lb_datos where codigo = :ll_codigo`.
