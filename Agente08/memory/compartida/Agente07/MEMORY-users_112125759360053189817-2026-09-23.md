```sql
SELECT @vali_dias = ISNULL(valor, 0)
FROM parametros_generales
WHERE clave = 'cant_dias_val_autorizacion'
  AND sistema = 'Presmed'

IF (@vali_dias > 0 AND @aufree = '-3')
    SET @vali_fecha = DATEADD(DAY, @vali_dias, @orden_fecha)
ELSE IF (@vali_dias > 0)
```

## ¿Qué información emite?

Genera un padrón detallado, con **una fila por afiliado/integrante**, reconstruido a la fecha seleccionada.

### Información principal

- Número de afiliado: entidad, contrato e integrante.
- Apellido y nombre.
- Parentesco y datos del titular.
- Sexo y fecha de nacimiento.
- Tipo y número de documento.
- CUIL.
- Fecha de ingreso.
- Situación del afiliado: activo o baja.
- Fecha y motivo de baja.
- Plan.
- Origen.
- Estado de cuenta.
- Observaciones.

### Información opcional

El usuario puede agregar columnas como:

- Nacionalidad y estado civil.
- Edad.
- Domicilio particular y de cobro.
- Teléfonos, celular y correo electrónico.
- Cuenta, subcuenta y megacuenta.
- Tarifa e importe.
- Categoría y familiar a cargo.
- Forma de pago.
- Credenciales.
- Promotor y delegación comercial.
- Condición frente al IVA.
- Situación terapéutica.
- Prestador externo, convenio y modo de facturación.
- Derivación de aportes:
  - Si deriva o no.
  - Sistema.
  - Obra social.
  - Datos de derivación sindical.

### Datos exclusivos para entidades con RNOS/RNAS

Cuando la entidad posee `PREPAGAS.RNOS`, se habilitan:

- **Tipo de beneficiario**, obtenido del régimen del afiliado.
- **Situación de revista**.
- **Estado SSS**.
- Filtros por tipo de beneficiario y situación de revista.

Para dependientes con aportante grupal, el reporte busca el régimen y situación de revista del integrante titular aportante.

## ¿Para qué se utiliza?

Es un reporte operativo para:

1. Obtener una fotografía del padrón a una fecha determinada.
2. Auditar afiliados activos, bajas y composición de grupos familiares.
3. Controlar plan, documentación, datos personales y situación administrativa.
4. Revisar la clasificación requerida para obras sociales: régimen, situación de revista y estado SSS.
5. Verificar derivaciones de aportes y obra social asociada.
6. Filtrar segmentos del padrón y exportarlos o imprimirlos.

**Importante:** no es el archivo reglamentario de novedades para presentar ante RNAS/SSS. Es una **consulta interna, imprimible y exportable**, utilizada para control y análisis del padrón.
