Pato, funcionalmente el **coordinador** es un prestador agrupador —normalmente un círculo, colegio o asociación— que administra la relación con un conjunto de prestadores individuales.

No representa a una persona que coordina clínicamente una atención. Es una figura **administrativa y contractual**.

## Relación en `PRESTAD_CIRCU_COORD`

| Campo | Significado |
|---|---|
| `prestad` | Círculo o coordinador |
| `prestad2` | Prestador asociado al círculo |
| `prestad2_codi` | Código que el círculo asigna al prestador |
| `alta_fecha` | Inicio de la relación |
| `baja_fecha` | Fin de la relación; `NULL` significa vigente |

La clave es:

```text
prestad2 + prestad
```

Un mismo prestador puede pertenecer a más de un coordinador.

### Ejemplo real en `Ospecon_Prox_Ver`

```text
prestad       = 1
Coordinador   = COLEGIO MÉDICO DE LA PAMPA

prestad2      = 1071
Prestador     = URQUIZA MARSERO, CARINA NOEMI

prestad2_codi = 672
```

Esto significa:

> La profesional `1071` está asociada al Colegio Médico de La Pampa y, dentro de ese colegio, se identifica con el código `672`.

## Funciones del coordinador

### 1. Agrupar prestadores

Permite determinar a qué círculo pertenece un prestador:

```text
Prestador individual → PRESTAD_CIRCU_COORD → círculo/coordinador
```

El procedimiento `prs_circulo_x_prestador` utiliza directamente esta relación.

### 2. Administrar el código interno del asociado

`prestad2_codi` no es el código general de `PRESTADORES`.

Es el código con el que el coordinador reconoce al asociado dentro de su propia estructura. En esta base, todas las relaciones vigentes tienen informado ese código.

### 3. Definir categoría dentro del círculo

La categoría de un prestador asociado no se toma de la categoría propia del círculo.

Se configura en:

```text
PRESTAD_CIRCU_CATE
```

Relación:

```text
prestad     = coordinador
prestad2    = asociado
cate        = categoría del asociado dentro del círculo
vigen_desde = vigencia
```

Por lo tanto, el mismo profesional podría tener categorías diferentes según el círculo o la vigencia.

### 4. Definir lugares habilitados dentro del círculo

Se utiliza:

```text
PRESTAD_LUGARES_CIRCU
```

Esta tabla relaciona:

```text
coordinador + prestador asociado + lugar
```

El sistema la consulta para determinar en qué lugares puede operar el asociado bajo ese círculo.

### 5. Intervenir en cartilla

El procedimiento `prs_asig_carti` marca como pertenecientes a un círculo a los prestadores encontrados como:

```text
PRESTAD_CIRCU_COORD.prestad2
```

Esto permite que la cartilla interprete al prestador como integrante de una red coordinada.

### 6. Agrupar expedientes y liquidaciones

La relación se utiliza para:

- consultar expedientes pendientes del coordinador;
- consultar liquidaciones de sus asociados;
- agrupar expedientes del prestador individual bajo el círculo;
- identificar al prestador efector dentro de un expediente presentado por el coordinador;
- recuperar, cuando corresponde, la cuenta asociada al coordinador.

Ejemplo conceptual:

```text
Expediente.prestad = médico asociado
PRESTAD_CIRCU_COORD.prestad2 = médico asociado
PRESTAD_CIRCU_COORD.prestad = círculo
```

Así el sistema puede presentar al círculo todos los expedientes de sus asociados.

## Lo que no define esta tabla

`PRESTAD_CIRCU_COORD` por sí sola no define:

- convenios;
- valores de prestaciones;
- categoría concreta;
- lugares;
- cuenta de pago;
- autorización para realizar una prestación.

Solo establece la relación base entre coordinador y asociado. Las demás condiciones se obtienen de tablas complementarias.

## Círculo

El círculo representa una organización que agrupa profesionales.

Ejemplos reales:

```text
COLEGIO MÉDICO DE LA PAMPA
CÍRCULO MÉDICO DE AZUL
ASOCIACIÓN MÉDICA DE BAHÍA BLANCA
```

La relación se configura así:

```text
PRESTAD_CIRCU_COORD.prestad  = círculo
PRESTAD_CIRCU_COORD.prestad2 = profesional asociado
```

Además de la pertenencia, puede administrarse:

```text
PRESTAD_CIRCU_COORD.prestad2_codi
    → código del profesional dentro del círculo

PRESTAD_CIRCU_CATE
    → categoría del profesional dentro del círculo

PRESTAD_LUGARES_CIRCU
    → lugares donde el profesional opera bajo el círculo
```

El círculo se utiliza cuando importa conocer:

- qué profesionales lo integran;
- el código asignado a cada miembro;
- la categoría del miembro;
- sus lugares de atención;
- su presentación en cartilla;
- las prestaciones o expedientes pertenecientes a sus miembros.

## Coordinador

El coordinador es una entidad que centraliza la operatoria administrativa de uno o varios prestadores.

Ejemplos reales de tipo `O` en la base:

```text
SANATORIO PASTEUR S.A.
CLÍNICA YUNES S.R.L.
HEALTH NET S.A.
SANATORIO FRANCHIN
RED IMAC
```

Su función está relacionada principalmente con:

- agrupación de expedientes;
- consulta de liquidaciones pendientes;
- liquidación de prestadores coordinados;
- determinación de la cuenta del coordinador;
- centralización de presentación y cobro.

El coordinador puede ser una clínica, sanatorio, red o administrador. No necesita ser un colegio profesional ni representar una matrícula gremial.

## Ejemplo conceptual

### Círculo

```text
Círculo Médico
    ├── Médico A, categoría B
    ├── Médico B, categoría C
    └── Médico C, categoría A
```

La relación describe la pertenencia profesional y las condiciones de cada miembro.

### Coordinador

```text
Sanatorio coordinador
    ├── Prestador A
    ├── Prestador B
    └── Prestador C
```

Los profesionales realizan las prestaciones, pero el coordinador puede centralizar la presentación, liquidación o cuenta de pago.

## ¿Para qué se usa uno u otro?

Se utiliza **Círculo** cuando el contrato o padrón representa una asociación profesional y se necesita administrar miembros, códigos, categorías y lugares.

Se utiliza **Coordinador** cuando una entidad concentra la operatoria administrativa o liquidatoria de distintos prestadores, sin constituir necesariamente un círculo profesional.

No deberían usarse como sinónimos:

```text
Círculo     → pertenencia y representación profesional
Coordinador → centralización administrativa/liquidatoria
```
