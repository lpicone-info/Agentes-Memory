```sql
afi_deriv_aportes.meses_a_estimar = meses_a_estimar + 1
```

## Condiciones para que se incremente

El `+1` ocurre únicamente cuando:

- El aporte es de tipo estimado (`APORTES.tipo_aporte = 'E'`).
- Está vinculado al comprobante mediante un ajuste interno y `APORTES_AJUSTES`.
- La relación `APORTES_AJUSTES` está vigente.
- El aporte estimado todavía no estaba dado de baja.
- Se encuentra una derivación correspondiente al afiliado, obra social, CUIT y período del aporte.

Si el comprobante utilizó varios aportes estimados, el campo puede aumentar más de una unidad.
