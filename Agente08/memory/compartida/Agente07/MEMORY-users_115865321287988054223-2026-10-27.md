Pato, en **Liquidaciones → Sanatorio → Internación** hay tres controles diferentes:

## 1. Que la autorización aparezca en la búsqueda

El buscador muestra autorizaciones que:

- Pertenecen al afiliado consultado —por contrato/integrante o documento—.
- Están dentro del rango de fechas.
- Coinciden con el tipo de autorización seleccionado.
- No están dadas de baja.
- Pueden ser autorizaciones madre o asociadas/prórrogas.

Que aparezca en el buscador **no garantiza que pueda incorporarse correctamente**. El buscador no filtra todos los controles posteriores ni exige necesariamente que la cabecera esté aceptada.

Evidencia: [prs_autoxafi.sql](</home/desarrollo-ia-07/.openclaw/workspace/svn/mpariso-Infomedical-trunk/backend/procedures/prs_autoxafi.sql:39>).

## 2. Que pueda asociarse a la internación

Al seleccionar o ingresar el número, Presmed controla:

| Control | Resultado |
|---|---|
| La autorización no existe | Se limpia el número y no se incorpora. |
| Está dada de baja | Se genera el error 87. |
| Es de Prestaciones, Excepciones o Situaciones terapéuticas (`P`, `E` o `S`) | No corresponde funcionalmente a internación; genera el error 81. |

| Pertenece a otro afiliado | El sistema consulta si se desea recuperar la autorización. Si se acepta, la internación adopta el afiliado de la autorización; si se rechaza, no se incorpora. |
| El sanatorio/efector no corresponde al expediente | Normalmente se bloquea. Para prestadores que no son círculo puede admitirse si está habilitado el parámetro `liquida_efector_diferente` y el usuario confirma. |

| Ya está en otro expediente | Se informa como autorización utilizada y genera el error 84. |
| Ya está en otro ítem del mismo expediente | Pregunta si se desea ingresarla igualmente. |

## 3. Qué prestaciones de esa autorización se agregan

Una autorización válida puede asociarse, pero sus prestaciones se incorporan solamente cuando:

- El ítem de la autorización está vigente.
- Está **aceptado**: `esta = 'A'`.
- Tiene cantidad pendiente.
- No fue consumido completamente en otra liquidación.
- Queda pendiente alguno de sus conceptos: honorarios, gastos o ayudantes.

Presmed descuenta lo ya liquidado en honorarios, órdenes u odontología. Por eso puede suceder que:

```text
La autorización se pueda seleccionar
pero no agregue ninguna prestación
```

En ese caso muestra:

> “No quedan prestaciones pendientes para liquidar”.

Si la autorización no tiene prestaciones detalladas, también puede quedar referenciada, pero informa que no posee detalle para recuperar.

Evidencia: [prs_auto_prestac_aliqui.sql](</home/desarrollo-ia-07/.openclaw/workspace/svn/mpariso-Infomedical-trunk/backend/procedures/prs_auto_prestac_aliqui.sql:80>) y [wp_expe_sana.srw](</home/desarrollo-ia-07/.openclaw/workspace/svn/mpariso-Infomedical-trunk/exe/Source Infomedical/wp_expe_sana.srw:2225>).

## Errores que quedan para revisión

Otros desvíos no determinan necesariamente que la autorización desaparezca de la carga. Pueden quedar como errores o débitos para la revisión obligatoria de internación:

- Fecha liquidada anterior al inicio de internación.
- Alta o egreso censado anterior a la fecha liquidada.
- Días liquidados superiores a los autorizados.
- Falta de cobertura, convenio o valorización.
- Prestaciones deshabilitadas.
- Diferencias entre días facturados, autorizados y censados.

## Conclusión funcional

Una autorización es plenamente utilizable cuando es **vigente, correspondiente a internación, de la entidad y afiliado correctos, compatible con el sanatorio/efector del expediente y con prestaciones aceptadas todavía pendientes de liquidar**.

La internación también puede cargarse **sin autorización**. Asociar una autorización aporta el afiliado, las prestaciones aceptadas, los días autorizados/censados y las prórrogas relacionadas, pero no evita la revisión posterior.

Madre de Internación/Cirugía
