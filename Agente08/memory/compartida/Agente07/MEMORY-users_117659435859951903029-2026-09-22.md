Juana, en `Presmed > Autorizaciones > Autorizaciones > Prórroga de días de internación`, el campo **Fecha** corresponde a `dw_auto.fecha`.

### ¿Cuándo queda editable?

Ingresando desde el menú:

1. Al abrir o limpiar la ventana, **Fecha está protegida**.
2. Se vuelve editable cuando se carga una **autorización madre válida**:
   ```powerscript
   If ids_auto.rowcount() > 0 then
       dw_auto.object.fecha.protect = '0'
   end if
   ```
3. Si la autorización cargada ya es una prórroga (`autorizaciones.prorro = 'S'`), se deshabilita toda la cabecera y **Fecha deja de ser editable**.
4. Si la ventana se abre en modo consulta, también queda protegida.

### Importante: editable no siempre significa que pueda guardarse

El código desprotege explícitamente `fecha` al encontrar una autorización válida, pero la grabación puede estar bloqueada si la autorización:

- está dada de baja;
- se abrió en modo consulta;
- pertenece a una sucursal o sector sin acceso para el usuario;
- está cerrada y no cumple las condiciones para editarla.

En `Ospecon_Prox_Ver`, el parámetro:

```text
Presmed / Autorizaciones / permite_editar_auto_cerrada = S
```

permite editar autorizaciones cerradas, siempre que no tengan:

- ajustes asociados;
- expedientes asociados;
- censos o egresos;
- transacciones `02C` o `02D`;
- relaciones `02A`.

### Validaciones al cambiar la fecha

- Debe ser una fecha válida y no puede quedar vacía.
- La fecha de validez se recalcula automáticamente como:
  ```text
  Fecha de autorización + 30 días
  ```
  porque `cant_dias_val_autorizacion = 30`.
- La fecha de orden no puede ser posterior a la fecha de autorización.
- Si la fecha ingresada coincide con la autorización madre, muestra una advertencia, pero permite continuar si el usuario confirma.

**Conclusión:** en el circuito normal desde el menú, **Fecha queda editable después de cargar una autorización madre existente que no sea ya una prórroga**. La posibilidad efectiva de guardar depende además del estado, acceso y asociaciones de esa autorización.

Evidencia principal: `wp_auto_prorrogas.srw`, eventos `ue_getauto`, `ue_setefector`, `ue_postopen` y `ue_restaurar`. No realicé cambios.
