Jean, la relación es:

```text
pedidos_attach.nro_pedido
        ↓
pedidos.nro_pedido
        ↓
autorizaciones.nro_pedido
```

`PEDIDOS_ATTACH` tiene una clave foránea con `PEDIDOS`. `AUTORIZACIONES` también conserva el número de pedido que originó la autorización.

### Consultar desde un número de pedido

```sql
DECLARE @nro_pedido INT = 12345

SELECT
    p.nro_pedido,
    p.origen,
    p.ubicacion AS ubicacion_pedido,
    a.sucur,
    a.auto,
    a.fecha AS fecha_autorizacion,
    a.esta AS estado_autorizacion,
    pa.item,
    pa.archivo,
    pa.ubicacion AS ubicacion_adjunto,
    DATALENGTH(pa.datos) AS bytes_binario,
    pa.alta_fecha,
    pa.baja_fecha
FROM pedidos p
LEFT JOIN autorizaciones a
    ON a.nro_pedido = p.nro_pedido
    AND a.baja_fecha IS NULL
LEFT JOIN pedidos_attach pa
    ON pa.nro_pedido = p.nro_pedido
    AND pa.baja_fecha IS NULL
WHERE p.nro_pedido = @nro_pedido
ORDER BY a.sucur, a.auto, pa.item
```

### Consultar desde una autorización

```sql
DECLARE @sucur SMALLINT = 1
DECLARE @auto INT = 123456

SELECT
    a.sucur,
    a.auto,
    a.nro_pedido,
    p.origen,
    p.ubicacion AS ubicacion_pedido,
    pa.item,
    pa.archivo,
    pa.ubicacion AS ubicacion_adjunto,
    DATALENGTH(pa.datos) AS bytes_binario,
    pa.alta_fecha
FROM autorizaciones a
INNER JOIN pedidos p
    ON p.nro_pedido = a.nro_pedido
LEFT JOIN pedidos_attach pa
    ON pa.nro_pedido = p.nro_pedido
    AND pa.baja_fecha IS NULL
WHERE a.sucur = @sucur
AND a.auto = @auto
AND a.baja_fecha IS NULL
ORDER BY pa.item
```

Consideraciones:

- Un pedido puede generar **más de una autorización**.
- Si no existen filas en `PEDIDOS_ATTACH`, revisar `PEDIDOS.ubicacion`: el sistema lo utiliza como ubicación alternativa para pedidos antiguos.
- `PEDIDOS_ATTACH.datos` contiene el binario cuando el archivo fue almacenado en base.
