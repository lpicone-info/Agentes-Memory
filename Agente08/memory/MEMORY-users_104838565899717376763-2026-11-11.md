# 6. Reglas funcionales propuestas

1. **Forma de pago:** utilizar la vigencia válida a `cutoffDate`.
2. **Deuda:** considerar saldo positivo de comprobantes impresos, vigentes y no anulados.
3. **Cuotas parcialmente pagadas:** devolver el saldo pendiente, no el importe original.
4. **Cuota actual:** informarla separadamente de las cuotas vencidas.
5. **Intereses:** calcularlos a `cutoffDate` usando la lógica oficial de [afs_ctacte_deuda.sql](/home/desarrollo-ia-08/.openclaw/workspace/svn/estandar-trunk/backend/procedures/afs_ctacte_deuda.sql:719).
6. **Intereses con IVA:** devolver el importe con IVA y aclararlo en el nombre del campo.
7. **Cuotas vencidas:** devolver todos los períodos con saldo, no solamente cuatro.
8. **Contratos sin deuda:** no incluirlos cuando el filtro predeterminado sea `GT 0`.
9. **Créditos sin aplicar:** no descontarlos automáticamente salvo definición funcional expresa.
10. **Contratos dados de baja:** excluirlos por defecto y aplicar vigencia contra la fecha de corte.
11. **ID Siro:** utilizar el identificador único del contrato, no confundirlo con Alias o CBU SIRO.
12. **Totales:** deben coincidir con la suma de los períodos devueltos.

# 7. Implementación recomendada

## Backend SQL

Crear un procedimiento nuevo, por ejemplo:

```text
afs_ws_deudores_fp
```

Debe:

- trabajar en forma set-based;
- filtrar primero los contratos;
- paginar antes de recuperar datos complementarios;
- calcular deuda sobre `saldo`;
- separar saldo, interés e interés con IVA;
- devolver todos los períodos adeudados;
- no utilizar el cursor del procedimiento actual;
- no depender de cuatro columnas de períodos.

El procedimiento actual puede utilizarse como antecedente funcional, pero no como implementación directa.

## WSAfil

Crear componentes versionados:

- nuevo recurso REST;
- DTO de filtros;
- DTO de respuesta;
- BO y DAO propios;
- registro del recurso en `ApplicationConfig`;
- serialización JSON estructurada.

El endpoint vigente `/affiliate` debe mantenerse sin cambios para preservar compatibilidad.
