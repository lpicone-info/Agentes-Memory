### [23/10/2026 09:18:50] Agente

En este contexto práctico del WS, **“entidad” y “prepaga” se refieren al mismo concepto funcional**: la organización a la que pertenece el afiliado.

La diferencia es de denominación:

- **Entidad**: nombre funcional usado por el usuario.
- **`prepaga`**: código interno con el que Afilmed identifica esa entidad.

Por ejemplo:

```xml
<prepaga>1</prepaga>
```

significa: buscar o procesar al afiliado para la **entidad cuyo código interno es 1**.

Técnicamente, no debe confundirse con otros identificadores externos que pueda tener la entidad —RNOS, CUIT, código SSSalud o el campo `PREPAGAS.enti`—. Para este WS, el dato relevante es `PREPAGAS.prepaga`.

Por eso, mi conclusión anterior se mantiene: el request informa la entidad mediante `<prepaga>`, pero el response documentado no devuelve el código `prepaga` de la entidad donde finalmente encontró al afiliado.
