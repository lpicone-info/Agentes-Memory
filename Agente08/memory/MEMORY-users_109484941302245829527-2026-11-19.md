### [19/11/2026 14:42:30] Agente

Javier, el sistema usa dos datos distintos:

- **Para identificar que el mensaje es una anulación 04A:**  
  ```xml

  ```

- **Para identificar la transacción original que debe anular**, depende del método SOAP invocado:
  - **`AnularTransaccion`**: utiliza  
    ```xml
    <Transaccion>3500000003</Transaccion>
    ```

**Conclusión:** si estás llamando a `AnularTransaccion`, el sistema intenta anular la operación indicada en `<Transaccion>`. Si llamás a `EjecutarTransaccion`, deberías informar `<NroReferenciaCancel>` o el código de preautorización correspondiente.

Además, el error **738** significa que la transacción original encontrada no pertenece a un tipo anulable; solo acepta originales `02A`, `02C`, `02D`, `02L`, `02I` o `02Q`.
