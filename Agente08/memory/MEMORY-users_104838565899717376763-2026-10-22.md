### Cómo funciona

Las cargas deben realizarse como **dos importaciones separadas**:

1. **Archivo de prestaciones**
   - Contiene el detalle de las prestaciones.
   - Puede informar sucursal y autorización generada en Presmed/Casa Central.
   - Utiliza el formato TXT configurado para el prestador.

2. **Archivo/listado de transacciones remotas**
   - Contiene referencias a transacciones remotas existentes.
   - El sistema localiza las transacciones aceptadas y las incorpora al expediente.

No se pueden mezclar ambos diseños dentro de un único archivo.

### Segunda importación

Cuando el expediente ya contiene prestaciones, el sistema muestra:

> El expediente de referencia contiene registros cargados.

Ofrece dos comportamientos:

- **Aceptar:** elimina las prestaciones existentes antes de importar.
- **Cancelar:** conserva las prestaciones existentes y permite agregar las nuevas.

Para que convivan prestaciones nativas y remotas se debe seleccionar **Cancelar —conservar registros existentes—** y continuar con la segunda importación.
