1. Toma `dw_sel.object.proce_fecha[1]`.
2. Obtiene mes y año de esa fecha.
3. Arma una fecha con el día `01` de ese mismo mes/año.
4. Le resta 1 día con `RelativeDate(ld_tmp, -1)`.
5. La exporta con máscara `DDMMYYYY`.

- Primer día del mes: `01/06/2026`
- Menos 1 día: `31/05/2026`
- Exportado como: `31052026`
