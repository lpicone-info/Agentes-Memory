### [20/11/2026 11:07:55] Agente

Jean, la vinculación entre un expediente de liquidación y sus adjuntos se guarda en:

### `EXPE_ATTACH`

Claves principales:

- `ofi`: oficina del expediente.
- `expe`: número de expediente.
- `attach`: identificador correlativo del adjunto.
- `tipo`: tipo definido en `ADJUNTOS_TIPOS`.
- `archivo`: nombre del archivo.
- `id_archivo`: referencia utilizada para recuperar el archivo.
- `baja_fecha`: determina si la vinculación sigue vigente.
- `origen`: origen de la carga.

La clave primaria es:

```text
ofi + expe + attach
```

Tiene relaciones directas con:

- `EXPEDIENTES`, mediante `ofi + expe`.
- `ADJUNTOS_TIPOS`, mediante `tipo`.

La tabla no almacena el contenido binario del archivo; conserva sus metadatos y la referencia `id_archivo`.

Consulta de ejemplo:

```sql
SELECT
    EA.ofi,
    EA.expe,
    EA.attach,
    EA.tipo,
    AT.deno AS tipo_adjunto,
    EA.descri,
    EA.archivo,
    EA.id_archivo,
    EA.origen,
    EA.alta_fecha
FROM EXPE_ATTACH EA
INNER JOIN ADJUNTOS_TIPOS AT
    ON AT.tipo = EA.tipo
WHERE EA.ofi = <oficina>
AND EA.expe = <expediente>
AND EA.baja_fecha IS NULL
```
