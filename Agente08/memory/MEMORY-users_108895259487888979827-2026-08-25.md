Jean, sí. Para `CONSALUD_PROD`, si querés saber el último punto usado en facturación masiva de cuota para OSPAT, usaría esta consulta:

```sql
SELECT TOP 1
       c.ente,
       e.deno AS ente_deno,
       c.prepaga,
       pr.abre_deno AS prepaga_deno,
       c.emi_grupo,
       eg.deno AS emi_grupo_deno,
       c.factu_perio,
       c.fecha,
       c.alta_fecha,
       c.compro_tipo,
       c.compro_nro,
       punto_utilizado = SUBSTRING(c.compro_nro, 2, 4),
       p.deno AS punto_deno,
       p.emite_factura_elec,
       c.contra,
       c.cuit,
       c.proceso_origen,
       c.total
FROM comprobantes c
JOIN compro_items ci
  ON ci.ente = c.ente
 AND ci.compro_tipo = c.compro_tipo
 AND ci.compro_nro = c.compro_nro
 AND ci.baja_fecha IS NULL
JOIN entes e
  ON e.ente = c.ente
JOIN prepagas pr
  ON pr.prepaga = c.prepaga
LEFT JOIN emi_grupos eg
  ON eg.emi_grupo = c.emi_grupo
LEFT JOIN puntos p
  ON p.punto = SUBSTRING(c.compro_nro, 2, 4)
WHERE c.ente = 1
  AND c.prepaga = 1
  AND c.compro_tipo = 'FC'
  AND c.proceso_origen = 'FM'
  AND ci.factu_concep = 'CUO'
  AND c.baja_fecha IS NULL
ORDER BY c.fecha DESC, c.alta_fecha DESC, c.compro_nro DESC
```

La validé contra `CONSALUD_PROD`: para OSPAT devuelve como último punto usado el `0006 - FAC NO ELECTRONICA`, con comprobantes `FC` de origen `FM` del período `08/2026`.

El dato clave es `SUBSTRING(c.compro_nro, 2, 4)`: toma el punto desde el número del comprobante, por ejemplo `B000600000012` → `0006`.
