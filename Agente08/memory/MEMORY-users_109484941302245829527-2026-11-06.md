- Se consulta `ZZ_USUARI` para obtener sucursal, sector, nivel y `cambia_pass`.
- Si `cambia_pass = 'S'`, desconecta al usuario y obliga a cambiar la contraseña.

### Active Directory

Si el acceso está configurado como `AD`, la pantalla queda oculta y se utiliza el usuario de Windows. En ese caso la autenticación se delega a Active Directory y luego se verifica que ese usuario esté registrado y habilitado en la base.
