Es un **error de ejecución de PowerBuilder**:

```text
Type mismatch accessing external object property sector
```

Significa que, al ejecutar esta asignación:

```powerscript
dwa_datos.object.sector[1] = au.sector
```

PowerBuilder encontró que el tipo de dato esperado por la propiedad dinámica `sector` no coincide con el tipo que recibió en tiempo de ejecución.

“External object property” se refiere al acceso dinámico a una propiedad del DataWindow; **no significa que sea un error de SQL ni de un servicio externo**.

- `str_auto.sector`: `integer`.
- DataWindow `sector`: `number`.
