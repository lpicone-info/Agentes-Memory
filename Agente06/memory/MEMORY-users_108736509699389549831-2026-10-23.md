## Casos funcionales

- **Estimado no facturado y luego ingresa el real:** el estimado continúa facturable; el real queda consumible.
- **Real no facturado y luego se genera el estimado:** el real pasa a consumible; el estimado queda facturable.
- **Estimado ya facturado y luego ingresa el real:** la detección no filtra por importe facturado; el real queda consumible y no se revierte el estimado.
- **Real ya facturado y luego se genera el estimado:** no se revierte el real ya facturado; el nuevo estimado queda facturable.
