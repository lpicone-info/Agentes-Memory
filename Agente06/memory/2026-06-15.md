Evidencia: `wp_cons_afi_x_plan.ue_aceptar` ejecuta `dw_list.Retrieve(...)`; `dw_list` usa `d_cons_afi_x_plan_grid`, cuyo SQL ejecuta el SP.
- `afs_afi_expor_sss`: ruta `m_afilia > Afiliados > Consultas > Padron Interno`. El usuario selecciona Entidad, Periodo y planes, y presiona Aceptar. Tambien se usa al imprimir. Evidencia: `d_afi_expor_sss` y `d_afi_expor_sss_prn`.
- `afs_arma_aportes`: ruta `m_afilia > Tarifas > Consultas > Test de cuota`. El usuario ingresa Solicitud o Entidad/Grupo familiar/Periodo y presiona Aceptar. Evidencia: `ue_aceptar` llama `ue_calc_aportes`, que crea un DataStore con `d_test_aportes_sp` y ejecuta `Retrieve`.
- `afs_cons_deriv_aportes_sistema`: ruta `m_afilia > Configuracion > Desregulaciones > Sistema de derivacion de aportes`. El usuario selecciona un sistema, presiona Baja y confirma. Tambien aplica desde Detalle seleccionando un registro y presionando Baja. Ejecucion directa con `DECLARE PROCEDURE` y `EXECUTE`.
- `afs_detalle_padron_farma`: ruta `m_afilia > Afiliados > Consultas > Reporte Padron de Afiliados para Farmacia`. El usuario selecciona Tipo de socio, marca planes y presiona Aceptar. Evidencia: `dw_lista.Retrieve(...)` sobre `dw_detalle_padron_farma`.
- `afs_padron_de_bajas_afiliados`: ruta `m_afilia > Afiliados > Consultas > Bajas de afiliados`. El usuario selecciona Entidad, opcionalmente Sucursal y Motivo, ingresa Desde/Hasta y presiona Aceptar. Evidencia: `dw_items.Retrieve(...)` sobre `d_afs_padron_de_bajas_afi`.
- `afs_padron_morosos`: ruta `m_afilia > Cuentas Corrientes > Analisis de morosidad`. El usuario selecciona Entidad, ingresa Fecha y presiona `Padron Morosos`. No se ejecuta con `Consultar`. Evidencia: el boton dispara `ue_exportar`, que ejecuta `dw_padron_morosos.Retrieve(...)` sobre `d_padron_morosos`.
- `afs_padron_rnas_sss`: ruta `m_afilia > Afiliados > Consultas > Padron de Usuarios SSS`. El usuario selecciona Entidad, Periodo, tipo de padron `RNAS` y presiona Aceptar. Evidencia: se asigna `d_padron_rnas_sss` a `dw_exporta` y se ejecuta `Retrieve`.
- `afs_padron_sss`: misma ruta que el anterior. El usuario selecciona Entidad, Periodo, tipo de padron `RNEMP` y presiona Aceptar. Evidencia: se asigna `d_padron_sss` a `dw_exporta` y se ejecuta `Retrieve`.
