## ¿De qué se trata?

Al importar una transacción remota en un expediente de **órdenes o sanatorio**, el sistema utiliza directamente el lugar recibido en:

```text

```

El problema es que ese lugar puede estar dado de baja. El adjunto del R30708 establece esta regla:

1. Si el lugar recibido está vigente, conservarlo.
2. Si está dado de baja, buscar lugares vigentes del prestador.
3. Si existe uno, utilizarlo.
4. Si hay varios, seleccionar el de `vigen_desde` más reciente.
5. Si empatan, tomar un `TOP 1`.

Para que el resultado sea determinístico, recomiendo desempatar además por `lugar ASC`.
