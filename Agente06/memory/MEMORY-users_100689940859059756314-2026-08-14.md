Sí, puede estar relacionado con `+=`, pero no porque `+=` esté mal en sí, sino por cómo PowerBuilder propaga `NULL`.

En PowerBuilder, si concatenás un `string` con un valor `NULL`, el resultado completo pasa a ser `NULL`.

Ejemplo:

```powerscript
ls_buscar = "ente = 1"
ls_valor = NULL

ls_buscar += " AND es_pyme = '" + ls_valor + "'"
```

Resultado:

```powerscript
ls_buscar = NULL
```

En tu función, el candidato más sospechoso es este:

```powerscript
ls_es_pyme = dwa_datos.object.es_pyme[1]
```

Si `dwa_datos.object.es_pyme[1]` viene `NULL`, entonces esta línea deja toda la expresión en `NULL`:

```powerscript
ls_buscar += " AND es_pyme '" + ls_es_pyme + "'"
```

También puede pasar con cualquiera de estos valores si vienen `NULL`:

```powerscript
as_clase
as_modo_fac
as_origen
as_condicion
ai_accion_nivel_restric
adt_vigencia
```

Además, ahí tenés otro posible bug de sintaxis en el filtro:

```powerscript
ls_buscar += " AND es_pyme '" + ls_es_pyme + "'"
```

Probablemente debería ser:

```powerscript
ls_buscar += " AND es_pyme = '" + ls_es_pyme + "'"
```

Para confirmarlo rápido en debug, revisá `ls_buscar` después de cada línea. Vas a ver exactamente en cuál concatenación pasa de tener texto a quedar `NULL`.

La corrección típica es validar antes:

```powerscript
IF IsNull(ls_es_pyme) THEN ls_es_pyme = ""
```

Y hacer lo mismo con los argumentos que puedan venir nulos. En resumen: `+=` no es el problema principal; el problema es que alguna parte concatenada viene `NULL`, y PowerBuilder convierte toda la cadena resultante en `NULL`.

### [14/08/2026 18:07:19] Agente

Correcto: `'NULL'` no representa un valor nulo. Representa el texto literal `"NULL"`.

En un `DataStore.Find()` no tenés que armar algo como:

```powerscript
es_pyme = 'NULL'
```

Ni tampoco:

```powerscript
es_pyme = NULL
```

Para buscar valores nulos en una expresión de DataWindow/DataStore, usá `IsNull()`:

```powerscript
ls_buscar += " AND IsNull(es_pyme)"
```

Entonces la lógica debería separarse así:

```powerscript
IF IsNull(ls_es_pyme) THEN
   ls_buscar += " AND IsNull(es_pyme)"
ELSE
   ls_buscar += " AND es_pyme = '" + ls_es_pyme + "'"
END IF
```

Eso evita dos problemas:

1. No concatenás un `NULL`, que te destruiría toda la variable `ls_buscar`.
2. Generás una condición válida para que el `Find()` busque filas donde `es_pyme` realmente sea nulo.

Tu filtro final, si `es_pyme` es nulo, debería quedar así:

```text
ente = 1 AND clase = 'D' AND modo_fac = 'A' AND origen = 'A' AND cumple_condicion = 'C' AND IsNull(es_pyme) AND accion_nivel_restric = 0 AND vigencia = DATE ('2027-1-1' )
```

No hay que envolver `NULL` con símbolos especiales. En `Find()`, la forma correcta es expresar la condición con `IsNull(campo)`.
