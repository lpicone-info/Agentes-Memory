Marcelo, en ese caso no viene de una propiedad visual propia del `.srd`, sino de la clase base `dw_clase`.

El mecanismo es este:

En [dw_clase.sru](/home/desarrollo-ia-06/.openclaw/workspace/svn/mromano-britanico-2026.07/exe/Source%20Infomedical/dw_clase.sru:714), `of_setmark(TRUE)` activa una bandera interna:

```powerscript
ib_select_row = ab_onoff
r = GetRow()
IF r > 0 THEN THIS.SelectRow( r, ab_onoff )
```

Y después, en el evento `rowfocuschanged` de la misma clase, cuando cambia la fila actual, hace:

```powerscript
IF ib_select_row AND currentrow > 0 THEN
    selectRow( 0, FALSE )
    SelectRow( currentrow, TRUE )
END IF
```

Eso es lo que pinta de azul la fila seleccionada: `SelectRow(currentrow, TRUE)`.

En `wp_ctacte_afi`, después de cargar/filtrar/ordenar, está explícitamente activado en [wp_ctacte_afi.srw](/home/desarrollo-ia-06/.openclaw/workspace/svn/mromano-britanico-2026.07/exe/Source%20Infomedical/wp_ctacte_afi.srw:245):

```powerscript
idw_list.SetFocus( )
idw_deta.of_setmark( TRUE )
idw_list.of_setmark( TRUE )
```

En cambio, en `wp_ctacte_aportes`, `dw_lista_aportes` hereda de `dw_clase`, pero no vi llamada a `of_setmark(TRUE)`. Después del retrieve en [wp_ctacte_aportes.srw](/home/desarrollo-ia-06/.openclaw/workspace/svn/mromano-britanico-2026.07/exe/Source%20Infomedical/wp_ctacte_aportes.srw:101) solo hace:

```powerscript
ll_rowcount = idw_lista.retrieve(li_prepaga,ls_contra,ld_desde,ld_hasta)
```

Para que se comporte como la otra, la lógica debería quedar después de validar que trajo filas:

```powerscript
dw_lista_aportes.SetFocus()
dw_lista_aportes.of_setmark(TRUE)
```

o usando la variable ya asignada:

```powerscript
idw_lista.SetFocus()
idw_lista.of_setmark(TRUE)
```

Conclusión: la propiedad/evento clave no está en `d_ctacte_afi_compro_lista`; está en `dw_clase.rowfocuschanged`, habilitado por `of_setmark(TRUE)`.
