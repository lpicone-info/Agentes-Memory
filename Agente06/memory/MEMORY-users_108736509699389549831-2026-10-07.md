## R30527 — Análisis de `APORTE_INDICES`

### 1. Función de `APORTE_INDICES`

`APORTE_INDICES` contiene los parámetros económicos necesarios para calcular un aporte estimado a partir del sueldo declarado.

Campos relevantes:

| Campo | Uso |
|---|---|
| `cuenta` | Cuenta de obra social; debe coincidir con `obra_soc` de la derivación. |
| `vigen_desde` | Vigencia del índice aplicable al período. |
| `sueldo_desde / sueldo_hasta` | Rango salarial que debe contener el sueldo. |
| `valor_apor` | Porcentaje del aporte. |
| `tope_apor` | Tope de la base del aporte. |
| `valor_cont` | Porcentaje de contribución. |
| `tope_cont` | Tope de la base de contribución. |
| `baja_fecha` | El cálculo exige que sea `NULL`. |

La fórmula utilizada por `afs_valida_valor_aportes` es:

```text
min(sueldo, tope_apor) * valor_apor / 100
+
min(sueldo, tope_cont) * valor_cont / 100
```

Fuente:

[afs_valida_valor_aportes.sql](/home/desarrollo-ia-06/.openclaw/workspace/svn/ogomez-Britanico-trunk/backend/procedures/afs_valida_valor_aportes.sql:24)

---

### 2. ¿Cuándo es obligatorio?

Para **todo cálculo de aporte estimado que pase por `afs_valida_valor_aportes`**, `APORTE_INDICES` es obligatorio.

#### Camino por solicitud

```text
solicitudes
→ soli_afiliados
→ soli_deriv_aportes
→ soli_deriv_aportes_empresas
→ aporte_indices
→ deriv_aportes_sistema_det
```

Usa un `INNER JOIN` contra `APORTE_INDICES`.

#### Camino normal de afiliado

```text
afi_deriv_aportes
→ afi_deriv_empresas
→ aporte_indices
→ deriv_aportes_sistema_det
```

También usa un `INNER JOIN`.

Este es el camino utilizado por:

```text
afi_genera_aportes_estimados
→ afs_valida_valor_aportes
```

Fuente:

[afi_genera_aportes_estimados.sql](/home/desarrollo-ia-06/.openclaw/workspace/svn/ogomez-Britanico-trunk/backend/procedures/afi_genera_aportes_estimados.sql:183)

### Casos que no requieren índices

No requieren `APORTE_INDICES` los aportes reales importados cuando el importe proviene directamente del archivo o proceso de recepción. Esos procesos no calculan el aporte mediante `afs_valida_valor_aportes`.

Tampoco requiere índices una inserción directa mediante `afi_aportes`, pero eso no constituye el circuito normal de cálculo estimado.

Por lo tanto:

| Situación | ¿Requiere `APORTE_INDICES`? |
|---|---:|
| Aporte estimado por derivación normal | Sí |
| Aporte estimado por solicitud | Sí |
| Aporte real importado con importe informado | No |
| Inserción directa mediante `afi_aportes` | No |
| Aporte estimado con plan cubierto | La validación del plan está comentada; sigue requiriendo índice |
