Marcelo, texto explicativo para documentar las temporales del SP:

En el procedimiento `afs_afiliados_deuda_vencida` se utilizan tablas temporales para separar el análisis en etapas y evitar reprocesar información pesada varias veces.

`#deuda`  
Se usa para guardar el universo inicial de facturas vencidas candidatas.  
Contiene los comprobantes de deuda que cumplen las condiciones principales del proceso: prepaga, contrato, comprobante, período de facturación, fecha de vencimiento, saldo pendiente, grupo de emisión y validación de afiliado clase `D`.  
Es la base del resto del procedimiento: todo lo que se calcule después parte de los contratos y facturas cargados en esta temporal.

`#contratos_deuda`  
Se usa para obtener una lista única de contratos con deuda.  
Agrupa la información de `#deuda` por `prepaga` y `contra`, conservando el mayor `factu_perio` del contrato.  
Su objetivo es evitar que los aportes se multipliquen cuando un mismo contrato tiene más de una factura vencida. Esta temporal mejora la performance y corrige el cálculo de aportes disponibles, porque permite buscar aportes una sola vez por contrato.

`#aportes`  
Se usa para guardar el total de aportes facturables disponibles por contrato.  
Toma los contratos existentes en `#contratos_deuda` y suma los registros vigentes de `aportes` con importe facturable positivo y período válido.  
Además guarda el primer período de aporte y la cantidad de aportes encontrados. Luego se relaciona contra `#deuda` para calcular cuánto puede aplicarse sobre cada factura vencida.

En resumen: `#deuda` identifica las facturas vencidas, `#contratos_deuda` reduce esa deuda a contratos únicos para no duplicar cálculos, y `#aportes` calcula los importes disponibles para aplicar contra esa deuda.
