- Error observado en PowerBuilder: `procedure has not been execute or has not result`.
- Se confirmo que `CLOSE sp` en PowerBuilder solo cierra el handle del procedimiento; no cierra la transaccion de `SQLCA`. Si `AutoCommit = False`, hay que ejecutar `COMMIT USING SQLCA` o `ROLLBACK USING SQLCA`.
- Se observo previamente una sesion desde `INFONBOOK003`, programa `afilia`, en `sleeping` con `open_tran = 1`, causando bloqueos `LCK_M_S`. Luego quedo solo una sesion de SSMS (`spid 85`) sin transaccion abierta.
