# MODALIDAD MIXTA

El modo Mixto tiene dos decisiones diferentes.

## 1. Seleccionar/generar el aporte

Depende de:

```text
origen R
+ clase D
+ aporte disponible
+ período habilitado
```

`subcta_conceptos` no interviene para volver elegible al aporte.

## 2. Direccionar AP/APE ya generado

Una vez creado el ajuste:

```sql
subcta_conceptos.concep = AP o APE
subcta_conceptos.factu = A o E
```

determina si el ítem va al afiliado o a la empresa.

Si no existe configuración específica, el código usa:

```sql
ISNULL(SC.factu, 'A')
```

[afi_genera_compro_aju_aportes.sql:388](/home/desarrollo-ia-06/.openclaw/workspace/svn/ogomez-Prevencion-trunk/backend/procedures/afi_genera_compro_aju_aportes.sql:388)

Por tanto:

> Configurar `AP/APE → A` solamente direcciona un ajuste que ya fue generado. No hace que una clase `E` supere la condición `R + D`.

`modo_fac_def` también influye en cuánto aporte toma:

- default `A`: hasta saldar el importe;
- default distinto de `A`: toma todos los aportes disponibles.
