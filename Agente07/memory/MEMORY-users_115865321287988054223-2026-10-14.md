## Respuesta concreta

**Sí:** para conservar el número de lugar de la autorización, el prestador del expediente debe tener un lugar con el mismo código.

Pero la comparación es solamente por:

```text
lugar = código numérico
```

No compara:

- domicilio;
- localidad;
- provincia;
- ni que ambos lugares representen físicamente el mismo establecimiento.

Ejemplo:

```text
Autorización:
Prestador 200
Lugar 2 = SAN MARTÍN 100

Expediente:
Prestador 300
Lugar 2 = BELGRANO 500
```

El sistema considera que el código `2` coincide y selecciona:

```text
Prestador 300 / Lugar 2 / BELGRANO 500
```

Si el prestador `300` no tuviera lugar `2`, seleccionaría su primer lugar disponible.

## Conclusión

El código de lugar no es global: identifica un lugar dentro de cada prestador. Por eso, comparar solamente el número entre dos prestadores diferentes puede asociar domicilios completamente distintos. Ese es el comportamiento actual de trunk, incorporado en el recorrido del **R30192**.
