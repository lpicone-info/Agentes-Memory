## Solicitudes que permiten modificar el plan

1. **Motivo 6 — Cambio de plan/tarifa**
   - Es el circuito específico para cambiar el plan de un afiliado existente.
   - El plan vigente se muestra como antecedente y se habilitan campos separados para ingresar el **nuevo plan y la nueva tarifa**.

2. **Motivo 10 — Cambio de clase de afiliado**
   - Permite modificar clase, cuenta y subcuenta.
   - Como consecuencia del cambio de clase, también permite seleccionar un **nuevo plan y una nueva tarifa**.
   - Al impactar la solicitud, el nuevo plan se registra en `AFI_PLANES`.

3. **Motivo 13 — Cambio de derivación de aportes**, pero **condicionado**
   - Puede producir un cambio de plan cuando:
     - corresponde al circuito de Obra Social/RNAS;
     - está configurado el parámetro general `Afilmed / Solicitudes / plan_depende_de_tipo_beneficiario = 'S'`;
     - el plan o la tarifa seleccionados son diferentes de los anteriores.
   - Si no se cumplen esas condiciones, la solicitud modifica la derivación de aportes pero **no cambia el plan del afiliado**.

4. **Motivo 1 — Afiliación**
   - Permite seleccionar el plan, pero normalmente se trata de la **asignación inicial**, no de un cambio de plan de un afiliado existente.
   - En una **reafiliación**, el mismo circuito puede generar una nueva vigencia de plan para el contrato.

## Conclusión

Para un afiliado existente, los tipos de solicitud que efectivamente pueden cambiar su plan son:

- **6 — Cambio de plan/tarifa**
- **10 — Cambio de clase de afiliado**
- **13 — Cambio de derivación de aportes**, únicamente bajo las condiciones indicadas.

Los demás motivos no permiten seleccionar un plan diferente que luego sea aplicado al afiliado. Aunque el proceso de impacto del motivo **7 — Cambio de titularidad** vuelve a registrar el plan con una nueva vigencia, el plan no es editable y se conserva el mismo.
