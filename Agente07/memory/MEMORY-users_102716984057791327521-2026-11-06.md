## Conclusión

Para un expediente cuyo prestador es un círculo, la importación utiliza finalmente:


Cuando se informan simultáneamente el código de lugar de atención y el número de terminal, **la terminal tiene prioridad** para las transacciones habituales de prestaciones, como `02A`.

## Resolución del lugar

El WS envía por separado:

- `<lugarAtencion><codigo>` → `@efe_lugar`.
- `<NumeroTerminal>` → `@prm_nroTerminal`.

Evidencia: [AutorizacionesDAO.java](/home/desarrollo-ia-07/.openclaw/workspace/svn/mpariso-Infomedical-trunk/ws_auto_remotas/src/java/com/autorem/daos/AutorizacionesDAO.java:270)

Luego `pri_auto_remotas` aplica este orden:

1. Valida que el código de lugar informado pertenezca al prestador y esté vigente.
2. Si no existe, lo reemplaza por el menor `PRESTAD_LUGARES.lugar` vigente.
3. Si se informó terminal, busca un lugar vigente donde:

   ```sql
   PRESTAD_LUGARES.opera_terminal = NumeroTerminal
   ```

4. Si encuentra más de uno, toma:

   ```sql
   MIN(PRESTAD_LUGARES.lugar)
   ```

5. Ese lugar reemplaza al código informado originalmente.
