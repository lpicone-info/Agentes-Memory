Pato, en `V25.08.001` los centros de atención se cargan desde la tabla `puntos_atencion`.

El flujo es:

1. En el login, `webpos/modelo/usuario.php` ejecuta `ars_usuario_pass_valido`.
2. Ese SP toma de `ZZ_USUARI`:
   - `clini` como código del prestador/centro
   - `es_centro` para saber si ese `clini` debe tratarse como centro
3. Si `es_centro = 'S'`, cruza `ZZ_USUARI.clini` con `puntos_atencion.cod_punto_atencion` para obtener la denominación del centro.
4. En pantalla, `frame_prestador.php` instancia `CentroAtencion`, llama:
   - `prs_puntos_atencion` para datos del centro
   - `ars_centro_prestadores` para listar prestadores asociados
5. Los prestadores asociados salen de `prestad_lugares.cod_punto_atencion = @prm_centro`, cruzado con `prestadores`.

Referencias:
- `ars_usuario_pass_valido.sql`: usa `ZZ_USUARI.clini`, `ZZ_USUARI.es_centro` y `puntos_atencion`.
- `prs_puntos_atencion.sql`: lee directamente `puntos_atencion`.
- `ars_centro_prestadores.sql`: lee `prestad_lugares` + `prestadores`.

Lo que muestra:

- **Cobertura**: qué cobertura encontró, plan, cartilla, tope, material complementario, definición de copago y a quién se descuenta.
- **Valores finales**: valor total calculado, parciales de especialista, ayudante, gastos, instrumentadora, copago, plus, urgencia, convenio, mínimos, globales.
