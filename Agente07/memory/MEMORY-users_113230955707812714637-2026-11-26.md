## Circuito de identificación

Cuando el ingreso es manual y no se informa explícitamente un financiador:

1. El valor de `<NumeroCredencial>` se procesa como documento.
2. El WebService invoca `ars_afiliado` sin una prepaga determinada (`@prm_prepaga = 0`).
3. El procedimiento busca todas las afiliaciones vigentes para ese documento.
4. Solo considera prepagas con:
   - `habilitada_webpos = 'S'`
   - `app_prioridad` informada.
5. Selecciona la prepaga con el menor `app_prioridad`.
6. Con esa afiliación determina:
   - `prepaga`
   - `contrato`
   - `integrante`
7. Finalmente, la entidad se obtiene mediante la relación `PREPAGAS.ente`.

Si se informa una prepaga concreta, la búsqueda queda restringida a esa prepaga. Para ingreso mediante credencial física, consulta `AFI_CREDENCIALES`, también filtrando por la prepaga recibida.
