Pato, **no todas las exportaciones manejan el importe con punto decimal**. El comportamiento depende del campo y de la máscara configurada en la homologación:

- Si la máscara está vacía, campos como `saldo`, `total`, `total2` y `total3` usan una máscara con punto: `###############.00`.
- Si la máscara contiene `.`, el importe se genera con decimales según esa máscara.
- Si la máscara **no contiene punto**, el sistema multiplica el importe por `100` y lo exporta como entero, sin separador decimal.
