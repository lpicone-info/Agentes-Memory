  - `api/src/routes/cartillas/combo.js`, línea 21: `router.get("/getLocalidades"...`

  - `api/src/controllers/cartillas/combo/comboLocalidades.js`, línea 5: `const {provin, zona} = req.body;`

**Diagnóstico**
El cliente probablemente llama el endpoint como GET con query string, por ejemplo:

```text
/api/cartillas/combo/getLocalidades?provin=2&zona=9
```

Pero el código no lee `req.query`, lee `req.body`. Entonces `provin` y `zona` llegan como `undefined`, se ejecuta el SP como si fueran `NULL`, y no devuelve localidades.

Además hay otro detalle: si el SP devuelve el error funcional `cod = 1`, la API igual responde con `cod: 0` arriba y mete ese error dentro de `datosLocalidades`. Eso puede ocultar el problema al cliente.

**Recomendación**
Para `getLocalidades`, corregir el controlador para leer parámetros desde `req.query` si el endpoint sigue siendo `GET`, o cambiar la ruta a `POST` si quieren mantener parámetros por body.
