INNER JOIN INFORMATION_SCHEMA.COLUMNS c
  ON LOWER(c.TABLE_SCHEMA) = 'dbo'
  AND LOWER(c.TABLE_NAME) = LOWER(s.tabla)
  AND LOWER(c.COLUMN_NAME) = LOWER(s.columna)

Para que el resultado también muestre pares que están en el `.sql` pero no existen en la base, usar esta variante:

```sql
SELECT
  s.tabla,
  s.columna,
  s.nulabilidad_esperada AS nulabilidad_sql_esperada,
  c.IS_NULLABLE AS nulabilidad_actual_bd,
  CASE
    WHEN c.COLUMN_NAME IS NULL THEN 'NO_EXISTE_EN_BD'
    WHEN c.IS_NULLABLE <> s.nulabilidad_esperada THEN 'DIFIERE'
  END AS resultado
FROM #CamposSinNullabilidadExplicita s
LEFT JOIN INFORMATION_SCHEMA.COLUMNS c
  ON LOWER(c.TABLE_SCHEMA) = 'dbo'
  AND LOWER(c.TABLE_NAME) = LOWER(s.tabla)
  AND LOWER(c.COLUMN_NAME) = LOWER(s.columna)
WHERE c.COLUMN_NAME IS NULL
  OR c.IS_NULLABLE <> s.nulabilidad_esperada
ORDER BY
  s.tabla,
  s.columna
```

En SQL Server, `INFORMATION_SCHEMA.COLUMNS.IS_NULLABLE = 'YES'` significa `NULL`; `NO` significa `NOT NULL`.
