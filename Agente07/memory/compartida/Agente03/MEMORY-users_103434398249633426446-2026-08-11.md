### [11/08/2026 09:38:05] Agente

Marcelo, si el criterio funcional es **“origrect inmediatamente superior”**, ese `ORDER BY` no sería el correcto.

Con:

```sql
ORDER BY x.fecpresent DESC,
         x.origrect DESC
```

primero elegís la rectificativa con **mayor fecha de presentación**, no necesariamente la de `origrect` inmediatamente superior.

Para cumplir lo pedido en `Solución Propuesta`, debería ser:

```sql
ORDER
BY x.origrect ASC,
   x.fecpresent DESC,
   x.registro DESC
```

Así, para un registro `origrect = 0`, toma primero `origrect = 1`; para `origrect = 1`, toma `origrect = 2`, etc. Luego, si hubiese más de un registro con ese mismo `origrect`, desempata por la presentación más reciente y registro mayor.
