```powerscript
/*
  SI as_buscar TIENE S, BUSCA SI UNA PREPAGA AL MENOS TIENE RNOS
  SI as_buscar TIENE N, BUSCA SI UNA PREPAGA AL MENOS NO TIENE RNOS
*/

LONG ll_prepaga

SELECT MAX(prepaga) INTO :ll_prepaga
FROM PREPAGAS
WHERE baja_fecha IS NULL
AND (
        (rnos IS NOT NULL AND :as_buscar = 'S')
        OR
        (rnos IS NULL AND :as_buscar = 'N')

USING SQLCA;

IF NOT isNull(ll_prepaga) THEN
    RETURN TRUE
ELSE
    RETURN FALSE
END IF
```

Qué hace:

Recibe un parámetro string, `as_buscar`, que puede ser `'S'` o `'N'`.

Si recibe `'S'`, busca si existe al menos una prepaga activa con `rnos IS NOT NULL`.

```sql
baja_fecha IS NULL
AND rnos IS NOT NULL
```

Si encuentra alguna, devuelve `TRUE`.

Si recibe `'N'`, busca si existe al menos una prepaga activa con `rnos IS NULL`.

```sql
baja_fecha IS NULL
```
