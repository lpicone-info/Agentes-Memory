## 2. Prestador demandante o matrícula

No existe una obligatoriedad universal. Se controla **por cada prestación**, según `COBERTURAS.prescri`, considerando entidad, plan, nomenclador y código de prestación.

### `prescri = 'L'` — demandante libre

### `prescri = 'D'` — demandante de cartilla
