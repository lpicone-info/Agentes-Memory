Jean, de acuerdo con los manuales del proyecto estándar, la pantalla adjunta corresponde a:

`Planes → Niveles de autorización`

Su función es asignar a cada prestación el nivel que deberá tener el usuario para poder autorizarla.

**Relación con Admin**

El nivel configurado en esta pantalla se compara contra el campo **Nivel Autorización** del usuario en `Admin`.

La regla es:

`Nivel del usuario >= Nivel requerido por la prestación`

La comparación es inclusiva.

| Nivel configurado en la prestación | Usuario que puede aprobar |
|---|---|
| **Nivel 0** | Usuarios con nivel 0, 1 o 2 |
| **Nivel 1** | Usuarios con nivel 1 o 2 |
| **Nivel 2** | Usuarios únicamente con nivel 2 |

Por lo tanto:

- **Usuario nivel 0:** puede aprobar prestaciones de nivel 0. Si intenta autorizar una prestación de nivel 1 o 2, queda pendiente por falta de nivel.
- **Usuario nivel 1:** puede aprobar prestaciones de nivel 0 y nivel 1. No puede aprobar prestaciones de nivel 2.
- **Usuario nivel 2:** puede aprobar prestaciones de nivel 0, 1 y 2.

**Interpretación de la pantalla**

- Prestación sin tilde en nivel 1 ni nivel 2: queda configurada como **nivel 0**.
- Prestación tildada en la columna **1**: queda configurada como **nivel 1**.
- Prestación tildada en la columna **2**: queda configurada como **nivel 2**.
- Las columnas 1 y 2 son excluyentes: una prestación no puede quedar simultáneamente en ambos niveles.

Importante: que una prestación tenga nivel 0 no significa necesariamente que no requiera autorización. El nivel se valida cuando la prestación está cubierta por el plan y además está configurada para requerir autorización.

Cuando un usuario de nivel inferior genera una autorización que contiene una prestación de nivel superior, esta queda en estado **Pendiente** y debe ser resuelta desde **Autorizaciones → Supervisión de autorizaciones → Pendientes y supervisadas por nivel** por un usuario con el nivel correspondiente. Si una autorización tiene varios ítems y alguno queda pendiente, la autorización permanece pendiente.

Además, existe una configuración independiente para definir el nivel mínimo requerido según determinados motivos de rechazo. Para el motivo **“falta de nivel”**, el nivel habilitado para resolverlo depende directamente del nivel configurado en esta pantalla.

**Evidencia consultada**

- Manual `Planes - Niveles de autorización`: indica que el nivel de la prestación se corresponde con el nivel del usuario de Admin.
- Manual `Supervision de autorizaciones`: establece que nivel 0 filtra nivel 0; nivel 1 filtra niveles 0 y 1; y nivel 2 filtra niveles 0, 1 y 2.
- Código estándar `w_clase_auto.srw`, líneas 792-804 y 4776-4784: valida que el nivel del usuario no sea menor al nivel requerido.
- Código estándar `wp_auto_niveles.srw`, líneas 192-198: persiste nivel 0, 1 o 2 según la selección realizada.
