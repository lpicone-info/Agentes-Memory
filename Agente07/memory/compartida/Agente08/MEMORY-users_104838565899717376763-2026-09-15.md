Inge, para obtener afiliados activos que **no tienen `AFI_OPCION` vigente al día de hoy**, usá:

```sql
SELECT
    a.prepaga,
    a.contra,
    a.inte,
    a.cuil,
    a.ape,
    a.nombre,
    a.ingre_fecha,
    a.baja_fecha,
    'SIN AFI_OPCION VIGENTE AL DIA DE HOY' AS observacion
FROM afiliados a
WHERE a.baja_fecha IS NULL
  AND NOT EXISTS
  (
      SELECT 1
      FROM afi_opcion ao
      WHERE ao.prepaga = a.prepaga
        AND ao.contra = a.contra
        AND ao.inte = a.inte
        AND ao.vigen_desde <= CONVERT(date, GETDATE())
        AND
        (
            ao.baja_fecha IS NULL
            OR ao.baja_fecha > CONVERT(date, GETDATE())
        )
  )
ORDER BY
    a.prepaga,
    a.contra,
    a.inte
```

La vigencia tomada es: `vigen_desde <= hoy` y `baja_fecha IS NULL` o `baja_fecha > hoy`.
