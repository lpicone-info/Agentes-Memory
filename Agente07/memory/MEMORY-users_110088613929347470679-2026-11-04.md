Sí, Facundo. Una prestación puede no tener capítulo ni subcapítulo.

En `SMC_Prox_Ver`:

- `PRESTACIONES.capi` permite `NULL`.
- `PRESTACIONES.subcapi` permite `NULL`.
- La obligatoriedad depende de `NOMENCLADORES.obli_capi`:
  - `S`: exige capítulo y subcapítulo.
  - `N`: la prestación se registra sin ambos datos.

Datos actuales:

- 4.966 prestaciones tienen capítulo y subcapítulo.
- 5.629 prestaciones no tienen ninguno.
- No existen casos con capítulo informado y subcapítulo nulo, ni a la inversa.

Por lo tanto, funcionalmente son válidos estos dos escenarios:

```text
capi informado + subcapi informado
capi NULL      + subcapi NULL
```

La combinación válida se determina mediante:

```text
PRESTACIONES.nomen = NOMENCLADORES.nomen
NOMENCLADORES.obli_capi
```
