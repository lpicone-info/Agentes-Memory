- Fecha desde y hasta.
- Prestador efector, si fue informado.
- Tipos de transacción seleccionados, separados por comas.
- Nomenclador.
- Estado:
  - `@prm_rechazadas = 0`: aceptadas (`esta = 'A'`).

1. Recupera el detalle con `prs_cons_transac_remotas`.

Pato, validé la estructura directamente en `SMC_Prox_Ver`. La relación es:

- Pedido: `PEDIDOS.prepaga + contra + inte`
- Historia ST: `SITU_HISTORIAS.prepaga + contra + inte`
- Descripción: `SITU_TERAPEUTICAS.situ`

```sql
DECLARE @fecha_consulta     datetime = GETDATE()
DECLARE @fecha_pedido_desde date = NULL
DECLARE @fecha_pedido_hasta date = NULL
DECLARE @nro_pedido         int = NULL
DECLARE @situ               char(3) = NULL

SELECT p.Nro_pedido,
       p.prepaga,
       p.contra,
       p.inte,
       p.tipo,
       p.origen,
       p.estado,
       p.alta_fecha AS pedido_alta_fecha,
       p.sucur,
       p.auto,
       h.histo,
       h.situ,
       st.deno AS situacion_terapeutica,
       h.fecha AS st_vigencia_desde,
       h.vali_fecha AS st_vigencia_hasta
FROM dbo.PEDIDOS AS p
INNER JOIN dbo.SITU_HISTORIAS AS h
        ON h.prepaga = p.prepaga
       AND h.contra = p.contra
       AND h.inte = p.inte
INNER JOIN dbo.SITU_TERAPEUTICAS AS st
        ON st.situ = h.situ
WHERE p.baja_fecha IS NULL
  AND h.baja_fecha IS NULL
  AND h.esta = 'A'
  AND h.fecha <= @fecha_consulta
  AND (
        h.vali_fecha IS NULL
        OR h.vali_fecha >= CONVERT(date, @fecha_consulta)
      )
  AND (
        @fecha_pedido_desde IS NULL
        OR p.alta_fecha >= @fecha_pedido_desde
      )
  AND (
        @fecha_pedido_hasta IS NULL
        OR p.alta_fecha < DATEADD(day, 1, @fecha_pedido_hasta)
      )
  AND (
        @nro_pedido IS NULL
        OR p.Nro_pedido = @nro_pedido
      )
  AND (
        @situ IS NULL
        OR h.situ = @situ
      )
ORDER BY p.Nro_pedido DESC,
         h.histo DESC
```

Una historia se considera vigente cuando:

- no está dada de baja;
- está aceptada (`esta = 'A'`);
- ya comenzó su vigencia;
- `vali_fecha` no está informada o todavía no venció.

Si un afiliado tiene varias ST vigentes, el pedido aparecerá una vez por cada historia, permitiendo identificar exactamente cuáles posee.
