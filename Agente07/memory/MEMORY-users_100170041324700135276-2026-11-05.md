# Viabilidad de automatización desde la pantalla

## Resultado

**Viabilidad general: media.**

Es posible automatizar gran parte del recorrido, pero una automatización exclusivamente visual sería frágil.

### Automatizable con buena viabilidad

- Inicio de Presmed.
- Inicio de sesión.
- Navegación por menús.
- Apertura de cada tipo de autorización.
- Ingreso de sucursal y número.
- Recuperación de la autorización.
- Presión del botón de impresión.
- Selección del destinatario.
- Apertura de la previsualización.
- Generación del PDF.
- Captura de evidencia.

### Automatizable con mayor dificultad

- Lectura de campos dentro de DataWindows.
- Identificación estable de botones sin identificadores de automatización.
- Manejo de ventanas modales.
- Selección de impresoras.
- Esperas variables durante la generación del reporte.
- Diferencias de resolución, escala de Windows o posición de ventanas.

PowerBuilder puede exponer algunos controles a Windows UI Automation, pero los DataWindows y controles personalizados no siempre proporcionan identificadores estables. Si no los exponen, habría que usar coordenadas, imágenes u OCR, lo que reduce la estabilidad.

## Validación del PDF

Esta parte tiene **alta viabilidad** si se combina la pantalla con una validación técnica:

1. Presmed genera el PDF.
2. El automatismo localiza el archivo.
3. Extrae el texto del PDF.
4. Busca:
   - Apellido y nombre esperado.
   - `DU 33330424`.
5. Verifica que ambos aparezcan en la misma impresión.
6. Guarda el PDF y una captura como evidencia.

La posición exacta “a continuación del apellido y nombre” requeriría analizar las coordenadas del texto en el PDF o complementar con comparación visual.

## Validación de no modificación

Desde la pantalla solamente puede comprobarse parcialmente. Para demostrar objetivamente que la autorización no cambió se necesita una validación adicional:

1. Consultar `dbo.AUTORIZACIONES` antes de reimprimir.
2. Guardar una fotografía lógica de sus datos funcionales.
3. Ejecutar la reimpresión desde Presmed.
4. Consultar nuevamente la fila.
5. Comparar los valores, excluyendo campos técnicos de impresión permitidos.

## Estrategia recomendada

Una automatización híbrida:

1. **Automatización de interfaz:** abre Presmed, recupera la autorización y genera la impresión.
2. **Validación del PDF:** comprueba nombre y documento.
3. **Validación SQL de solo lectura:** confirma que la autorización no sufrió cambios funcionales.
4. **Evidencia automática:** conserva capturas, PDF y resultado de las comparaciones.

Para CP25, esta estrategia tiene **viabilidad alta**. Una automatización basada únicamente en clics e imágenes desde la pantalla tendría **viabilidad media y mantenimiento elevado**.
