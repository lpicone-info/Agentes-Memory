## ¿Qué es un circuito?

Un circuito define el recorrido que puede realizar una autorización entre los distintos sectores de trabajo de Presmed.

Su finalidad es organizar las etapas de revisión, auditoría, corrección y resolución de una autorización. Cada sector funciona como una bandeja de trabajo y los usuarios solamente pueden acceder a las bandejas que tengan habilitadas.

Habitualmente, una autorización comienza en **Carga Inicial**. Desde allí puede:

- Avanzar hacia otros sectores.
- Volver al sector anterior.
- Regresar a Carga Inicial, cuando el circuito lo permita.
- Finalizar aceptada o rechazada.

Al cerrar una autorización, esta vuelve automáticamente a la bandeja de Carga Inicial.

## ¿Cómo se asigna un circuito?

Cuando se genera una autorización, tanto desde Presmed como mediante una transacción remota, se consideran los siguientes datos:

1. **Entidad** a la que pertenece.
2. **Tipo de autorización**.
3. **Nivel máximo de los ítems incluidos**.
4. **Fecha de alta de la autorización**.

Con esos datos se busca un circuito activo y vigente. El nivel puede configurarse como:

- Nivel 0.
- Nivel 1.
- Nivel 2.
- Todos los niveles.

Cuando se utiliza **Todos**, el circuito puede aplicarse sin importar el nivel de los ítems.

La combinación de entidad, tipo de autorización, nivel y fecha de vigencia debe identificar una configuración única.

## Permanencia del circuito

Una vez asignado, el circuito queda asociado a la autorización durante toda su vida.

Esto significa que:

- No cambia aunque posteriormente se modifique la configuración general.
- La autorización conserva las reglas de recorrido con las que fue generada.
- Cuando un circuito ya tiene autorizaciones asociadas, no pueden agregarse, eliminarse ni reordenarse sus pasos.

Si no se encuentra un circuito aplicable, no se realiza una nueva asignación y la autorización continúa según el esquema anterior.

## ¿Cómo avanza una autorización?

Los posibles destinos dependen de:

- El sector donde se encuentra actualmente.
- Su estado: pendiente, aceptada o rechazada.
- El motivo o grupo de rechazo, cuando corresponda.

Si existen varios rechazos, se considera el de mayor prioridad. Los destinos se presentan en el orden definido para el circuito.

Cuando el usuario deriva la autorización:

- Selecciona uno de los sectores permitidos.
- Puede incorporar una nota.
- La nota queda disponible en la auditoría de la autorización.
- Puede devolverla al sector anterior.
- Puede enviarla a Carga Inicial cuando esa posibilidad esté habilitada.

## Autorizaciones remotas 02C

Las autorizaciones generadas mediante una transacción remota `02C` también reciben un circuito.

Al generarse:

1. Se busca el primer destino configurado que corresponda con el tipo de autorización, su estado y el motivo de rechazo.
2. Si existe, la autorización se envía a ese sector.
3. Si no existe un destino aplicable, queda en **Carga Inicial**.

Francisco, la derivación de una autorización se genera en dos etapas diferentes:

## 1. Asignación del circuito

Cuando se crea la autorización, Presmed busca un circuito que coincida con:

- La entidad.
- El tipo de autorización.
- El nivel máximo de los ítems incluidos.
- La vigencia correspondiente a la fecha de alta.

Si encuentra una coincidencia, ese circuito queda asociado permanentemente a la autorización. Los cambios posteriores en la configuración no modifican el circuito ya asignado.

## 2. Derivación entre sectores

La derivación no sigue necesariamente un recorrido único. En cada sector, Presmed determina los destinos permitidos considerando:

- El sector actual.
- El estado general de la autorización: pendiente, aceptada o rechazada.
- El grupo de rechazo aplicable.

El funcionamiento es:

```text
Sector actual
→ Estado de la autorización
→ Grupo de rechazo
→ Destinos habilitados por el circuito
→ Selección del usuario
→ Nuevo sector
```

### Reglas aplicadas

- Si la configuración no indica un grupo de rechazo específico, puede utilizarse con cualquier rechazo o sin rechazo.
- Si la autorización tiene varios rechazos, se considera el de mayor prioridad.
- Cuando existen varios destinos posibles, se muestran en el orden configurado.
- El usuario selecciona el sector al cual desea enviar la autorización.
- Puede agregar una nota, que queda registrada en la auditoría.
- También puede devolverla al sector inmediato anterior.
- Si el circuito lo permite, puede enviarla a **Carga Inicial** desde cualquier sector.

## Caso especial: autorizaciones remotas `02C`

Al generarse una autorización mediante una transacción `02C`:

1. Se le asigna el circuito correspondiente.
2. Se busca la primera derivación configurada que coincida con su tipo, estado y grupo de rechazo.
3. Se envía automáticamente al primer sector coincidente según el orden configurado.
4. Si no existe una derivación aplicable, queda en **Carga Inicial**.

Por lo tanto, la derivación inicial de una `02C` puede ser automática; en las derivaciones posteriores, el usuario elige entre los destinos que el circuito habilita.
