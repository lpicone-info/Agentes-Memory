## 1. Datos recibidos

La pantalla envía:

```sql
@prepaga
@contra
@inte
@fecha_proc
```

Se accede desde:

**Presmed > Autorizaciones > Consultas > Topes en autorizaciones por afiliado**

## 2. Determinación del plan y del período

El procedimiento:

1. Busca en `AFI_PLANES` el plan vigente del contrato para `@fecha_proc`.
2. Recupera la configuración de topes relacionando:
   - `COBERTURAS`
   - `TOPES`
   - `GRUPOS`
3. Determina si el tope es:
   - Individual o grupal.
   - Año calendario o año asociación.

## 3. Consumos considerados

Actualmente suma exclusivamente:

```sql
SUM(AUTO_PRESTAC_ITEMS_REMOTAS.canti)
```

Relacionando:

```text
AUTO_REMOTAS.transac
AUTO_PRESTAC_ITEMS_REMOTAS.transac
```

Aplica principalmente estas condiciones:

```sql
AUTO_REMOTAS.prepaga = @prepaga
AUTO_REMOTAS.contra = @contra
AUTO_REMOTAS.fecha BETWEEN @desde_cal AND @hasta_cal
AUTO_REMOTAS.baja_fecha IS NULL

AUTO_PRESTAC_ITEMS_REMOTAS.esta = 'A'
AUTO_PRESTAC_ITEMS_REMOTAS.baja_fecha IS NULL
```

Además, la remota debe cumplir:

```sql
AUTO_REMOTAS.auto IS NOT NULL
OR AUTO_REMOTAS.tipo_transac IN ('02A', '02L', '02D')
```

## 4. Tope individual y grupal

- **Individual:** agrega el filtro:

```sql
AUTO_REMOTAS.inte = @inte
```

- **Grupal:** no filtra integrante; suma el consumo de todos los integrantes del contrato.

## 5. Información mostrada

La consulta devuelve, entre otros datos:

- Prestación y descripción.
- Grupo de tope.
- Valor del tope.
- Tipo individual o grupal.
- Año calendario o asociación.
- Plan.
- Período consultado.
- Cantidad consumida.

La DataWindow calcula:

```text
Total consumido = SUM(canti) por grupo
Saldo disponible = Tope del grupo - Total consumido
```
