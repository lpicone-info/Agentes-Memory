### [30/09/2026 12:33:48] Agente

Facundo, la relación se realiza mediante el número de nivel:

| Función | Tabla | Campo relacionado |
|---|---|---|
| Define la regla y el nivel resultante | `MOROSIDAD_REGLAS` | `accion_nivel_restric` |
| Describe el nivel | `MOROSIDAD_NIVEL` | `nivel` |
| Configura restricciones de autorizaciones | `MOROSIDAD_AUTORIZACION` | `nivel` |
| Configura restricciones de reintegros | `MOROSIDAD_REINTEGROS` | `nivel` |

La relación lógica principal es:

```text
MOROSIDAD_REGLAS.accion_nivel_restric
                  ↓
       MOROSIDAD_NIVEL.nivel
                  ↓
MOROSIDAD_AUTORIZACION.nivel
```

### Funcionamiento

1. `afi_morosidad_analisis` evalúa si el afiliado cumple una fila de `MOROSIDAD_REGLAS`.
2. Si cumple, toma `accion_nivel_restric` como nivel resultante.
3. `afi_morosidad_estado` busca ese nivel en `MOROSIDAD_AUTORIZACION`.
4. Además del nivel, compara:
   - `tipo_auto`: tipo de autorización; por ejemplo, `I` para Internación.
   - `condicion`: `P`, `U` o `T`.
   - `vigencia` y `baja_fecha`.

Para el afiliado `601085/00`:

```text
MOROSIDAD_REGLAS.accion_nivel_restric = 1
MOROSIDAD_NIVEL.nivel                 = 1
MOROSIDAD_AUTORIZACION.nivel          = 1
MOROSIDAD_AUTORIZACION.tipo_auto      = I
MOROSIDAD_AUTORIZACION.condicion      = T
```

La consulta conceptual sería:

```sql
SELECT
       mr.accion_nivel_restric,
       mn.deno,
       ma.tipo_auto,
       ma.condicion,
       ma.vigencia,
       ma.baja_fecha
FROM MOROSIDAD_REGLAS mr
INNER JOIN MOROSIDAD_NIVEL mn
        ON mn.nivel = mr.accion_nivel_restric
INNER JOIN MOROSIDAD_AUTORIZACION ma
        ON ma.nivel = mr.accion_nivel_restric
```

**Importante:** no existe una clave foránea física entre estas tablas. La asociación se implementa funcionalmente mediante los campos `accion_nivel_restric` y `nivel`.
