## Comprobantes de afiliados

Los comprobantes de facturación de afiliados utilizan otro circuito. Su código de barras:

La configuración relacionada es el campo:


El comportamiento es:

| `barra_ente_rec` | Resultado |
|---:|---|
| `NULL` | Utiliza el formato predeterminado `PF`. |
| Mayor que `0` | Utiliza el tipo de código de barras del ente recaudador seleccionado. |
