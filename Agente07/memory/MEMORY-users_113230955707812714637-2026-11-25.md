## Formato del archivo CABA

El archivo debe contener 12 campos separados por punto y coma:

```text
fecha_publicacion
fecha_vigen_desde
fecha_vigen_hasta
CUIT
tipo_contribuyente
marca_alta_sujeto
marca_cambio_alicuota
alicuota_percepcion
alicuota_retencion
grupo_percepcion
grupo_retencion
razon_social
```

Ejemplo para el contrato `200039210603`:

```text
25112026;01112026;31122026;27392106036;C;S;N;1,50;0,00;00;00;SANTIA BRENDA
```

Las fechas se informan como `DDMMAAAA` y las alícuotas con coma decimal.

## Prueba controlada desde SQL

El siguiente ejemplo carga directamente la temporal y ejecuta el SP principal dentro de una transacción. Termina con `ROLLBACK`, por lo que no conserva los cambios:

```sql
USE Roisa_Prox_Ver

SET NOCOUNT ON
SET XACT_ABORT ON

BEGIN TRY
    BEGIN TRAN

    IF EXISTS (
        SELECT 1
        FROM dbo.TMP_IIBB_PADRON_CABA
    )
    BEGIN
        RAISERROR(
            'La tabla TMP_IIBB_PADRON_CABA no está vacía. Se cancela la prueba',
            16,
            1
        )
    END

    INSERT INTO dbo.TMP_IIBB_PADRON_CABA
    (
        fecha_publicacion,
        fecha_vigen_desde,
        fecha_vigen_hasta,
        nro_cuit,
        tipo_contr_insc,
        marca_alta_sujeto,
        marca_alicuota,
        alicuota_perc,
        alicuota_ret,
        nro_grupo_perc,
        nro_grupo_ret,
        razon_social
    )
    VALUES
    (
        '25112026',
        '01112026',
        '31122026',
        '27392106036',
        'C',
        'S',
        'N',
        '1,50',
        '0,00',
        '00',
        '00',
        'SANTIA BRENDA'
    )

    EXEC dbo.afs_tmp_iibb_padron
        @prm_cod_juris = 901

    EXEC dbo.afs_val_tmp_iibb_padron
        @prm_cod_juris = 901

    EXEC dbo.afi_iibb_padron
        @prm_prepaga = 1,
        @prm_cod_juris = 901

    SELECT
        prepaga,
        contra,
        cuit,
        cod_juris,
        vigen_desde,
        vigen_hasta,
        alicuota_percep,
        lote
    FROM dbo.AFI_ALICUOTAS_IIBB
    WHERE prepaga = 1
      AND contra = '200039210603'
      AND cuit = '27392106036'
      AND cod_juris = 901

    ROLLBACK TRAN
END TRY
BEGIN CATCH
    IF @@TRANCOUNT > 0
        ROLLBACK TRAN

    SELECT
        ERROR_NUMBER() AS error_numero,
        ERROR_MESSAGE() AS error_descripcion
END CATCH
```
