La pantalla lista actas de intimación y, cuando corresponde, el certificado asociado. - `Desde`
- `Hasta`
- `Con Acta`
- `Con Certificado`

**Resultado**
La grilla muestra:
- Cuenta
- CUIT
- Razón social / obra social
- Nro. de acta
- Fecha de acta
- Nro. de certificado
- Fecha de certificado
- Estado del certificado
- Periodo
- Total intereses

Con doble click sobre una fila, la pantalla abre el detalle de consulta de actas para esa acta/cuenta/rango, usando `wp_consulta_actas`.

**Reglas funcionales observadas**
- El certificado nace asociado a un acta previa.
- El antecedente `R22946` define que el certificado de deuda se genera a partir de un acta de intimación y no se anula de forma independiente; queda condicionado por el acta.
- La consulta se alimenta de `actas`, `actas_items`, `actas_certificados` y `estados_certificados`.
