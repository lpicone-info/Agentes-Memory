CASE

```sql
CASE
    WHEN tipo IN ('P', 'E') THEN ape_razon + ', ' + nombre_abre
    ELSE ape_razon
END
```

Por lo tanto, **`P` usa inequívocamente apellido y nombre; `I`, `C` y `O` usan razón social; `E` requiere definir el criterio según la funcionalidad afectada**.

### Diferencia funcional

| Campo | Representa |
|---|---|
| `efe_prestad` | Efector genérico de prestaciones ambulatorias o transacciones remotas |
| `efe_sana` | Sanatorio/institución donde se realiza la internación |
| `efe_sana_lugar` | Lugar de atención del sanatorio de internación |

La `05P` no autoriza una prestación ambulatoria nueva: prolonga la permanencia del afiliado en el sanatorio informado en la autorización inicial. Por eso debe heredar:

```text
05P.efe_sana       = inicial.efe_sana
05P.efe_sana_lugar = inicial.efe_sana_lugar
```
