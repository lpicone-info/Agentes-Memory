## 2. Generar la transacción `02F`

La `02F` no se genera desde un menú de Presmed.

Se genera desde el **Validador de Farmacias**, mediante:

```text
Web Service: RegistrarConsumoFarmacia
Operación: guardar
```

En la prueba manual se puede utilizar SoapUI con el mismo servicio que ya estás ejecutando.

Parámetros determinantes:

```xml
<simula>0</simula>
<fecha_venta>12/11/2026</fecha_venta>
<fecha_prescripcion>12/11/2026</fecha_prescripcion>
```

- `simula = 0`: registra una venta.
- `simula = 1`: registra una consulta o simulación.
- Si `fecha_venta` es anterior al día de ejecución, Presmed transforma la transacción en `02J`.
- Para obtener `02F`, la fecha de venta debe ser la fecha actual.
- El producto, afiliado y fecha deben coincidir con la autorización cargada previamente.

## Circuito completo

```text
Presmed
Autorizaciones → Autorizaciones → Productos de farmacia
```
