### Fecha hasta

3. La fecha devuelta se asigna a `gd_hoy`, sin conservar la hora.

```text
Fecha hasta = fecha actual del servidor SQL
```

### Fecha desde

Se calcula tomando el día anterior a `gd_hoy`, obteniendo su número de día y restándolo a `gd_hoy`.

El resultado normal es el **primer día del mes actual**.

Ejemplo:

```text
gd_hoy      = 11/11/2026
fecha desde = 01/11/2026
fecha hasta = 11/11/2026
```

Existe un caso particular: si la ventana se abre el primer día del mes, toma el primer día del mes anterior.

```text
gd_hoy      = 01/11/2026
fecha desde = 01/10/2026
fecha hasta = 01/11/2026
```

## Criterios utilizados para encontrar el circuito

`prs_obtener_circuito` consulta la configuración dada de alta en el ABM considerando:

- `CIRCUITOS.id_submodulo = 1`, correspondiente a autorizaciones.
- Prepaga de la autorización.
- Tipo de autorización.
- Nivel calculado para la autorización.
- Circuitos vigentes:
  ```sql
  CIRCUITOS.baja_fecha IS NULL
  ```
- Mayor `CIRCUITOS.vigen_desde` que no supere la fecha de la autorización.
- Si no hay coincidencia específica por nivel, también contempla la configuración de nivel general:
  ```sql
  CIRCUITOS.nivel = 'T'
  ```
