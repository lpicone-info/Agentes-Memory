## JOIN recomendado

```sql
LEFT JOIN (
    SELECT
        efe.ofi,
        efe.expe,
        efe.farma,
        efe.lote,
        efe.rece_nro,
        efe.item_nro,
        cantidad_errores = COUNT(*)
    FROM dbo.expe_farma_errores efe
    WHERE efe.baja_fecha IS NULL
    GROUP BY
        efe.ofi,
        efe.expe,
        efe.farma,
        efe.lote,
        efe.rece_nro,
        efe.item_nro
) err
    ON err.ofi = eri.ofi
    AND err.expe = eri.expe
    AND err.farma = eri.farma
    AND err.lote = eri.lote
    AND err.rece_nro = eri.rece_nro
    AND err.item_nro = eri.item
```

Esto devuelve:

- `0` si el ítem no tiene errores.
- `1` si tiene un error.
- `2` si tiene dos errores.
- Y así sucesivamente.
