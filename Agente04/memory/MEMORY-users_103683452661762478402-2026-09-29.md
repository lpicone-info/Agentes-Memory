### Tolerancias

`desvi_porce` y `desvi_monto_item` se obtienen de `farma_normas`, por `prepaga + rece_tipo`, considerando solamente la norma vigente.

La diferencia se considera significativa cuando supera **cualquiera** de estas condiciones:

```text
abs(valor1 - valor2) * 100 / valor2 > desvi_porce
```

o:

```text
abs(valor1 - valor2) > desvi_monto_item
```

Por lo tanto:

- Para tolerar una diferencia debe cumplir simultáneamente ambos límites.
- La igualdad exacta con el umbral se tolera porque se utiliza `>` y no `>=`.
- Si el segundo valor es cero, se omite el porcentaje y se controla solamente el monto.
- Las tolerancias no se descuentan del débito: solamente determinan si la diferencia debe considerarse y qué rechazo corresponde.
