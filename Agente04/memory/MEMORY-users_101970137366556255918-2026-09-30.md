Marcelo, `expe_farma_errores` ya participa en el `FROM` con el alias `efe`:

```sql
FROM dbo.expe_farma_errores efe
```

Además, esa tabla contiene `item_nro`, pero **no contiene un campo llamado `item`**. Por eso no puede agregarse directamente:

```sql
ON item = efe.item_nro
```

Falta identificar la otra tabla que contiene el campo `item`. El JOIN tendría esta estructura:

```sql
INNER JOIN dbo.<tabla_faltante> t
    ON t.ofi = efe.ofi
    AND t.expe = efe.expe
    AND t.farma = efe.farma
    AND t.lote = efe.lote
    AND t.rece_nro = efe.rece_nro
    AND t.item = efe.item_nro
```

No conviene relacionarla únicamente por `item = item_nro`, porque el número de ítem puede repetirse entre expedientes, farmacias, lotes y recetas.

Necesito el nombre y la estructura de la tabla que contiene `item` para armar el JOIN exacto.
