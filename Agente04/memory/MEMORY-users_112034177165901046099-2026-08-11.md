### [11/08/2026 23:28:20] Agente

Walter, en Sybase usá el `VARCHAR` con longitud explícita:

```sql
CONVERT(VARCHAR(6), @prm_zona)
```

Para `SMALLINT`, con `VARCHAR(6)` alcanza porque el rango puede ser `-32768` a `32767`.

Ejemplo:

```sql
SELECT @var_texto = CONVERT(VARCHAR(6), @prm_zona)
```

Si lo estás concatenando:

```sql
SELECT @var_texto = 'Zona: ' + CONVERT(VARCHAR(6), @prm_zona)
```

El problema suele aparecer porque `VARCHAR` sin longitud en `CONVERT` no siempre se resuelve bien en Sybase ASE.
