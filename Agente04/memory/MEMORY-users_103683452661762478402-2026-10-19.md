### Defecto detectado

El procedimiento intenta insertar una primera nota durante la modificación mediante:

```sql
if @nota is not null and @yatienenota = null
    insert into expe_farma_notas ...
```

La comparación `@yatienenota = NULL` nunca resulta verdadera en SQL. Por lo tanto:

- Si el expediente ya tenía nota, se actualiza correctamente.
- Si no tenía nota, **Modificación de expedientes no inserta el primer registro**, aunque el usuario ingrese una nota.
