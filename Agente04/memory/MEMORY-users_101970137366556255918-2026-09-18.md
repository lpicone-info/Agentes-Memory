Marcelo, te la dejo corregida con `JOIN` explícitos, parámetros y aliases para evitar ambigüedad en los dos `rece_nro`:

```sql
SELECT
    a.farma,
    f.manda_farma,
    f.razon,
    a.lote,
    c.afi_dto,
    c.rece_nro AS rece_nro_farmacia,
    a.rece_nro AS rece_nro_receta,
    a.prepaga,
    a.contra,
    a.inte,
    a.emi_fecha,
    a.ticket_nro,
    a.rece_vta_valor,
    a.audi_vta_valor,
    a.ok
FROM expe_farma_recetas a
INNER JOIN expe_farmacias c
    ON c.ofi = a.ofi
    AND c.expe = a.expe
    AND c.farma = a.farma
    AND c.lote = a.lote
INNER JOIN farmacias f
    ON f.farma = a.farma
WHERE a.ofi = @prm_ofi
    AND a.expe = @prm_expe
    AND a.ok = 'N'
    AND a.baja_fecha IS NULL
    AND c.audi_fecha IS NULL
    AND c.carga_fecha IS NOT NULL
    AND c.baja_fecha IS NULL
ORDER BY
    f.manda_farma,
    a.lote,
    a.prepaga,
    a.contra,
    a.inte,
    a.emi_fecha,
    a.rece_nro
```

```sql
@prm_ofi = 1
@prm_expe = 6050801
```
