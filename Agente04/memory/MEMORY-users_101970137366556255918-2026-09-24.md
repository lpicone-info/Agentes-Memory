### [24/09/2026 17:03:47] Agente

Marcelo, técnicamente podés invocar `DoubleClicked`, pero no es recomendable porque ese evento depende de parámetros propios del mouse (`row`, `dwo`, coordenadas).

Conviene centralizar la acción en un **User Event**, porque representa una operación y no necesita devolver un resultado.

Por ejemplo, crear en la ventana:

```powerscript
// Evento: ue_cargar_lote(long al_row)

IF al_row <= 0 THEN
    RETURN
END IF

// Lógica actual de carga
```

Desde `dw_lotes.DoubleClicked`:

```powerscript
Parent.Event ue_cargar_lote(row)
```

Desde `cb_cargar.Clicked`:

```powerscript
long ll_row

ll_row = dw_lotes.GetRow()

IF ll_row > 0 THEN
    Parent.Event ue_cargar_lote(ll_row)
END IF
```

Usaría una **function** únicamente si necesitás devolver un resultado, por ejemplo:

```powerscript
boolean of_cargar_lote(long al_row)
```

Para este caso, la mejor estructura es:

- `DoubleClicked`: detecta la fila y llama al User Event.
- `cb_cargar.Clicked`: obtiene la fila seleccionada y llama al mismo User Event.
- `ue_cargar_lote`: contiene toda la lógica compartida.
