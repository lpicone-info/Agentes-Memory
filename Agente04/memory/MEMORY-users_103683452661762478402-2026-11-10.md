## Caso de uso CU-29752-01

### Nombre

**Consultar informe de débitos por farmacia**

### Objetivo

Permitir al usuario consultar e imprimir los importes presentados y debitados a las farmacias, agrupados por farmacia, presentación o lote, dentro de un período determinado.

### Actor principal

Usuario administrativo, de auditoría o liquidación con acceso a la opción **Totales debitados por farmacia**.

### Precondiciones

- El usuario inició sesión y posee permiso para acceder al menú.
- Existen expedientes y presentaciones de farmacia cargados.
- Las recetas se encuentran asociadas a una farmacia y lote.
- Deben informarse obligatoriamente las fechas **Desde** y **Hasta**.

### Filtros disponibles

- Fecha desde.
- Fecha hasta.
- Farmacia:
  - Razón social.
  - Código de farmacia.
  - Código dentro de la mandataria.
- Mandataria.
- Provincia.
- Localidad.
- Barrio.
- Sólo farmacias no debitables.
- Ordenamiento:
  - Por fecha.
  - Por lote.

## Flujo principal

1. El usuario ingresa a **Reintegros → Consultas → Totales debitados por farmacia**.
2. El sistema abre `wp_rep_farma_deb`.
3. El sistema propone inicialmente:
   - **Desde:** primer día del mes actual del año anterior.
   - **Hasta:** último día del mes actual.
   - Mandataria correspondiente al último expediente de farmacia utilizado, si existe.
4. El usuario completa o modifica los filtros.
5. Opcionalmente busca una farmacia mediante el buscador.
6. El usuario selecciona el ordenamiento por fecha o lote.
7. Presiona **Consultar**.
8. El sistema valida que las fechas no sean nulas.
9. Ejecuta `dbo.prs_farma_debitos` con los filtros ingresados.
10. El procedimiento:
    - Determina las farmacias incluidas.
    - Filtra las presentaciones por `expe_farmacias.presen_fecha`.
    - Obtiene las recetas activas desde `expe_farma_recetas`.
    - Agrupa por expediente, farmacia y lote.
    - Calcula cantidad de recetas, importe presentado y débitos.
11. El sistema muestra:
    - Fecha de presentación.
    - Expediente.
    - Prepaga.
    - Farmacia y razón social.
    - Lote.
    - Descripción de la presentación.
    - Cantidad de recetas.
    - Importe total de recetas.
    - Fecha de carga.
    - Fecha de auditoría.
    - Porcentaje de descuento.
    - Total calculado.
    - Débito a farmacia.
12. Si existen resultados, se habilita la impresión.
13. El usuario puede imprimir el informe con los filtros utilizados en el encabezado.

## Flujos alternativos

### A1 — Fecha desde no informada

1. El sistema muestra: **“La fecha desde no puede ser nula”**.
2. Posiciona el cursor en `Desde`.
3. No ejecuta la consulta.

### A2 — Fecha hasta no informada

1. El sistema muestra: **“La fecha hasta no puede ser nula”**.
2. Posiciona el cursor en `Hasta`.
3. No ejecuta la consulta.

### A3 — Sin resultados

1. La grilla queda vacía.
2. La opción de impresión permanece deshabilitada.

### A4 — Sólo farmacias no debitables

Cuando se marca **Farmacias no debitables**, el procedimiento incluye únicamente farmacias cuyo convenio vigente a la fecha hasta tenga:

```sql
conve_farmacias.debita = 'N'
```

Para este modo, el importe mostrado como débito proviene de la suma de:

```sql
expe_farma_recetas.debi_farma
```

### A5 — Cambio de ordenamiento

- **Fecha:** utiliza `d_rep_farma_debitos`.
- **Lote:** utiliza `d_rep_farma_debitos_lote`.
- El sistema conserva los resultados ya recuperados y reorganiza la presentación.
