## Funcionamiento de `dbo.prs_farma_debitos`

### 1. Construcción del conjunto de farmacias

El SP crea `#farmas`, que contiene las farmacias que se procesarán.

#### Cuando `@debi = 'S'`

Selecciona únicamente farmacias cuyo convenio vigente a `@hasta` tenga:

```sql
conve_farmacias.debita = 'N'
```

La vigencia del convenio se determina mediante el máximo `vigen_desde` menor o igual a la fecha final.

#### Cuando `@debi = 'N'`

Incluye las farmacias sin restringirlas por la condición de débito.

#### Cuando se informa `@farma`

Procesa directamente esa farmacia.

Después aplica, cuando corresponda:

```text
Provincia
Localidad
Barrio
```

utilizando el domicilio normalizado de la farmacia.

### 2. Consolidación de presentaciones y recetas

El SP crea `#temp` y agrupa por:

```text
Oficina
Expediente
Farmacia
Lote
```

Para cada grupo calcula:

- `tot_rece`: cantidad de recetas.
- `tot_val`: suma de `rece_vta_valor`.
- `tot_deb`: suma de `debi_farma`.

La fecha evaluada es:

```sql
expe_farmacias.presen_fecha BETWEEN @desde AND @hasta
```

Las presentaciones y recetas dadas de baja quedan excluidas:

```sql
expe_farmacias.baja_fecha IS NULL
expe_farma_recetas.baja_fecha IS NULL
```

### 3. Armado del resultado

El SP relaciona la información acumulada con:

- la presentación;
- el expediente;
- la farmacia.

Devuelve principalmente:

- Fecha de presentación.
- Expediente.
- Prepaga.
- Lote.
- Descripción de la presentación.
- Cantidad de recetas.
- Valor total de recetas.
- Fecha de carga.
- Fecha de auditoría.
- Total calculado.
- Débito calculado.
- Porcentaje de descuento de farmacia.
- Débito total de farmacia.
- Código y razón social de la farmacia.
- Código de farmacia dentro de la mandataria.

El resultado se ordena por:

```text
Mandataria/farmacia externa
Farmacia
Fecha de presentación
```
