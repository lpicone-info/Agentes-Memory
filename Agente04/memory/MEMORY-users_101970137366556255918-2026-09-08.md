Marcelo, para que pinte azul la fila seleccionada en una DW tipo grilla, el patrón mínimo es hacerlo en el evento `rowfocuschanged` de esa DataWindow:

```powerscript
IF currentrow > 0 THEN
   this.SelectRow(0, FALSE)
   this.SelectRow(currentrow, TRUE)
END IF
```

En tu caso sería en `dw_lista` de `wp_rep_productos_homo`, si querés que esa grilla también marque visualmente la fila activa.

Si la DW tiene colores dinámicos de fondo en el detail, como esta:

```powerscript

```

igual `SelectRow()` debería pintar la selección estándar en azul. Si no lo hace, ahí habría que revisar si algún ancestro o propiedad visual está pisando el color de selección.
