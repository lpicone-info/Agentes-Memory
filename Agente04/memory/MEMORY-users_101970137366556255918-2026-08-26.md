IF l_status <> NotModified! THEN
    li_lote = dw_lotes.Object.lote[ll]

    IF IsNull(li_lote) OR li_lote = 0 THEN

        FETCH ins_lote INTO :li_lote

Para que funcione bien, la DW debe traer o inicializar correctamente `lote`. En filas nuevas conviene que `lote` quede en `0` o `NULL`. En filas existentes debe venir con el número real de lote desde la base.
