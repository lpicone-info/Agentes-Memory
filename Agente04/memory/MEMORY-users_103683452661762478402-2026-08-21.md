Julián, la función `obtenerCampos(formato)` toma el texto que escribís en el campo **Formato** y lo convierte en una lista de campos con nombre y longitud.

Está pensada para formatos de ancho fijo. Ejemplo de entrada:

```text
codigo: 5
nombre: 20
importe: 10
```

La función hace esto:

1. Divide el texto por renglones:

```javascript
.split(/\r?\n/)
```

Soporta saltos de línea tipo Windows o Linux.

2. Limpia espacios al inicio y al final de cada renglón:

```javascript
.map(function(linea) {
  return linea.trim();
})
```

3. Descarta renglones vacíos:

```javascript
.filter(Boolean)
```

4. Separa cada renglón usando separadores permitidos:

```javascript
var partes = linea.split(/[:;,=|\t]+/);
```

Acepta, por ejemplo:

```text
codigo: 5
codigo, 5
codigo; 5
codigo=5
codigo|5
codigo	5
```

5. Toma la primera parte como nombre del campo y la segunda como longitud:

```javascript
var nombre = (partes[0] || "").trim();
var longitud = parseInt((partes[1] || "").trim(), 10);
```

6. Devuelve un objeto por campo:

```javascript
{
  nombre: nombre,
  longitud: Number.isFinite(longitud) && longitud > 0 ? longitud : 0
}
```

7. Finalmente descarta campos inválidos, o sea sin nombre o con longitud menor o igual a cero:

```javascript
.filter(function(campo) {
  return campo.nombre && campo.longitud > 0;
});
```

Con este formato:

```text
codigo: 5
nombre: 20
importe: 10
```

devuelve internamente algo equivalente a:

```javascript
[
  { nombre: "codigo", longitud: 5 },
  { nombre: "nombre", longitud: 20 },
  { nombre: "importe", longitud: 10 }
]
```

Después `parsearRegistros()` usa esa lista para cortar cada registro por posiciones fijas.
