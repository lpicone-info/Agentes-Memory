## Criterio de desarrollo a documentar
- Daniel pidio documentar el criterio para que futuras propuestas puedan chequear si estan proponiendo algo ya rechazado.
- Criterio central: primero buscar la modificacion minima viable. Si el cambio requerido es pequeno/minimo, no reconstruir una estructura grande. Solo ampliar el cambio si una dependencia tecnica concreta lo obliga.
- Principio de conservacion del comportamiento previo: cuando una estructura ya funciona, la evolucion debe modificar solo lo que el requerimiento obliga, preservando configuraciones visuales, colores, listas de valores, expresiones, formatos, validaciones, relaciones con otras DataWindow y comportamientos existentes.
- Antes de reemplazar una linea o bloque completo, evaluar si alcanza con modificar una propiedad puntual o incorporar nueva logica.
- Solo se justifica una modificacion amplia si existe limitacion tecnica que impide el cambio minimo sin comprometer consistencia.
