## Cuándo se genera el mensaje

Para cada registro que sea miembro —`inte <> inte_titular`— PowerBuilder busca un registro del titular que cumpla simultáneamente:

1. `inte` del titular igual a `inte_titular` del miembro.
2. Vigencia inicial del titular menor o igual a la del miembro.
3. Si el miembro no tiene fin de vigencia, el titular tampoco debe tenerlo.
4. Si el miembro tiene fin de vigencia, el titular debe:
   - no tener fin, o
   - finalizar en una fecha mayor o igual.
5. Si el miembro tiene `baja = 'N'`, el titular también debe tener `baja = 'N'`.

La búsqueda está en [uo_desregulacion.sru](/home/luispicone/.openclaw/workspace/git/ext_waferreyra-smg-code-afilmed-MASTER-2587-Aumentos-Segmentados_20260601/ws_objects/solicitudes.pbl.src/uo_desregulacion.sru:1184).

Si no encuentra al titular entre los datos de la solicitud, ejecuta `afs_derivacion_aportes`. El mensaje se muestra cuando:

- el SP no devuelve registros, o
- devuelve registros, pero ninguno cumple todas las condiciones anteriores.
