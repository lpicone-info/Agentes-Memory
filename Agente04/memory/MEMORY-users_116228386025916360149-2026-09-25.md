## Valores posibles del Estado

| `expe_farma_recetas.ok` | Estado mostrado | Interpretación |
|---|---|---|
| `N` | **A revisar** | La receta aún no está auditada o tiene errores marcados “Por revisar”. |
| `S` | **Ok** | No quedaron errores que impidan aprobarla. |
| `R` | **Rechazada** | La receta fue rechazada completamente. |
| `X` | **Vista** | Fue auditada, conserva errores, pero el débito total es cero. |

## Qué ocurre con `expe_farma_errores`

La existencia de errores no alcanza por sí sola para mostrar “A revisar”.

Durante la auditoría, `wp_audit_receta` evalúa las filas de errores:

[wp_audit_receta.srw:1684](/home/luispicone/.openclaw/workspace/git/EXT_MaPaduan-smg-code-presmed-medico-presmed-PRS-3850-Reingenieria-LiqFarmacias_20260603/ws_objects/liqui18.pbl.src/wp_audit_receta.srw:1684)

- Si no hay errores: `ok = 'S'`.
- Si existen errores y alguno permanece con `vali = 'N'` (“Por revisar”): `ok = 'N'`.
- Si todos fueron resueltos:
  - `ok = 'R'` si la receta queda totalmente rechazada.
  - `ok = 'X'` si conserva algún ítem aprobado.

Luego PowerBuilder envía ese valor a `dbo.pru_expe_farma_recetas`, que actualiza `expe_farma_recetas.ok`.

### Entonces, los casos son:

```text
Hay error vigente + vali = 'N'
        → ok = 'N'
        → A revisar
```

```text
No hay errores
        → ok = 'S'
        → Ok
```

```text
Había errores, fueron revisados/resueltos
        → ok = 'R' o 'X'
        → Rechazada / Vista / Con Debito
```

Importante: que el error haya quedado registrado en una tabla de auditoría **no cambia automáticamente el Estado**. El Estado cambia cuando el proceso de auditoría determina el nuevo `ok` y lo persiste en `expe_farma_recetas`.

La importación también crea inicialmente las recetas con `ok = 'N'`; por eso pueden aparecer “A revisar” incluso antes de una auditoría.

**Conclusión:** “A revisar” significa técnicamente `ok = 'N'`, no simplemente “existe una fila en `expe_farma_errores`”. Las filas de errores explican el motivo, pero el valor que gobierna la columna es `expe_farma_recetas.ok`.
