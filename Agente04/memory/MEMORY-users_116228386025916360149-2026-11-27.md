## Flujo funcional

1. Se accede desde **Reintegros → Carga de recetas**.
2. El sistema muestra los expedientes de Farmacia pendientes de carga, filtrados por oficina y prepaga.
3. Se selecciona un expediente.
4. Dentro de la ventana se seleccionan farmacia y lote.
5. Solo permite trabajar con lotes abiertos:
   - `A`: habilitado.
   - `C`: lote en auditoría, bloqueado.
   - `L`: lote auditado, bloqueado.
6. Se cargan la cabecera de la receta, sus medicamentos y posibles errores.
7. Se debe ejecutar **Test**.
8. Después del testeo se habilita **Agregar/Modificar** para guardar.

## Datos de la receta

La cabecera permite informar:

- Fecha de expendio.
- Fecha de prescripción.
- Número de ticket.
- Valor total y valor a cargo del afiliado.
- Prepaga, contrato, integrante y credencial.
- Porcentaje de descuento.
- Médico prescriptor, tipo y provincia de matrícula.
- Tratamiento normal o prolongado.
- Receta común o de guardia.
- Situación terapéutica.

La búsqueda del afiliado completa nombre, plan y descuento ambulatorio. También valida la situación terapéutica disponible.

## Medicamentos

Por cada ítem se informa principalmente:

- Troquel o código de barras.
- Producto.
- Cantidad.
- Precio de venta.
- Precio a cargo del afiliado.
- Datos comerciales del medicamento.
- Autorización, cuando corresponde a PMO.

Al ingresar el producto:

- Busca el medicamento por troquel o código de barras.
- Detecta productos repetidos.
- Si se repite un código de barras, acumula la cantidad.
- Obtiene el precio vigente para la fecha de expendio.
- Calcula el importe del afiliado aplicando el descuento informado.

## Test y errores

El botón **Test** ejecuta las reglas funcionales de Farmacia sobre la receta y sus ítems. Como resultado:

- Calcula valores reconocidos para auditoría.
- Genera errores electrónicos.
- Identifica diferencias de importe o porcentaje como sobre/subfacturación.
- Permite registrar errores visuales manuales.
- Un error visual puede afectar un ítem específico o toda la receta usando ítem `0`.
- Evita duplicar el mismo error para el mismo ítem.
- Registra automáticamente el error de matrícula ilegible cuando corresponde.

Cada modificación vuelve a bloquear la grabación y obliga a ejecutar nuevamente el test.

Evidencia: [wp_carga_receta.srw](/home/luispicone/.openclaw/workspace/git/smg-code-presmed-main/ws_objects/liqui17.pbl.src/wp_carga_receta.srw:147).

## Resultado de la grabación

Al guardar:

- Inserta o modifica la cabecera en `expe_farma_recetas`.
- Reemplaza los ítems de `expe_farma_rece_items`.
- Registra errores electrónicos y visuales en `expe_farma_errores`.
- La receta queda con:
  - `ok = 'S'` si no tiene errores.
  - `ok = 'N'` si tiene al menos un error.
- En una modificación se reinician los débitos de farmacia y afiliado.
- La operación finaliza con `COMMIT`.
