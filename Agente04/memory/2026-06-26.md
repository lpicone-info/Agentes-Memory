## Redmine 29934 - Ajuste por mensaje "No hay modificaciones para grabar"

Problema reportado por Walter:

- Al modificar datos en `wp_subcta_grupo_rel`, el sistema mostraba `No hay modificaciones para grabar`.
- El flujo debe permitir:
  - Alta/grabacion de un registro nuevo.
  - Edicion posterior del mismo registro.
  - Baja del registro.

- `ue_grabar` aun tenia `call super::ue_grabar`.
- `ue_valida` aun tenia `call super::ue_valida`.
- La clase base revisaba modificaciones antes de la logica propia y no detectaba cambios porque la ventana usa `dwa_datos` para alta/edit.

- Archivo: `/mnt/Agentes/WalterF/Swiss/UPGRADE_Plan-Master-2541_Grupos-Relacionados/wp_subcta_grupo_rel.srw`.

- Se removio `call super::ue_valida` de `ue_valida`.
- Se agrego validacion explicita al inicio de `ue_grabar`:
  - `IF this.event ue_valida() < 0 THEN RETURN -1`
