## `prs_farma_expe_import_valida`

Este procedure sí tiene una validación explícita:

```sql
INSERT INTO #FARMA_EXPE_RECHA
SELECT fila_id, RECHA = 6052
FROM #FARMA_EXPE
WHERE RIGHT(#FARMA_EXPE.MATRICULA, 9) <> '000000000'
AND isnumeric(RIGHT(#FARMA_EXPE.MATRICULA, 9)) = 1
AND NOT EXISTS (
    SELECT 1
    FROM dbo.prestadores AS PRE
    WHERE baja_fecha IS NULL
    AND (
        (
            LEFT(#FARMA_EXPE.MATRICULA, 1) IN ('N', '0')
            AND isnumeric(matri_naci) = 1
            AND CONVERT(NUMERIC(15,0), RIGHT(#FARMA_EXPE.MATRICULA, 9))
                = CONVERT(NUMERIC(15,0), matri_naci)
        )
        OR
        (
            LEFT(#FARMA_EXPE.MATRICULA, 1) = 'P'
            AND isnumeric(matri_prov) = 1
            AND CONVERT(NUMERIC(15,0), RIGHT(#FARMA_EXPE.MATRICULA, 9))
                = CONVERT(NUMERIC(15,0), matri_prov)
        )
    )
)
```

### Qué valida realmente

- Matrícula con prefijo `N` o `0`: busca en `prestadores.matri_naci`.
- Matrícula con prefijo `P`: busca en `prestadores.matri_prov`.
- Solo acepta prestadores vigentes:
  ```sql
  baja_fecha IS NULL
  ```
- Cuando no encuentra coincidencia genera:
  ```text
  Rechazo 6052: Matrícula inexistente
  ```

## Limitación importante: no valida `manda + matrícula`

Aunque el procedure recibe:


la validación de matrícula **no utiliza ese parámetro**.

La condición real es:

```text
Existe algún prestador vigente con esa matrícula
```

No es:

```text
Existe esa matrícula para la mandataria indicada
```

Además, la tabla `prestadores` no contiene una columna `manda`. Por lo tanto, si la necesidad funcional exige validar el par:


## Otras limitaciones

El rechazo `6052` no se genera cuando la matrícula:

- Está vacía.
- Es `NULL`.
- No es numérica en los últimos nueve caracteres.
- Es `000000000`.

Esos casos no entran en el `NOT EXISTS`; simplemente quedan fuera de esta validación.

Tampoco comprueba:

- Que la matrícula pertenezca a una farmacia determinada.
- Que corresponda a un prestador específico.
- Que exista una única coincidencia.
- Que esté asociada a `@prm_manda`.
