- Criterio tecnico registrado:
  - Para OpenClaw version `2026.5.27`, el metodo documentado/oficial para Google Chat es el plugin `@openclaw/googlechat`.
  - El canal Google Chat de OpenClaw esta documentado como `HTTP only`.
  - Usa Google Chat API webhooks hacia el endpoint del gateway, por defecto `/googlechat`.
  - Permite conversacion con el agente por DM y spaces/grupos, similar a Discord en concepto operativo.
  - Tiene limitantes frente a Discord:
    - Requiere Google Workspace Business/Enterprise.
    - Requiere proyecto Google Cloud.
    - Requiere Google Chat API habilitada.
    - Requiere Service Account.
    - Requiere endpoint HTTPS publico para `/googlechat`.
    - DMs usan pairing por defecto.
    - En grupos/spaces conviene usar allowlist y menciones obligatorias.
  - Incoming webhook simple de Google Chat no sirve para conversar con el agente; solo permite enviar mensajes hacia Chat y no recibir eventos de usuarios.
  - Existen variantes Google Chat sin webhook HTTP publico, como Pub/Sub, Apps Script o Dialogflow, pero OpenClaw `2026.5.27` no las documenta como metodo soportado para el canal `googlechat`.
  - La alternativa segura recomendada para el metodo oficial no es eliminar el webhook, sino exponer solo `/googlechat` mediante Tailscale Funnel, Cloudflare Tunnel o reverse proxy restringido por path, sin exponer el resto del gateway.
