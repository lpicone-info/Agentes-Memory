Son expedientes con `tipo = 'S'`.

Un expediente sanatorio puede tener dos partes:
- **Parte Ambulatoria:** prestaciones ambulatorias dentro de un expediente sanatorio. En código se identifica cuando `exp.tipo = 'S' AND exp.ambu_total <> 0`.
- **Parte Internación:** prestaciones propias de internación sanatorial.

La misma lógica del código lo separa así:

```powerscript
IF (exp.tipo = 'O') OR (exp.tipo = 'S' AND exp.ambu_total <> 0) THEN
```

Eso significa: aplicar lógica de órdenes también a Sanatorio cuando tiene parte ambulatoria.

**Odontología**

También aparece referencia a `E` como “Odontología no valorizado” en selección/supervisión, pero la pantalla `wp_expe_odon` comenta explícitamente que algunas lógicas aplican solo a `D`, no a `E`.

Resumen corto:

```text
O = Órdenes
S = Sanatorio
  - ambulatorio si tiene ambu_total <> 0
  - internación para la parte sanatorial/internación
D = Odontología valorizada
E = Odontología no valorizada, según módulos de supervisión/selección
```
