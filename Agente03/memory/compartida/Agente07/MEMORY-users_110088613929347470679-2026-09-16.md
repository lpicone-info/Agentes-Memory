Facundo, validé en `SMC_Prox_Ver` y el filtro devuelve casos reales: 730 titulares vigentes.

El criterio es:
`afi_clase.clase_afi = 'E'` y contrato vigente en `subcta_contratos.modo_fac = 'E'`.

```sql
DECLARE @fecha smalldatetime

SELECT @fecha = GETDATE()

SELECT
    A.prepaga,
    A.contra,
    A.inte,
    A.ape,
    A.nombre,
    A.paren,
    A.docu_tipo,
    A.docu_nro,
    AC.clase_afi,
    AC.cuenta,
    C.razon AS cuenta_razon,
    AC.subcta,
    S.deno AS subcta_deno,
    SC.modo_fac,
    SC.vigen_desde AS vigen_desde_contrato
FROM afiliados A
INNER JOIN afi_clase AC
ON  AC.prepaga = A.prepaga
AND AC.contra = A.contra
INNER JOIN subcta_contratos SC
ON  SC.cuenta = AC.cuenta
AND SC.subcta = AC.subcta
INNER JOIN cuentas C
ON C.cuenta = AC.cuenta
INNER JOIN subcuentas S
ON S.cuenta = AC.cuenta
AND S.subcta = AC.subcta
WHERE AC.clase_afi = 'E'
AND SC.modo_fac = 'E'
AND A.paren = 'T'
AND (A.baja_fecha IS NULL OR A.baja_fecha > @fecha)
AND (AC.baja_fecha IS NULL OR AC.baja_fecha > @fecha)
AND AC.vigen_desde = (
    SELECT MAX(AC2.vigen_desde)
    FROM afi_clase AC2
    WHERE AC2.prepaga = AC.prepaga
    AND AC2.contra = AC.contra
    AND AC2.vigen_desde <= @fecha
    AND (AC2.baja_fecha IS NULL OR AC2.baja_fecha > @fecha)
)
AND (SC.baja_fecha IS NULL OR SC.baja_fecha > @fecha)
AND SC.vigen_desde = (
    SELECT MAX(SC2.vigen_desde)
    FROM subcta_contratos SC2
    WHERE SC2.cuenta = SC.cuenta
    AND SC2.subcta = SC.subcta
    AND SC2.vigen_desde <= @fecha
    AND (SC2.baja_fecha IS NULL OR SC2.baja_fecha > @fecha)
)
AND C.baja_fecha IS NULL
AND S.baja_fecha IS NULL
ORDER BY
    C.razon,
    S.deno,
    A.contra,
    A.inte
```

El `A.paren = 'T'` lo dejé para obtener el titular del contrato. Para traer todos los integrantes de esos contratos, se quita esa condición.
