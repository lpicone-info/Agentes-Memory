El punto fino: aunque ese error está con `baja_fecha`, el código del SP no filtra `ee.baja_fecha IS NULL` en esa eliminación para honorarios. Entonces igual lo toma y borra el candidato de copago antes de insertar en `expe_copagos`.

La condición está en `pru_expe_copagos`:

```sql
IF @tipo = 'H'
  DELETE #copa
  FROM expe_errores ee
  WHERE ee.ofi = @ofi
    AND ee.expe = @expe
    AND ee.item = #copa.item
    AND ee.esta = 'P'
    AND ee.vali = 'S'
    AND ee.real_valor = 0
```

Conclusión: no es falta de configuración de copago. Es el error `21` del item 7 en `expe_errores`, con `real_valor = 0`, que sigue impactando el cálculo porque el SP no considera `baja_fecha`.
