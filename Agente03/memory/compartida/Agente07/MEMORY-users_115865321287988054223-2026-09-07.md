Resumen práctico:

```text
Solo copago por prestación vigente           => cobra prestación
Solo copago por orden vigente                => cobra orden
Ambos vigentes + criterio Suma               => cobra ambos
Ambos vigentes + criterio Reemplaza/Reemp    => cobra el de orden en lugar del de prestación
```

Aclaración importante: “Paga al prestador” indica **quién cobra el copago**, no define si suma o reemplaza. La decisión de cobrar uno u otro o ambos la define el criterio `Suma/Reemplaza` del copago por orden.
