```xml

    <ApellidoPrescriptor>...</ApellidoPrescriptor>
  </Prescriptor>

```

El servicio lee esos tags así:

```text
ProvinciaPrescriptor      -> ori_matri_prov_provin
NroMatriculaPrescriptor   -> ori_matri_prov / ori_matri_naci
ApellidoPrescriptor       -> ori_nombre
```

Para tu caso, el prestador existe en base como:

```text
prestad = 170
ape_razon = ROLDAN
nombre_abre = HUGO
matri_prov = A94783
matri_prov_provin = 2
provincia = BUENOS AIRES
cod_activia = B
```

El XML que pasaste manda:

```xml
<ProvinciaPrescriptor>A</ProvinciaPrescriptor>
<NroMatriculaPrescriptor>A94783</NroMatriculaPrescriptor>
<ApellidoPrescriptor>ROLDAN, HUGO</ApellidoPrescriptor>
```

Ese `A` se traduce como provincia `10 - SALTA`, no como Buenos Aires. Por eso en la transacción quedó:

```text

ori_matri_prov_provin = 10
ori_nombre = ROLDAN, HUGO
```

```xml
<Prescriptor>
```
