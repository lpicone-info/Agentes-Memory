Cuando se tilda:

- El sistema exporta los comprobantes seleccionados.
- Luego crea los comprobantes de cobro/recibo correspondientes.
- Aplica esos pagos contra las facturas o débitos incluidos en el lote.
- Usa la **Fecha Acreditación** informada como fecha del pago/acreditación.
- Los comprobantes quedan procesados dentro del lote, es decir, ya no quedan pendientes de aplicación para una corrida posterior.

En forma simple: **si no se tilda, solo se arma/exporta el archivo; si se tilda, además se impactan los pagos en cuenta corriente**.

Texto sugerido:

“La opción ‘Aplica los pagos’ indica que, además de generar el archivo de débitos, el sistema debe registrar automáticamente la cobranza de los comprobantes exportados. Al estar tildada, por cada comprobante del lote se genera el recibo correspondiente y se aplica el pago usando la Fecha Acreditación indicada. Esto hace que los comprobantes exportados queden cobrados/aplicados en la cuenta corriente. Si no se tilda, la exportación genera el archivo y registra el lote, pero no impacta automáticamente los pagos.”
