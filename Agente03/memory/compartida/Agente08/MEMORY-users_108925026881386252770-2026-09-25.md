2. **Padrón actual:** para el período **Hasta 08/2026**, considera quiénes se encuentran activos al **01/08/2026**.

Para estar incluido en el padrón actual, el afiliado debe:

- haber ingresado hasta el 01/08/2026;
- no tener fecha de baja; o
- tener una baja posterior a esa fecha.

Cuando una persona estaba en el padrón anterior, pero ya no corresponde incluirla en el padrón actual, el sistema genera un movimiento de baja `B`.

Como el nuevo período comienza el **01/08/2026**, el último día en que esa persona perteneció al padrón anterior es el **31/07/2026**. Por eso esa es la fecha que se informa en el archivo.

### Ejemplo

Un grupo familiar tiene:

- `00`: titular
- `01`: cónyuge
- `02`: hijo

**Si se da de baja todo el grupo**, el archivo genera una baja para `00`, `01` y `02`, todos con fecha **31/07/2026**.

**Si se da de baja solamente al integrante 02**, el archivo genera la baja únicamente para `02` con fecha **31/07/2026**. El titular y el integrante 01 continúan activos.

        CASE
            WHEN a.campo = 'Vigencia Desde'
            AND ISDATE(a.valor_nuevo) = 1
            THEN CONVERT(DATETIME, a.valor_nuevo, 103)
        END,
        alta.Periodo_Alta,
        valor.Periodo_Por_Valor
    ), 103) AS Periodo_Afectado,
    CONVERT(CHAR(10), a.fecha_hora, 103) AS Fecha,
    CONVERT(CHAR(8), a.fecha_hora, 108) AS Hora,
    TRIM(a.usuario) AS Usuario,
    a.activi AS Actividad,
    a.campo AS Campo,
    a.valor_anterior AS Valor_Anterior,
    a.valor_nuevo AS Valor_Nuevo
FROM conve_prestac_valores_auditoria a
INNER JOIN conve_prestaciones cp
    ON cp.conve_prestac = a.conve_prestac
OUTER APPLY
(
    SELECT
        MAX(CONVERT(DATETIME, a2.valor_nuevo, 103)) AS Periodo_Alta
    FROM conve_prestac_valores_auditoria a2
    WHERE a2.conve_prestac = a.conve_prestac
    AND a2.fecha_hora = a.fecha_hora
    AND a2.activi = 'Alta de valores para los convenios'
    AND a2.campo = 'Vigencia Desde'
    AND ISDATE(a2.valor_nuevo) = 1
) alta
OUTER APPLY
(
    SELECT TOP 1
        cpv.vigen_desde AS Periodo_Por_Valor
    FROM conve_prestac_valores cpv
    WHERE cpv.conve_prestac = a.conve_prestac
    AND cpv.baja_fecha IS NULL
    AND ISNUMERIC(a.valor_nuevo) = 1
    AND cpv.valor = CONVERT(DECIMAL(18,2), a.valor_nuevo)
    ORDER BY cpv.vigen_desde
) valor
WHERE cp.conve = @convenio
