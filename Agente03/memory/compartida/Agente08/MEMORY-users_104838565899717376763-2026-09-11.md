Inge, la consulta de detección utilizada en `Sos_prod` es la siguiente. Identifica expedientes potencialmente afectados por tener `prepaga = -1`, estar liquidados, poseer copagos activos y no tener ajustes internos activos:

```sql
SELECT
  'RESUMEN' AS bloque,
  COUNT(*) AS expedientes_afectados,
  SUM(x.items_copago) AS items_con_copago,
  SUM(x.total_copago) AS total_copago
FROM (
  SELECT
    e.ofi,
    e.expe,
    COUNT(DISTINCT ec.item) AS items_copago,
    SUM(ec.valor * ec.canti) AS total_copago
  FROM expedientes e
  INNER JOIN expe_copagos ec
    ON ec.ofi = e.ofi
   AND ec.expe = e.expe
   AND ec.baja_fecha IS NULL
   AND ec.pago_copa = 'C'
  WHERE e.tipo = 'O'
    AND e.prepaga = -1
    AND e.liqui_fecha IS NOT NULL
    AND e.baja_fecha IS NULL
    AND NOT EXISTS (
      SELECT 1
      FROM aju_internos ai
      WHERE ai.ori_ofi = e.ofi
        AND ai.ori_expe = e.expe
        AND ai.baja_fecha IS NULL
    )
  GROUP BY e.ofi, e.expe
) x

GO

SELECT
  e.ofi,
  e.expe,
  e.perio,
  e.fecha,
  e.liqui_fecha,
  e.compro_tipo,
  e.compro_nro,
  COUNT(DISTINCT ec.item) AS items_copago,
  SUM(ec.valor * ec.canti) AS total_copago
FROM expedientes e
INNER JOIN expe_copagos ec
  ON ec.ofi = e.ofi
 AND ec.expe = e.expe
 AND ec.baja_fecha IS NULL
 AND ec.pago_copa = 'C'
WHERE e.tipo = 'O'
  AND e.prepaga = -1
  AND e.liqui_fecha IS NOT NULL
  AND e.baja_fecha IS NULL
  AND NOT EXISTS (
    SELECT 1
    FROM aju_internos ai
    WHERE ai.ori_ofi = e.ofi
      AND ai.ori_expe = e.expe
      AND ai.baja_fecha IS NULL
  )
GROUP BY
  e.ofi,
  e.expe,
  e.perio,
  e.fecha,
  e.liqui_fecha,
  e.compro_tipo,
  e.compro_nro
ORDER BY
  e.perio DESC,
  e.expe DESC
```

El primer bloque devuelve el resumen total y el segundo, el detalle de cada expediente detectado.
