Nicolas, para expedientes de **Farmacia**, el campo `conta_movimientos_expe.saldo` se calcula **por cada receta vigente** con esta fórmula:

```text
saldo =
    (rece_vta_valor - rece_afi_valor)
    - (rece_vta_valor × farma_dto / 100)
```

Luego se trunca a dos decimales:

```sql
ROUND(
    (rece_vta_valor - rece_afi_valor)
    - ((rece_vta_valor * farma_dto) / 100.00),
    2,
    1
)
```

### Campos utilizados

- `expe_farma_recetas.rece_vta_valor`: importe total de venta de la receta.
- `expe_farma_recetas.rece_afi_valor`: importe a cargo del afiliado.
- `expe_farmacias.farma_dto`: porcentaje de descuento de la farmacia.

Los valores nulos se consideran `0`.

### Ejemplo

```text
rece_vta_valor = 1.000
rece_afi_valor =   400
farma_dto      =    10%
```

```text
saldo = (1.000 - 400) - (1.000 × 10 / 100)
saldo = 600 - 100
saldo = 500
```
