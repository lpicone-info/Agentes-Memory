Para validar una URL en PowerBuilder, separá dos controles:

1. **Validez sintáctica**: que tenga formato de URL.
2. **Disponibilidad real**: que responda por HTTP/HTTPS.

Ejemplo simple para formato:

```powerscript
boolean lb_valida
string ls_url

ls_url = Trim(as_url)

lb_valida = Match(ls_url, "^(http|https)://[A-Za-z0-9.-]+(:[0-9]+)?(/.*)?$")
```

Uso recomendado:

```powerscript
IF NOT Match(Trim(ls_url), "^(http|https)://[A-Za-z0-9.-]+(:[0-9]+)?(/.*)?$") THEN
   MessageBox("Validación", "La URL no tiene un formato válido.")
   RETURN
END IF
```

Eso valida formato básico. No garantiza que la URL exista ni que el servidor responda.

Para validar conexión real, en PowerBuilder podés usar un objeto `inet` con `GetURL`, por ejemplo:

```powerscript
inet lnv_inet
integer li_rc
string ls_response

lnv_inet = CREATE inet

li_rc = lnv_inet.GetURL(ls_url, ls_response)

IF li_rc = 1 THEN
   MessageBox("Validación", "La URL respondió correctamente.")
ELSE
   MessageBox("Validación", "La URL no respondió o no es accesible.")
END IF

DESTROY lnv_inet
```

Criterio técnico: usá `Match` para validar que el texto sea una URL aceptable antes de intentar navegar o consumirla, y `inet.GetURL` solo si necesitás comprobar accesibilidad real.
