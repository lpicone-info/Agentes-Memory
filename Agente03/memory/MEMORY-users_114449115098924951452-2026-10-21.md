## Solución recomendada

### 1. Generar una solicitud por contrato seleccionado

El cursor debería partir de contratos distintos con `AT` o `AU`:

```sql
SELECT DISTINCT
       ai.prepaga,
       ai.contra
FROM AFI_IMPORTACIONES_ISSS ai
INNER JOIN TMP_AFI_IMPORTACIONES_ISSS ti
        ON ti.sp_id     = @prm_sp_id
       AND ti.prepaga   = ai.prepaga
       AND ti.file_nro  = ai.file_nro
       AND ti.linea_nro = ai.linea_nro
WHERE ai.cod_op IN ('AT', 'AU')
AND ISNULL(ai.ok, '') <> 'N'
AND ai.soli IS NULL;
```

Luego determinar el motivo:

```text
Si existe AT → motivo 1
Si sólo existen AU → motivo 2
```

Esto permitiría:

- alta completa de un grupo nuevo;
- alta de integrantes sobre un contrato existente;
- una sola solicitud por contrato;
- todos los integrantes seleccionados vinculados a esa solicitud.

La definición exacta de una o varias solicitudes para múltiples `AU` del mismo contrato debe confirmarse funcionalmente.

### 2. Limitar las actualizaciones a la selección
