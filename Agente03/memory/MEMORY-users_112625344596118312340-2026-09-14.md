### [14/09/2026 15:29:21] Agente

Cristian, en concreto las demoras provienen de estos puntos:

1. **Generación individual del archivo PSR**
   - En `wp_gene_crede_provi.wf_enviar_mail`, por cada afiliado se ejecuta `SaveAs(..., PSReport!, TRUE)`.
   - Es una operación de impresión/exportación a archivo y se repite una vez por credencial.

2. **Espera activa del archivo PSR**
   - Luego de generar el PSR, el código espera hasta 10 segundos con `SLEEP(1)` si el archivo todavía no aparece.
   - Esto bloquea la ventana y puede acumularse para varios afiliados.

3. **Procesamiento estrictamente secuencial**
   - Las credenciales se procesan una detrás de otra.
   - Para 50 afiliados, el tiempo total termina siendo la suma de generación, lectura, persistencia y espera de cada registro.

4. **Varias operaciones de base por cada mail**
   Para cada credencial se ejecutan llamadas separadas para:
   - `mai_mail_envio`
   - `mai_mail_to`
   - `mai_mail_attach_binary`
   - `mai_mail_proceso_llamador_creden`
   - `mau_mail_envio_send`

   Además, se recupera la configuración del mail dentro del ciclo mediante `mas_mail_procesos_text`.

5. **Lectura completa del PSR como BLOB**
   - El archivo generado se vuelve a abrir y leer completo antes de guardarlo en `MAIL_ATTACH_BINARY`.
   - Esto agrega uso de disco, memoria y transferencia hacia SQL Server.

6. **Conversión posterior PSR a PDF en Infomailer**
   - `nvo_main_infomailer.ue_procesar` toma el PSR y lo convierte a PDF usando Bullzip.
   - La espera actual tiene esta lógica:

   ```powerscript
   DO WHILE (NOT FileExists(...) OR ll_intentos <= 100)
   ```

   Por usar `OR`, continúa esperando aunque el PDF ya exista. Esto puede agregar más de 10 segundos por adjunto.

7. **Envío SMTP posterior**
   - Infomailer recién después convierte los adjuntos y ejecuta el envío SMTP.
   - Puede agregar demora por conexión, autenticación o respuesta del servidor, pero no es la causa principal demostrada en el análisis.

**Resumen:** para la demora de la pantalla, los principales responsables son `SaveAs` del PSR, la espera activa del archivo, el procesamiento secuencial y las múltiples grabaciones por mail. Para la demora total hasta que el correo llega, se suma la conversión PSR/PDF y el envío de Infomailer.
