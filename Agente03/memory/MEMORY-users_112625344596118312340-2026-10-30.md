## 5. Ver por qué el motor eligió Empresa

```sql
DECLARE @prepaga SMALLINT = 2
DECLARE @contra CHAR(15) = '106958'
DECLARE @fecha SMALLDATETIME = '20261002'

SELECT
    AC.prepaga,
    AC.contra,
    AC.clase_afi,
    AC.cuenta,
    AC.subcta,
    AC.vigen_desde AS clase_vigen_desde,
    SC.modo_fac,
    SC.modo_fac_def,
    SC.vigen_desde AS modalidad_vigen_desde,
    CU.razon AS cuenta_razon
FROM AFI_CLASE AS AC
INNER JOIN SUBCTA_CONTRATOS AS SC
    ON SC.cuenta = AC.cuenta
    AND SC.subcta = AC.subcta
LEFT JOIN CUENTAS AS CU
    ON CU.cuenta = AC.cuenta
WHERE AC.prepaga = @prepaga
AND AC.contra = @contra
AND AC.vigen_desde =
(
    SELECT MAX(X.vigen_desde)
    FROM AFI_CLASE AS X
    WHERE X.prepaga = AC.prepaga
    AND X.contra = AC.contra
    AND X.vigen_desde <= @fecha
    AND
    (
        X.baja_fecha IS NULL
        OR X.baja_fecha > @fecha
    )
)
AND SC.vigen_desde =
(
    SELECT MAX(X.vigen_desde)
    FROM SUBCTA_CONTRATOS AS X
    WHERE X.cuenta = SC.cuenta
    AND X.subcta = SC.subcta
    AND X.vigen_desde <= @fecha
    AND
    (
        X.baja_fecha IS NULL
        OR X.baja_fecha > @fecha
    )
)
```

Resultado relevante:

```text
clase_afi    = E
modo_fac     = E
modo_fac_def = E
cuenta       = 12241
subcta       = 2
```

Esa modalidad hace que el código actual transforme el COP en facturación empresarial, aunque el ajuste tenga `ori_sucur`, `ori_auto` y concepto `COP`.
