Cristian, en `trunk@84927` existen **cinco tipos funcionales de `MBox`**, determinados por el parámetro `fb_tipo`.

## Tipos de MBox

| Tipo | Finalidad | Comportamiento |
|---:|---|---|
| `1` | Información o validación común | Muestra el mensaje con icono `Information!`. No genera log ni rollback. |
| `2` | Error interno o de base de datos | Genera `sistema.err`, registra información de `SQLCA`, ejecuta `ROLLBACK` y muestra el mensaje con `Stopsign!`. |
| `3` | Advertencia | Muestra `Aviso:` seguido del mensaje, con icono `Exclamation!`. |
| `4` | Pregunta al usuario | Muestra icono `Question!`, botones configurables y devuelve qué botón seleccionó el usuario. |
| `5` | Registro de proceso automatizado | Genera `sistema.log` con el mensaje y contexto de conexión. No muestra ventana al usuario. |

## Tipo 4: botones

El cuarto parámetro, `fb_boton`, determina los botones:

### `fb_boton = 2`

```powerscript
OkCancel!
```

- Retorno `1`: Aceptar.
- Retorno `2`: Cancelar.

### Cualquier otro valor

```powerscript
YesNoCancel!
```

- Retorno `1`: Sí.
- Retorno `2`: No.
- Retorno `3`: Cancelar.

Aunque el comentario indica `fb_boton = 1`, la implementación realmente usa `YesNoCancel!` para cualquier valor distinto de `2`.

## Efectos importantes

### Tipo 2

Es el más delicado porque, además de mostrar un error:

```powerscript
ROLLBACK
```

También registra:

- usuario;
- ventana;
- actividad;
- código SQL;
- código de base;
- servidor;
- base;
- mensaje de `SQLCA`.

Si la configuración del error indica acción `9`, ejecuta:

```powerscript
Halt Close
```

### Tipo 5

Registra información en:

```text
sistema.log
```

Pero no presenta un `MessageBox` visual.

## Formas de invocación

### Función global completa

```powerscript
MBox(ventana, mensaje, tipo, botones)
```

Ejemplo:

```powerscript
MBox(THIS, 'Se produjo un error', 2, 0)
```

### Método heredado de `w_clase`

```powerscript
MBox(mensaje)
```

Equivale a:

```powerscript
MBox(THIS, mensaje, 1, 0)
```

También existe:

```powerscript
MBox(mensaje, tipo, botones)
```

que agrega automáticamente `THIS` como ventana.

### Sin ventana

```powerscript
MBoxWithoutWindow(mensaje, tipo, botones)
```

Internamente llama a `MBox` con una ventana nula. En ese caso el título mostrado es:

```text
Atención
```

## Resumen

- Hay **5 tipos funcionales**.
- Hay **3 formas prácticas de invocación**: global, método heredado de `w_clase` y `MBoxWithoutWindow`.
- Los tipos `1` y `3` solamente informan.
- El tipo `2` registra el error y hace rollback.
- El tipo `4` solicita una decisión y devuelve la opción elegida.
- El tipo `5` registra un evento automatizado sin mostrar mensaje.
