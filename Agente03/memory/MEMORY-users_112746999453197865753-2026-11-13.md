- debe existir un comprobante relacionado válido;
- si falta, ARCA normalmente debería devolver una validación FCE, no necesariamente `10060`.

Si el circuito genera una `NC/ND` común sin relación, sí puede aparecer `10060` por el fallback.

li_File = FileOpen('AFIP_CAE.xml', LineMode!, Write!, LockWrite!, Replace!)

li_File = FileOpen('AFIP_CAE.xml', LineMode!, Write!, LockWrite!, Replace!)
