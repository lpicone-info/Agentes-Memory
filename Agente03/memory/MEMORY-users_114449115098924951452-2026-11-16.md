## Diferencia principal

El circuito ISSS funciona así:

1. `afi_import_batch_isss` actualiza directamente las tablas definitivas.
2. `afi_afu_isss_ddjj` y `afi_afu_isss_trans` reprocesan aportes.
3. `afi_insert_soli_altas_isss` reconstruye después una solicitud con estado finalizado:
   - `SOLI_AFILIADOS.esta = 'F'`
   - `actu_fecha = GETDATE()`

Una solicitud convencional hace el recorrido inverso:

```text
SOLICITUDES / SOLI_*
        ↓
afu_soli_abordar1
        ↓
procedimientos específicos
        ↓
AFILIADOS / AFI_*
```

Por eso la solicitud generada por ISSS funciona principalmente como registro histórico; **no ejecuta el flujo estándar completo**.
