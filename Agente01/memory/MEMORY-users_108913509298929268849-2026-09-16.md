### [16/09/2026 16:41:25] Agente

El XML que mostraste es **venta nueva**, no inclusión.

La clave es:

```xml
soli_moti="1"
```

En el proceso:

```text
soli_moti = 1 -> Alta Total -> Venta nueva
soli_moti = 2 -> Alta Parcial -> Inclusión
```

Por lo tanto:

- `OPLF / FPLUNQ` identifica una cobertura **familiar**.
- `soli_moti="1"` indica que se crea un **contrato nuevo** para ese grupo familiar.
- El `contra="303450013"` informado en el XML no convierte la operación en inclusión; para `soli_moti=1` el proceso genera la venta nueva sin contrato previo.

La inclusión sería otro escenario:

```xml
soli_moti="2"
```

y debería partir de un contrato existente, agregando uno o más integrantes al grupo ya afiliado.

Entonces, la denominación correcta sería:
