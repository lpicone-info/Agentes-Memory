Savina, revisé el trunk `svarela-Version104-Afilmed-SolicitudesAutomaticas`. Para **traslado a contrato nuevo** el motivo es `soli_moti = 47`.

**Regla funcional**
El TAG a usar depende del tipo de cuenta destino:

- **Cuenta individual**: debe venir `responsable_pagador`.
- **Cuenta colectiva**: debe venir `empleado`.
- `responsable_pagador` y `empleado` son excluyentes. No pueden venir juntos.
- El TAG `integrantes` siempre representa las personas que se trasladan desde el contrato origen al contrato nuevo.
- El `empleado` no se considera integrante trasladado. No necesita `anter_prepa`, `anter_contra` ni `anter_inte`.

**Uso con `integrantes`**
Para cuenta individual:

```xml
<responsable_pagador docu_tipo="CC" docu_nro="..." ape="..." nombre="..." ... />

<integrantes>
  <integrante inte="01"
              anter_prepa="1"
              anter_contra="1000146"
              anter_inte="02"
              paren_destino="T"
              paren_real_destino="T"
              docu_tipo="CC"
              docu_nro="..." />
</integrantes>
```

Para cuenta colectiva:

```xml
<empleado docu_tipo="CC" docu_nro="..." ape="..." nombre="..." ... />

<integrantes>
  <integrante inte="01"
              anter_prepa="1"
              anter_contra="1000146"
              anter_inte="02"
              paren_destino="T"
              paren_real_destino="T"
              docu_tipo="CC"
              docu_nro="..." />
</integrantes>
```

En colectivo, los contactos del empleado van con `tipo_reg="E"`:

```xml
<contactos>
  <domicilio tipo_reg="E" ... />
  <telefono tipo_reg="E" ... />
  <email tipo_reg="E" ... />
</contactos>
```

Los contactos de integrantes trasladados van con `tipo_reg="I"` y su `inte`.

**Mensajes de error relevantes**

- `El XML no debe informar responsable_pagador y empleado en la misma solicitud`
- `El XML no debe informar responsable_pagador para traslado a contrato nuevo colectivo`
- `El XML debe informar empleado para traslado a contrato nuevo colectivo`
- `El XML no debe informar empleado para traslado a contrato nuevo individual`
- `El XML debe informar responsable_pagador para traslado a contrato nuevo`
- `El XML informa responsable_pagador sin datos obligatorios de traslado a contrato nuevo`
- `El XML informa empleado sin datos obligatorios de traslado a contrato nuevo colectivo`
- `El XML debe informar domicilio del empleado o existir domicilio vigente en Registro Unico`
- `El XML debe informar telefono del empleado o existir telefono vigente en Registro Unico`
- `El XML debe informar email del empleado o existir email vigente en Registro Unico`
- `Existen integrantes sin datos obligatorios de traslado a contrato nuevo`
- `No existe afiliado origen vigente para uno o mas integrantes del traslado a contrato nuevo`

**Conclusión**
La regla correcta es: `responsable_pagador` para individual, `empleado` para colectivo, siempre junto con `integrantes` para las personas realmente trasladadas. El empleado colectivo es un dato del contrato/pagador laboral, no una persona trasladada desde el contrato origen.
