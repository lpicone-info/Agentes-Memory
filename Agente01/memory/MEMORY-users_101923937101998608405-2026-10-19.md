## Casos donde no debe enviarse vacío

Por ejemplo:

```xml

```

no equivale necesariamente a omitirlo. Como el atributo existe, puede entrar en la validación que solo admite `S` o `N` y provocar rechazo. Si no aplica, debe omitirse:

```xml

```

Lo mismo aplica especialmente a:

- Fechas.
- Identificadores numéricos.
- Códigos de catálogo.
- Indicadores que admiten únicamente `S` o `N`.
- Campos condicionales como `soli_recha`, documentos de madre, campaña o seguro.


```xml

```

Lo mismo aplica a:

```xml
<preexistencias />
<notas />
<observaciones />
```
