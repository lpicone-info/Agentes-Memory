## Circuito técnico

```text
Comprobante legal FC/NC/ND
→ COMPROBANTES_RESOLUCION_DIAN: INSERTED
→ generación de xml_contenido
→ PENDING
→ SOAP Upload
→ UPLOADED + transactionId
→ DocumentStatus
├─ ACCEPTED
├─ RECEIVED/RETRY → nueva consulta
├─ REJECTED → Download DIAN_RESULT
└─ FAIL → registrar error Carvajal
→ descarga de PDF y XML firmado
```

El Batch repite el circuito aproximadamente cada minuto y contempla reintentos automáticos.
