```text
RECEIVED / RETRY

ACCEPTED

→ guardar en carpetas compartidas
→ marcar pdf/signed_xml en SQL

REJECTED
→ descargar DIAN_RESULT
→ registrar errores
→ habilitar reproceso

FAIL
→ registrar error
→ reintentar/reprocesar

→ escribir en log
→ desconectar
→ volver a intentar en el ciclo siguiente
```

## 3. Orden interno ejecutado por el Batch

```text
1. UPLOAD

3. PDF
4. SIGNED_XML
5. FAIL
6. REJECTED
```

Antes de `UPLOAD`:

```text
INSERTED
→ generar contenido XML
→ actualizar a PENDING
```

Después del `Upload`:

```text
PENDING
→ enviar XML Base64
→ recibir transactionId

```
