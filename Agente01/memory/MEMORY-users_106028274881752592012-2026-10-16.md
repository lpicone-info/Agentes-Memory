1. Chilkat no está instalado.
2. Está instalado, pero la DLL ActiveX/COM no está registrada.
3. Está instalada otra versión —por ejemplo Chilkat 10— que no publica el ProgID `Chilkat_9_5_0.*`.

7. Instalación dañada, dependencias faltantes o registro COM inaccesible.

## Qué no produce este error

El `-2` ocurre antes de:

- validar la licencia;
- resolver el servidor COBIS;
- abrir la conexión FTP/SFTP;

- seleccionar el directorio remoto;
- subir el archivo.

Por eso **no corresponde a firewall, puerto, credenciales de COBIS, disponibilidad del servidor, ruta remota ni licencia vencida**. Esas fallas generarían mensajes posteriores mediante `LastErrorText`.
