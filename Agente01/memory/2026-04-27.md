# 2026-04-27

- OpenClaw boot debugging: for `/new` and `/reset`, patching only `dist/bundled/boot-md/handler.js` is not enough. The bundled hook metadata file `dist/bundled/boot-md/HOOK.md` also must declare `"events": ["gateway:startup", "command:new", "command:reset"]`, because the loader registers internal hook listeners from HOOK.md metadata.
- Runtime findings from boot investigation: workspace bootstrap injection included `AGENTS.md`, `SOUL.md`, `TOOLS.md`, `IDENTITY.md`, `USER.md`, `HEARTBEAT.md`, `BOOTSTRAP.md` but not `BOOT.md`; original bundled `boot-md` only ran on `gateway:startup` until patched.
- Active OpenClaw config change applied in `~/.openclaw/openclaw.json`: `agents.defaults.bootstrapMaxChars = 32000` to avoid startup truncation of `REGLAS.md` (default observed was 12000; `bootstrapTotalMaxChars` 60000; `toolResultMaxChars` 16000).
- Workspace bootstrap hardening changes made: `REGLAS.md` now ends with exact marker `<!-- EOF REGLAS.md -->`; `BOOT.md` and `BOOTSTRAP.md` now require segmented reads of `REGLAS.md` in chunks of at most 12 lines until that EOF marker is reached.
- `BOOT.md` also now requires visible confirmation text `BOOTSTRAP COMPLETO` only after the full bootstrap sequence succeeds. This proves bootstrap completion when the boot run is actually delivered visibly.
