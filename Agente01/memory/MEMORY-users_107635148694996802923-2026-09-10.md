### [10/09/2026 11:37:35] Agente

El código vigente de ICDS sale del catálogo:

`dbo.ICDS`

Campos principales:

- `icd`: código ICD, `CHAR(6)`
- `deno`: descripción
- `baja_fecha`: vigencia

Para obtener únicamente códigos vigentes:

```sql
SELECT icd, deno
FROM dbo.ICDS
WHERE baja_fecha IS NULL
```

En el proceso de solicitudes automáticas, el valor informado en:

```xml
<preexistencia icd="E119" />
```

se valida contra `ICDS.icd`.

Luego se almacena en:

- `SOLI_PREEXISTENCIAS.icd`
- `AFI_PREEXISTENCIAS.icd`

La referencia del catálogo está en [ICDS.sql](/home/luispicone/.openclaw/workspace/svn/svarela-Version104-Afilmed-SolicitudesAutomaticas/backend/tables/ICDS.sql:2) y la consulta vigente en [prs_icds.sql](/home/luispicone/.openclaw/workspace/svn/svarela-Version104-Afilmed-SolicitudesAutomaticas/backend/procedures/prs_icds.sql:9).
