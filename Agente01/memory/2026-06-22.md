## Hallazgos tecnicos

- El mensaje se genera explicitamente en `backend/procedures/afu_fac_camp_comercial_errores.sql`.
- El procedimiento contiene la regla funcional comentada: se insertan como error de prefacturacion los casos con tarifa por `Parentesco + categoria` y luego se borran de la estructura de campanas para que no calculen descuento.
- El error se inserta en `#FAC_PREPROCESOS_ERR` con comentario `Los descuentos de campanas no aplican a tarifas de tipo Parentesco mas Categoria`.
- La condicion tecnica que dispara el caso es `FAC.tari_tipo = 'Q'`.
- El tipo `Q` corresponde a `Parentesco mas Categoria` / `Categoria y Parentescos`.
- Evidencias de tipo tarifa:
  - `backend/data_modifications/TARI_TIPOS.sql`
  - `backend/procedures/afs_fac_planmed_general.sql`
  - `backend/procedures/afu_fac_plan_actualiza_categ_paren.sql`
- El proceso no continua facturando normalmente sin descuento:
  - `afu_fac_camp_comercial_errores.sql` deja el error en temporales.
  - `afs_fac_mover_prepro_auxiliar.sql` mueve errores a `#FAC_PREFACTURAS_ERR`.
  - `afs_facturar_prefacturar.sql` elimina de `#FAC_PREFACTURAS` los movimientos de contratos con errores.
- Conclusion funcional: el inconveniente es bloqueante para prefacturacion/facturacion, no solo una advertencia.

## Accion recomendada

Para poder prefacturar/facturar febrero 2026, el contrato no debe llegar al proceso con la campana activa para ese periodo.

Como el menu no permite baja por origen `Venta Nueva`, la alternativa operativa controlada es cerrar vigencia en `AFI_CAMPANIAS` al `2026-01-31`, preservando historia hasta enero.

SQL propuesto, pendiente de confirmacion explicita antes de ejecutar cualquier update:

```sql
BEGIN TRAN

UPDATE AFI_CAMPANIAS
SET vigen_hasta = '20260131',
    modi_fecha = GETDATE()
WHERE prepaga = 1
AND contra = '1093141'
AND inte = '01'
AND cod_camp_comercial = 305
AND vigen_desde = '20250801'
AND vigen_hasta = '20260228'
AND baja_fecha IS NULL
AND soli = 4843445
AND soli_moti_origen = 1

SELECT @@ROWCOUNT AS filas_actualizadas

SELECT prepaga, contra, inte, cod_camp_comercial, vigen_desde, vigen_hasta,
       baja_fecha, soli, soli_moti_origen
FROM AFI_CAMPANIAS
WHERE prepaga = 1
AND contra = '1093141'
AND inte = '01'
AND cod_camp_comercial = 305

COMMIT TRAN
```

Luego se debe regenerar la prefacturacion del contrato para `02/2026`.
