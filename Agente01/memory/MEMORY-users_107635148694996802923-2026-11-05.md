## Reapertura por script

Para que el período vuelva a aparecer abierto en la ventana deben limpiarse **ambos campos**:

- `fecha_cierre`: es lo que valida `afi_procesa_comisiones`.
- `usu_cierre`: es lo que usa PowerBuilder para considerar visualmente el período cerrado.

Script mínimo controlado:

```sql
DECLARE @periodo DATETIME

SET @periodo = '20260901'

BEGIN TRANSACTION

IF NOT EXISTS
(
    SELECT 1
    FROM COMISIONES_MOVIMIENTOS_PERIODOS
    WHERE periodo = @periodo
    AND fecha_cierre IS NOT NULL
)
BEGIN
    RAISERROR('El periodo no existe o no se encuentra cerrado', 16, 1)
    ROLLBACK TRANSACTION
    RETURN
END

UPDATE COMISIONES_MOVIMIENTOS_PERIODOS
SET fecha_cierre = NULL,
    usu_cierre = NULL,
    modi_fecha = GETDATE(),
    usu_modi = SUSER_NAME()
WHERE periodo = @periodo
AND fecha_cierre IS NOT NULL

IF @@ROWCOUNT <> 1
BEGIN
    RAISERROR('No se pudo reabrir exactamente un periodo', 16, 1)
    ROLLBACK TRANSACTION
    RETURN
END

SELECT periodo,
       fecha_corte,
       fecha_cierre,
       modi_fecha,
       usu_modi,
       usu_cierre
FROM COMISIONES_MOVIMIENTOS_PERIODOS
WHERE periodo = @periodo

COMMIT TRANSACTION
```

1. Elimina los movimientos anteriores del período.
2. Restablece `SOLICITUDES.proce_fecha_comisiones`.
3. Regenera cabeceras, afiliados, recaudos, asesores y seguros.
4. Vuelve a marcar las solicitudes procesadas.
5. Registra nuevamente `fecha_cierre` y `usu_cierre`.
