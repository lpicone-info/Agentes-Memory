### Causa

`superbatch.ini` está guardado como **UTF-8 con BOM**. Sus primeros bytes son:

```text
EF BB BF 0D 0A [DataBaseConnection]
```

La línea vacía inicial deja el BOM aislado. Si se elimina, queda:

```text
EF BB BF [DataBaseConnection]
```

PowerBuilder lee el archivo mediante `ProfileString` y no reconoce la primera sección porque interpreta el BOM como parte del nombre:

```text
<BOM>[DataBaseConnection]
```

Por eso no encuentra `Auto-Login`, `ComputerName`, `DBMS`, etc.

### Evidencia

- [wp_login_batch_general.srw](/home/luispicone/.openclaw/workspace/svn/[SECRETO REDACTADO]/exe_afilmed/src/wp_login_batch_general.srw:127) busca la sección `DataBaseConnection` usando `ProfileString`.

- Los INI UTF-8 con BOM del proyecto presentan la misma línea vacía inicial.
- Los INI ASCII pueden comenzar directamente con `[DataBaseConnection]`.

Guardar `superbatch.ini` como:

- **ANSI/ASCII**, o
- **UTF-8 sin BOM**.
