**Paso A Paso**

1. Crear una app PowerBuilder 2022 simple en la VM.
2. Compilarla en **32 bits**, porque Afilmed usa COM/ActiveX legacy y Chilkat 9.5 normalmente está registrado como componente 32 bits.
3. Registrar Chilkat 9.5 en Windows si no quedó registrado:
   ```bat
   regsvr32 ChilkatAx-9.5.0-win32.dll
   ```
   Ejecutarlo como administrador.
4. Crear una ventana simple con campos:
   - Host
   - Puerto
   - Usuario
   - Password
   - Directorio remoto
   - Archivo local de prueba
   - Tipo: `FTP`, `FTPS explícito`, `SFTP`
5. Agregar un botón “Probar conexión”.
6. En ese botón simular primero lo que hace Afilmed:
   - `create oleobject`
   - `ConnectToNewObject("Chilkat_9_5_0.Ftp2")` para FTP/FTPS
   - `ConnectToNewObject("Chilkat_9_5_0.SFtp")` para SFTP
   - `UnlockComponent(...)`
   - setear host, puerto, usuario, password
   - conectar
   - mostrar `LastErrorText` si falla
7. Crear un archivo local chico, por ejemplo `C:\temp\chilkat_test.txt`.
8. Probar acciones equivalentes a Afilmed:
   - FTP/FTPS: `ChangeRemoteDir`
   - FTP/FTPS: `PutFile`
   - FTP/FTPS: `GetSizeByName`
   - FTP/FTPS: `DeleteRemoteFile`
   - SFTP: `AuthenticatePw`
   - SFTP: `InitializeSftp`
   - SFTP: `UploadFileByName`

Código base para el botón:

```powerscript
oleobject loo_ftp
integer li_rc, li_success
string ls_mensaje

loo_ftp = create oleobject

// Para FTP / FTPS
li_rc = loo_ftp.ConnectToNewObject("Chilkat_9_5_0.Ftp2")

// Para SFTP usar esta línea en lugar de la anterior:
// li_rc = loo_ftp.ConnectToNewObject("Chilkat_9_5_0.SFtp")

if li_rc < 0 then
    messagebox("Chilkat", "No pudo crear el objeto COM. Código: " + string(li_rc))
    destroy loo_ftp
    return
end if

li_success = loo_ftp.UnlockComponent("CLAVE_LICENCIA_CHILKAT")
if li_success <> 1 then
    messagebox("Chilkat Unlock", string(loo_ftp.LastErrorText))
    destroy loo_ftp
    return
end if

// FTP / FTPS
loo_ftp.AutoFix = 0
loo_ftp.Hostname = "HOST_FTP"
loo_ftp.Username = "USUARIO"
loo_ftp.Password = "PASSWORD"
loo_ftp.Port = 21
loo_ftp.Ssl = 0

// FTPS explícito, igual que Afilmed cuando cifrado = 'E'
// loo_ftp.AuthTls = 1

loo_ftp.ConnectTimeout = 30
loo_ftp.ReadTimeout = 20000
loo_ftp.IdleTimeoutMs = 60000

li_success = loo_ftp.Connect()
if li_success <> 1 then
    messagebox("FTP Connect", string(loo_ftp.LastErrorText))
    destroy loo_ftp
    return
end if

li_success = loo_ftp.ChangeRemoteDir("/directorio/prueba")
if li_success <> 1 then
    messagebox("FTP ChangeRemoteDir", string(loo_ftp.LastErrorText))
    loo_ftp.Disconnect()
    destroy loo_ftp
    return
end if

li_success = loo_ftp.PutFile("C:\temp\chilkat_test.txt", "chilkat_test.txt")
if li_success <> 1 then
    messagebox("FTP PutFile", string(loo_ftp.LastErrorText))
    loo_ftp.Disconnect()
    destroy loo_ftp
    return
end if

messagebox("Chilkat", "Prueba FTP finalizada correctamente")

loo_ftp.Disconnect()
destroy loo_ftp
```

Para SFTP, el flujo cambia después del `ConnectToNewObject`:

```powerscript
li_success = loo_ftp.Connect("HOST_SFTP", 22)
if li_success <> 1 then

end if

li_success = loo_ftp.InitializeSftp()
if li_success <> 1 then

    destroy loo_ftp
    return
end if

li_success = loo_ftp.UploadFileByName("/directorio/prueba/chilkat_test.txt", "C:\temp\chilkat_test.txt")
if li_success <> 1 then
    messagebox("SFTP Upload", string(loo_ftp.LastErrorText))
    destroy loo_ftp
    return
end if

messagebox("Chilkat", "Prueba SFTP finalizada correctamente")
destroy loo_ftp
```
