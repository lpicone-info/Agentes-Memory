En base consultada con el profile `PruebasCoreINFOMEDICAL` encontré escenarios mezclados:

Conclusión técnica: **no es un comportamiento consistente del retiro laboral; es falta de cascada o validación entre `AsesorLaboral` y `AsesorPlan`**.
