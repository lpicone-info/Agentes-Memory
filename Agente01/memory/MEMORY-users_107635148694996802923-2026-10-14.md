   ```text

   documento
   nombre

   ```

```text

```

### Condiciones para automatizar

La reversión automática solo debería continuar cuando el comprobante:

- está vigente;
- no fue reversado;
- no tiene pagos aplicados;
- no está incluido en acuerdos;
- puede regenerarse completamente;
- corresponde a un período igual o posterior a la aplicación.

Si tiene un recaudo aplicado, saldo anticipado o acuerdo de pago, debe bloquearse para tratamiento controlado.

La secuencia transaccional debe ser:

```text

→ reversar facturación futura
→ validar nuevamente
→ generar e impactar Cambio de Responsable Pagador
→ refacturar al nuevo contratante
→ validar id_contratante
COMMIT
```

```text
ROLLBACK
```
