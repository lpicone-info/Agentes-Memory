“**Genera CC automático**” significa **genera automáticamente un Cambio de Cobertura**.

En esta tarea, el sistema detecta durante la prefacturación que:

- El contratante está en un estado cooperativa que permite el cambio.
- Su plan y tarifa de asociado coinciden con una homologación configurada.
- Se cumple la fecha de aplicación o existe una solicitud habilitante.

Entonces genera internamente una novedad de cambio de cobertura, sin que el usuario tenga que cargarla manualmente.

El movimiento esperado es:

- **Motivo:** `6 - Cambio de cobertura`
- **Transacción:** `CC`
- **Plan/tarifa origen:** asociado
- **Plan/tarifa destino:** familiar
- **Marca:** `cambio_asoc_fam = 'S'`
- **Estado del movimiento:** `B`

Por ejemplo:

```text
PREFA / APREFTE
        ↓ CC automático
PREFA / FPREFTE
```

Por eso, en los casos de prueba, “debe generar CC automático” quiere decir que después de ejecutar la prefacturación debe existir el movimiento de cambio desde la tarifa de asociado hacia la tarifa familiar para ese contrato. No significa generar una factura de tarjeta de crédito ni crear manualmente una nueva solicitud.
