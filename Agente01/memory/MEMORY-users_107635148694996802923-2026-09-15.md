Savina, para **carta de negación Presmed** se imprime desde la ventana de **Email / Impresión de la Autorización**: `wr_auto_impresion.srw`.

El flujo es:

1. Entrás a la autorización negada.
2. Abrís la opción de impresión/mail de la autorización.
3. Seleccionás **Impresión**.
4. El sistema valida:
   - que exista carta de negación generada
   - que esté finalizada
   - que el usuario tenga firma digital
   - que el usuario tenga rol asignado
5. Recupera el reporte `dwc_carta_negacion`.
6. Ejecuta `f_print(dw_imprimir)`.
7. Marca la carta como impresa llamando a `pru_carta_negacion` con `@prm_solo_impre = 'S'`.

Archivos clave:
- `exe_presmed/Source Infomedical/wr_auto_impresion.srw`
- `exe_presmed/Source Infomedical/dwc_carta_negacion.srd`
- `backend/procedures/prs_carta_negacion_requisitos.sql`
- `backend/procedures/pru_carta_negacion.sql`
